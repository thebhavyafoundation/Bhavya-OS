# README Standard

**Status:** published
**Date:** 2026-07-15
**Owner:** Engineering Team

## Purpose

Define README documentation standards for the Bhavya Foundation platform.

## Required Sections

Every package and application must include a README with the following sections:

### 1. Title and Description

```markdown
# Package Name

Brief description of what this package does and its purpose.
```

### 2. Installation

```markdown
## Installation

\`\`\`bash
pnpm install
\`\`\`
```

### 3. Usage

```markdown
## Usage

Examples of how to use this package.
```

### 4. API Reference

```markdown
## API

- `functionName()` - Description
- `ClassName` - Description
```

### 5. Development

```markdown
## Development

\`\`\`bash
pnpm dev
pnpm test
pnpm build
\`\`\`
```

### 6. Contributing

```markdown
## Contributing

Guidelines for contributors.
```

## Quality Standards

- Clear and concise writing
- Code examples for all features
- Up-to-date with latest changes
- Accessible to new users

## Template

Use the README template in `.github/README-template.md` as a starting point.
