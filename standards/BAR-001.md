# Bhavya Architecture Rules

**Status:** published
**Date:** 2026-07-15
**Owner:** Architecture Board

## Purpose

Define architectural rules and patterns for the Bhavya Foundation platform.

## Core Rules

### 1. Domain Isolation

Each mission domain operates independently:
- No cross-domain imports
- Shared platform through content-core
- Independent data storage

### 2. Single Publishing Pipeline

All data flows through the same mechanism:
- Mission apps publish to content-core
- Content-core publishes to Knowledge graph
- Library consumes published data

### 3. Filesystem as Source of Truth

- JSON files for structured data
- Markdown files for content
- Directory structure for organization

### 4. Type Safety

- TypeScript strict mode
- No `any` types
- Proper error handling

## Compliance

- All code must follow these rules
- Violations are caught in code review
- Exceptions require Architecture Board approval
