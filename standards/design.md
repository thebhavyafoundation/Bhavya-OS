# Design Standard

**Status:** published
**Date:** 2026-07-15
**Owner:** Design Team

## Purpose

Define design standards for the Bhavya Foundation platform to ensure visual consistency and brand compliance.

## Brand Identity

### Colors

- **Primary**: Deep Forest Green (#0D503C)
- **Secondary**: Earth Stone (#8B7355)
- **Accent**: Warm Gold (#C9A84C)
- **Neutral**: Warm grays with slight brown undertone

### Typography

- **Primary Font**: Inter (Google Fonts)
- **Heading Weights**: 600-700
- **Body Weight**: 400
- **Line Height**: 1.5-1.6

### Spacing

- Base unit: 4px
- Scale: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128

## Component Standards

### Buttons

- Primary: Green background, white text
- Secondary: Outline with green border
- Hover: Darken background 10%
- Focus: Visible focus ring

### Forms

- Consistent input heights
- Clear labels and placeholders
- Validation messages below inputs
- Required field indicators

### Cards

- Subtle shadows
- Rounded corners (8px)
- Consistent padding (16px-24px)

## Accessibility

- Minimum contrast ratio: 4.5:1 for text
- Focus indicators for all interactive elements
- Semantic HTML structure
