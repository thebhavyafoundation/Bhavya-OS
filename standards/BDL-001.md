# Bhavya Design Language

**Status:** published
**Date:** 2026-07-15
**Owner:** Design Team

## Purpose

Define the design language and visual identity for the Bhavya Foundation platform.

## Brand Colors

### Primary Colors

- **Deep Forest Green**: #0D503C (Primary)
- **Earth Stone**: #8B7355 (Secondary)
- **Warm Gold**: #C9A84C (Accent)

### Neutral Colors

- **Warm Gray 100**: #F5F3F0
- **Warm Gray 200**: #E5E2DD
- **Warm Gray 300**: #D4D0CA
- **Warm Gray 400**: #B8B3AB
- **Warm Gray 500**: #9C968E
- **Warm Gray 600**: #7A756E
- **Warm Gray 700**: #5C5751
- **Warm Gray 800**: #3D3A36
- **Warm Gray 900**: #1F1D1B

## Typography

### Font Family

- **Primary**: Inter (Google Fonts)
- **Monospace**: JetBrains Mono

### Type Scale

- **Heading 1**: 36px / 700 weight
- **Heading 2**: 30px / 600 weight
- **Heading 3**: 24px / 600 weight
- **Heading 4**: 20px / 600 weight
- **Body**: 16px / 400 weight
- **Small**: 14px / 400 weight

## Spacing

Base unit: 4px

- **xs**: 4px
- **sm**: 8px
- **md**: 16px
- **lg**: 24px
- **xl**: 32px
- **2xl**: 48px
- **3xl**: 64px

## Components

### Buttons

- **Primary**: Green background, white text
- **Secondary**: White background, green border
- **Ghost**: Transparent background, green text

### Forms

- **Input**: 40px height, 12px padding
- **Select**: Same as input
- **Textarea**: Min-height 100px

### Cards

- **Border radius**: 8px
- **Padding**: 24px
- **Shadow**: 0 2px 8px rgba(0,0,0,0.1)
