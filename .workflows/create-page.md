# Workflow: Create Page

## Trigger

- New page request from Founder or CEO

## Steps

1. **Research** — Gather requirements and content
2. **Design** — Create wireframe and mockup
3. **Implement** — Build page with Next.js
4. **Test** — Run accessibility and SEO checks
5. **Review** — Code review by Reviewer Agent
6. **Deploy** — Deploy to staging
7. **Verify** — Verify on live environment
8. **Publish** — Move to production

## Agents Involved

- Founder (approval)
- Researcher (content gathering)
- Designer (visual design)
- Developer (implementation)
- Reviewer (code review)
- QA (testing)
- Release (deployment)

## Output

- New page in apps/website
- Updated navigation
- Updated sitemap
- Updated documentation
