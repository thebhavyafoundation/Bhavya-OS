# Workflow: Generate Report

## Trigger

- Report request from Founder or CEO

## Steps

1. **Define Scope** — Clarify report requirements
2. **Gather Data** — Collect relevant information
3. **Analyze** — Process and analyze data
4. **Create Visualizations** — Generate charts and graphs
5. **Write Report** — Create report document
6. **Review** — Review for accuracy
7. **Publish** — Distribute to stakeholders

## Agents Involved

- Researcher (data gathering)
- Writer (report writing)
- Designer (visualizations)

## Output

- Report document
- Visualizations
- Executive summary
- Action items
