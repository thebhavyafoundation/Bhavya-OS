# Workflow: Write Blog

## Trigger

- Content request from Writer or SocialMedia agent

## Steps

1. **Research** — Gather topic information
2. **Outline** — Create article structure
3. **Write** — Create first draft
4. **Edit** — Proofread and refine
5. **SEO Optimize** — Optimize for search engines
6. **Review** — Content review
7. **Publish** — Publish to website
8. **Promote** — Share on social media

## Agents Involved

- Writer (content creation)
- Researcher (topic research)
- SEO (optimization)
- SocialMedia (promotion)

## Output

- Published blog post
- Social media posts
- Updated sitemap
- Analytics tracking
