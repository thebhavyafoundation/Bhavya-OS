# Workflow: Review PR

## Trigger

- Pull request created

## Steps

1. **Automated Checks** — Run lint, typecheck, tests
2. **Code Review** — Review code quality
3. **Security Review** — Check for vulnerabilities
4. **Documentation Review** — Verify docs updated
5. **Approval** — Approve or request changes
6. **Merge** — Merge if approved

## Agents Involved

- Reviewer (code review)
- Security (security review)
- QA (test verification)
- CTO (final approval)

## Output

- Code review comments
- Approval decision
- Merged code
- Updated documentation
