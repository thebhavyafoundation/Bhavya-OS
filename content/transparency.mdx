# Radical Openness by Architecture

Every governance document, Architecture Decision Record (ADR), release manifest, and agent execution policy is publicly accessible and machine-verifiable.

## Live Governance Datasets

### Architecture Decision Records (ADRs)
Immutable architectural contracts that govern the technical evolution of Bhavya OS.

### Service & Agent Registries
Real-time registry manifests generated deterministically from repository state (`pnpm registry:generate`).

### Domain Memory State
Structured JSON state storage across platform domains, governed by immutable meta-schemas.
