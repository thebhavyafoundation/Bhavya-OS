# Architecture-Change Trigger

New or changed package, app, route, schema, API, cross-package dependency, shared primitive, or infra boundary →

1. Load `bhavya-architecture` skill.
2. Read constitutions 02 (`BHAVYA-OS-CONSTITUTION.md`) + 08 (`ARCHITECTURE.md`) + `docs/architecture/REPOSITORY_SOURCE_OF_TRUTH.md` + `docs/architecture/DOMAIN_OWNERSHIP.md`.
3. Substantial design → `bhavya-reasons-canvas` into `specs/`.
4. Platform-wide evolution → RFC in `rfcs/`.

Architecture consolidation (runtimes, packages, type systems, registries) requires explicit human authorization (see `_config/project-governance.md` Human Gates).
