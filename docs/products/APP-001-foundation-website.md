# APP-001: Foundation Website — Master Product Specification

**Version:** 1.0.0
**Status:** Production
**Last Updated:** 2026-08-05

---

## Vision

The Bhavya Foundation website is the primary public interface for the organization. It communicates our mission, impact, and credibility to donors, volunteers, partners, and the public.

---

## Users

| User Type  | Need                       | Frequency |
| ---------- | -------------------------- | --------- |
| Donor      | Learn about impact, donate | Weekly    |
| Volunteer  | Find opportunities, engage | Monthly   |
| Partner    | Evaluate collaboration     | Quarterly |
| Media      | Access press materials     | As needed |
| Public     | Learn about mission        | Daily     |
| Researcher | Access data, reports       | Monthly   |

---

## Objectives

1. **Communicate Mission** — Clear, compelling storytelling
2. **Build Credibility** — Institutional trust and transparency
3. **Drive Engagement** — Donations, volunteers, partnerships
4. **Ensure Accessibility** — WCAG 2.1 AA compliance
5. **Optimize Performance** — Core Web Vitals pass
6. **Maximize SEO** — Top rankings for relevant queries

## Architecture

```
Next.js 15 App Router
├── src/
│   ├── app/           # 27 pages
│   ├── components/    # 50+ components
│   ├── lib/           # Utilities
│   └── styles/        # CSS
├── public/            # Static assets
└── next.config.ts     # Configuration
```

**Stack:**

- Next.js 15.5.20
- React 19.2.4
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lucide React
