# Graduation Profile

## Overview

The Graduation Profile defines what every Bhavya Foundation graduate should know, be able to build, and be able to teach.

## The Transformation

```
Curious Visitor
    ↓
Confident Builder
    ↓
AI Engineer
    ↓
Open Source Contributor
    ↓
Mentor
    ↓
Institution Builder
```

## Graduate Capabilities

### Know

- How AI works at a foundational level
- How to build AI-powered applications
- How to contribute to open source
- How to teach others
- How to lead institutions

### Build

- AI-powered applications
- Open source projects
- Real-world solutions
- Teaching materials
- Community programs

### Teach

- AI concepts to beginners
- Engineering practices to peers
- Research methods to students
- Leadership to mentors
- Vision to institutions
