# Master Curriculum v1.0

## Status: Final Planning Artifact

## Date: 2026-08-04

## Mission

The Curriculum Intelligence Engine is complete. Do not immediately create Knowledge Packages. Do not write lessons. Do not write labs.

The next objective is to synthesize a canonical Master Curriculum for Bhavya Foundation. This curriculum becomes the single source of truth for all future educational content.

## Primary Objective

Produce a ranked curriculum answering:

**"What should a Bhavya Foundation graduate know, be able to build, and be able to teach?"**

Every future Knowledge Package, lesson, project, assessment, article, and media asset derives from this curriculum.

## The Promise

A Bhavya Foundation graduate will be able to:

### Know

- How AI works at a foundational level
- How to build AI-powered applications
- How to contribute to open source
- How to teach others
- How to lead institutions

### Build

- AI-powered applications
- Open source projects
- Real-world solutions
- Teaching materials
- Community programs

### Teach

- AI concepts to beginners
- Engineering practices to peers
- Research methods to students
- Leadership to mentors
- Vision to institutions

## Curriculum Philosophy

### 1. Capabilities Over Tools

Teach durable capabilities that outlast specific tools.

### 2. Experiential Over Theoretical

Prioritize learning by doing over learning by reading.

### 3. Progressive Complexity

Start simple, increase complexity gradually.

### 4. Real-World Application

Every concept connects to real problems.

### 5. Community Learning

Learn with and from others.

### 6. Portfolio Building

Every module creates portfolio value.

### 7. Mission Alignment

Every module advances the transformation.

## The Transformation

```
Curious Visitor
    ↓
Confident Builder
    ↓
AI Engineer
    ↓
Open Source Contributor
    ↓
Mentor
    ↓
Institution Builder
```

## Exit Criteria

The Master Curriculum is complete when it clearly defines:

1. What every Bhavya graduate should know
2. What every Bhavya graduate should build
3. What every Bhavya graduate should contribute
4. What evidence demonstrates mastery
5. Which Knowledge Packages must be created first

## Final Rule

This is the last major planning artifact.

Once approved:

- Freeze the Master Curriculum (version 1.0)
- Manage changes through curriculum governance
- Shift work to producing high-quality Knowledge Packages
