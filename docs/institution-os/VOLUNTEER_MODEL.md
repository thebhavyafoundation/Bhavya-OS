# Volunteer Model

## Overview

The Volunteer Model defines how contribution is recognized at Bhavya Foundation. Volunteering is not unpaid labor — it is skill development, portfolio building, and community service.

## Volunteer Philosophy

### Core Principles

1. **Contribution is Learning** — Volunteering teaches skills
2. **Contribution is Portfolio** — Volunteering builds verifiable experience
3. **Contribution is Community** — Volunteering builds connections
4. **Contribution is Impact** — Volunteering creates value
5. **Contribution is Recognition** — Volunteering is recognized and rewarded

### The Volunteer Flywheel

```
Learn → Volunteer → Build Skills → Build Portfolio → Get Recognized → Learn More
```

Every volunteer experience strengthens the individual and community.
