# Career Model

## Overview

The Career Model defines how careers begin at Bhavya Foundation. Careers are not just about job placement — they are about building verifiable skills, portfolios, and professional networks.

## Career Philosophy

### Core Principles

1. **Skills Over Credentials** — What you can do matters more than where you studied
2. **Portfolio Over Resume** — What you built matters more than what you claim
3. **Impact Over Activity** — What changed matters more than what you did
4. **Network Over Isolation** — Who you know matters more than what you know alone
5. **Growth Over Comfort** — Learning matters more than knowing

### The Career Flywheel

```
Learn → Build → Contribute → Network → Career → Mentor → Learn
```

Every career stage feeds back into learning and community.

## Career Stages

### 1. Exploration

**Who:** Visitors and early-stage students
**Focus:** Understanding AI, exploring interests, building foundational skills
**Activities:**

- Complete initial lessons
- Build first projects
- Join community discussions
- Attend events
- Connect with mentors

**Portfolio:**

- Initial projects
- Learning documentation
- Community engagement
- Reflection essays

### 2. Foundation

**Who:** Students completing core curriculum
**Focus:** Building solid AI fundamentals and practical skills
**Activities:**

- Complete all core lessons
- Build multiple projects
- Contribute to discussions
- Attend workshops
- Connect with peers

**Portfolio:**

- Core projects
- Skills documentation
- Community contributions
- Peer feedback

### 3. Specialization

**Who:** Students choosing focus areas
**Focus:** Deep expertise in specific AI domains
**Activities:**

- Complete advanced lessons
- Build specialized projects
- Contribute to open source
- Attend specialized events
- Connect with experts

**Portfolio:**

- Specialized projects
- Open source contributions
- Expert recommendations
- Research contributions

### 4. Professional

**Who:** Students ready for career
**Focus:** Professional skills and career preparation
**Activities:**

- Build professional portfolio
- Network with industry
- Prepare for interviews
- Apply for positions
- Negotiate offers

**Portfolio:**

- Professional projects
- Industry connections
- Interview preparation
- Job offers

### 5. Leadership

**Who:** Professionals advancing careers
**Focus:** Leadership, mentorship, and institutional contribution
**Activities:**

- Lead projects
- Mentor students
- Contribute to curriculum
- Speak at events
- Build teams

**Portfolio:**

- Leadership evidence
- Mentorship impact
- Teaching contributions
- Industry influence

### 6. Executive

**Who:** Senior professionals
**Focus:** Strategic vision, institutional leadership, industry influence
**Activities:**

- Set strategic direction
- Build partnerships
- Influence industry
- Mentor leaders
- Shape institution

**Portfolio:**

- Strategic initiatives
- Partnership outcomes
- Industry influence
- Legacy projects

## Portfolio System

### What is a Portfolio?

A portfolio is a verifiable record of skills, projects, and impact. It is portable, shareable, and evidence-based.

### Portfolio Components

#### Skills

- **Technical Skills** — AI, programming, tools
- **Soft Skills** — Communication, leadership, teamwork
- **Domain Skills** — Specialized knowledge
- **Meta Skills** — Learning, problem-solving, critical thinking

#### Projects

- **Learning Projects** — Demonstrate skill acquisition
- **Open Source Projects** — Demonstrate contribution
- **Professional Projects** — Demonstrate impact
- **Research Projects** — Demonstrate innovation

#### Contributions

- **Code Contributions** — Open source work
- **Community Contributions** — Mentoring, teaching, organizing
- **Research Contributions** — Publications, experiments
- **Institutional Contributions** — Curriculum, governance

#### Impact

- **Student Impact** — How you helped others learn
- **Community Impact** — How you built community
- **Research Impact** — How you advanced knowledge
- **Industry Impact** — How you created value

### Portfolio Verification

#### Verification Methods

- **Maintainer Confirmation** — Open source maintainers verify contributions
- **Peer Review** — Peers verify work quality
- **Mentor Verification** — Mentors verify skill development
- **AI Verification** — AI tools verify code quality
- **Community Verification** — Community recognizes impact

#### Verification Standards

- Evidence-based
- Transparent
- Portable
- Verifiable
- Up-to-date

### Portfolio Presentation

#### Formats

- **GitHub Profile** — Code contributions and projects
- **Portfolio Website** — Comprehensive presentation
- **Resume/CV** — Professional summary
- **LinkedIn** — Professional network
- **Demo Day** — Live presentation

#### Best Practices

- Tell a story
- Show impact
- Demonstrate growth
- Be authentic
- Keep updated
