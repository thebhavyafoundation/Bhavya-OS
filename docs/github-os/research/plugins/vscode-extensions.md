# VS Code Extensions — Knowledge Package

## Executive Summary

Visual Studio Code's extension marketplace contains 50,000+ extensions. The most impactful ones fall into five categories: AI coding assistants, Git management, code quality/linting, debugging, and productivity workflow tools. In 2026, AI-powered extensions (GitHub Copilot, Codeium, Continue) dominate developer adoption, while foundational tools (GitLens, ESLint, Prettier, Error Lens) remain non-negotiable for professional teams. This package catalogs the extensions that deliver measurable productivity gains, not cosmetic changes.

## Tools by Category

### AI-Powered Coding Assistants

#### 1. GitHub Copilot

- **Description:** Industry-standard AI code completion trained on public code. Inline suggestions, chat interface, agent mode for multi-file refactoring.
- **Use Case:** Boilerplate generation, test creation, documentation writing, code completion
- **Installation:** VS Code Marketplace → GitHub Copilot
- **Pricing:** $10/mo individual, $19/mo business, free for verified OSS maintainers
- **Maintenance:** Actively maintained by Microsoft/GitHub. Monthly feature updates.
- **Productivity Gain:** 5/5 — Significant time savings on repetitive code, test generation, and refactoring tasks.

#### 2. Codeium (Windsurf)

- **Description:** Free AI-powered code completion with 70+ language support. Chat functionality for code explanations and generation. No telemetry on code for free-tier users.
- **Use Case:** Budget-conscious teams, students, rapid prototyping
- **Installation:** VS Code Marketplace → Codeium
- **Pricing:** Free tier with core autocomplete features
- **Maintenance:** Actively maintained as part of Windsurf ecosystem.

#### 3. Continue

- **Description:** Open-source AI assistant supporting custom models (Claude, GPT-4, local models). Best for teams with compliance requirements or privacy concerns.
- **Use Case:** Privacy-first teams, custom model workflows, enterprise compliance
- **Installation:** VS Code Marketplace → Continue
- **Pricing:** Free + API costs
- **Maintenance:** Active open-source community, GitHub-hosted.

#### 4. Amazon Q Developer

- **Description:** AWS-native AI coding assistant with cloud-aware service guidance and infrastructure suggestions.
- **Use Case:** AWS-heavy development, cloud-native applications
- **Maintenance:** Maintained by Amazon. Regular updates aligned with AWS services.

#### 5. Sourcegraph Cody

- **Description:** Repository-level code understanding for large codebases and monorepos. Cross-file context awareness.
- **Use Case:** Large codebases, monorepo navigation, cross-repository search
- **Maintenance:** Actively maintained by Sourcegraph.

### Git Management

#### 6. GitLens

- **Description:** Git supercharged — blame annotations, commit history visualization, branch comparison, interactive rebase. Visualizes who changed what, when, and why.
- **Use Case:** Understanding code history, blame annotations, branch management
- **Installation:** VS Code Marketplace → GitLens
- **Pricing:** Free core, $12/mo pro features
- **Maintenance:** Actively maintained by GitKraken/AXOS. Frequent updates.

#### 7. Git Graph

- **Description:** Visual Git branch graph directly in VS Code. Clean visualization of commit history and branch structure.
- **Use Case:** Visual branch management, understanding merge history
- **Installation:** VS Code Marketplace → Git Graph
- **Pricing:** Free
- **Maintenance:** Community-maintained, stable.

#### 8. GitHub Actions

- **Description:** Manage and monitor GitHub Actions workflows directly from VS Code. View workflow runs, debug failures.
- **Use Case:** CI/CD workflow management, Actions debugging
- **Installation:** VS Code Marketplace → GitHub Actions
- **Pricing:** Free
- **Maintenance:** Maintained by Microsoft/GitHub.

### Code Quality & Formatting

#### 9. ESLint

- **Description:** Integrates ESLint JavaScript/TypeScript linting into VS Code. Catches code quality issues in real-time.
- **Use Case:** JavaScript/TypeScript code quality enforcement
- **Installation:** VS Code Marketplace → ESLint
- **Pricing:** Free
- **Maintenance:** Core tool, extremely active community.

#### 10. Prettier

- **Description:** Opinionated code formatter supporting many languages. Enforces consistent style across team.
- **Use Case:** Code formatting consistency, auto-format on save
- **Installation:** VS Code Marketplace → Prettier
- **Pricing:** Free
- **Maintenance:** Widely adopted, very active.

#### 11. SonarQube for IDE (formerly SonarLint)

- **Description:** Real-time code quality and security analysis. Detects bugs, code smells, and security vulnerabilities as you type.
- **Use Case:** Security analysis, code quality enforcement, vulnerability detection
- **Installation:** VS Code Marketplace → SonarQube for IDE
- **Pricing:** Free
- **Maintenance:** Maintained by SonarSource. Active development.

#### 12. Error Lens

- **Description:** Displays error and warning messages inline on the same line as the problematic code. Eliminates switching to Problems panel.
- **Use Case:** Immediate error visibility, faster debugging
- **Installation:** VS Code Marketplace → Error Lens
- **Pricing:** Free
- **Maintenance:** Community-maintained, stable.

#### 13. EditorConfig for VS Code

- **Description:** Supports `.editorconfig` files to maintain consistent coding styles across editors and IDEs.
- **Use Case:** Cross-editor style consistency
- **Installation:** VS Code Marketplace → EditorConfig
- **Pricing:** Free
- **Maintenance:** Stable, minimal changes needed.

### Debugging & Testing

#### 15. Remote Development (SSH, Containers, WSL)

- **Use Case:** Remote development, container-based dev environments
- **Installation:** VS Code Marketplace → Remote Development

- **Maintenance:** Microsoft-maintained, actively developed.

#### 16. Test Explorer UI

- **Description:** Unified test explorer for running and debugging tests across multiple frameworks.
- **Use Case:** Test management, test debugging
- **Installation:** VS Code Marketplace → Test Explorer UI
- **Pricing:** Free
- **Maintenance:** Community-maintained.

- **Installation:** VS Code Marketplace → REST Client
- **Pricing:** Free
- **Maintenance:** Community-maintained.

#### 22. Peacock

- **Description:** Colorize VS Code workspace titles and borders. Useful for distinguishing multiple VS Code windows.

- **Installation:** VS Code Marketplace → Peacock
- **Pricing:** Free
- **Maintenance:** Microsoft-maintained.

## Hardware Impact

- **Minimal:** Most extensions add < 50MB RAM usage
- **AI extensions:** Copilot uses ~200MB additional RAM for language server
- **Heavy:** Docker extension can be resource-intensive with many containers
- **Recommendation:** Monitor with `Help → Process Explorer` in VS Code

## Compatibility

- **Platform:** Windows, macOS, Linux (all major platforms)
- **VS Code Version:** Most require VS Code 1.85+ (2024+)
- **Architecture:** x64, ARM64 (Apple Silicon native support)
- **Remote:** Full support via Remote SSH/Containers/WSL extensions
