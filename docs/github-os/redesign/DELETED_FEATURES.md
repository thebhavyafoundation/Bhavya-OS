# Deleted Features — GitHub OS v2.0

## Features Removed

### 1. Knowledge Graph

- **What:** SVG force-graph visualization of repository relationships
- **Why Removed:** Visual candy with no practical value. 15 nodes don't justify a full-page SVG.
- **Impact:** None — low usage, low value

### 2. Repository Comparisons

- **What:** Side-by-side score comparison of two repositories
- **Why Removed:** Scores don't tell the story. Comparison requires context, not just numbers.
- **Impact:** None — low usage, low value

### 3. Timeline

- **What:** Vertical timeline of releases, ADRs, milestones
- **Why Removed:** GitHub does this better. No unique value.
- **Impact:** None — low usage, low value

### 4. Institutional Memory

- **What:** Q&A format about repository knowledge
- **Why Removed:** Only 2 entries per repo. Low density, low value.
- **Impact:** None — low usage, low value

### 5. Dashboard Activity Feed

- **What:** Timeline of recent activities
- **Why Removed:** Low value — activities are generic, not actionable.
- **Impact:** None — low usage, low value

### 6. Dashboard Radar Widget

- **What:** Technology radar items
- **Why Removed:** Static data, no actionability.
- **Impact:** None — low usage, low value

### 7. Dashboard Recommendation Widget

- **What:** Priority-tagged recommendations
- **Why Removed:** Generic, not personalized.
- **Impact:** None — low usage, low value

### 8. Dashboard Pattern Widget

- **What:** Engineering patterns list
- **Why Removed:** Duplicated in Knowledge page.
- **Impact:** None — still accessible via Knowledge

### 9. Dashboard Health Widget

- **What:** Repository health bars
- **Why Removed:** Duplicated in repository detail.
- **Impact:** None — still accessible via repository detail

### 10. Sidebar Dead Links (15)

- **What:** Navigation links to non-existent pages
- **Why Removed:** Broken navigation is worse than no navigation.
- **Impact:** Positive — removes frustration

## Summary

- **Features removed:** 10
- **Features merged:** 9
- **Features preserved:** All core features
- **Net result:** Cleaner, faster, more focused product
