# User Journey — GitHub OS Beta Validation

## Journey 1: Discover → Understand → Learn

**Persona:** Senior Engineer
**Goal:** Understand a new codebase

| Step      | Action                    | Time    | Feeling                                               |
| --------- | ------------------------- | ------- | ----------------------------------------------------- |
| 1         | Open Dashboard            | 0s      | "Clean, focused"                                      |
| 2         | Click Browse Repositories | 2s      | "8 repos, good overview"                              |
| 3         | Click bhavya-platform     | 5s      | "Clear scores, maturity badge"                        |
| 4         | Read Overview tab         | 15s     | "Why Bhavya Cares explains the why"                   |
| 5         | Click Architecture tab    | 20s     | "Layered architecture, patterns, ADRs — this is rich" |
| 6         | Click Learning tab        | 30s     | "Prerequisites, reading order — actionable"           |
| 7         | Click Advisor tab         | 40s     | "Full assessment, debt, plan — comprehensive"         |
| **Total** |                           | **40s** | **"I understand this codebase"**                      |

**Journey 1 score: 9/10** — Fast, clear, actionable.
