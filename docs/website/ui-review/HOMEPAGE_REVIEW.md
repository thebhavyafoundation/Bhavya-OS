# Homepage Review

## Current State

The Bhavya Foundation homepage is a basic Starlight landing page with:

- Generic hero section
- 3-card grid (AI Institute, Knowledge Packages, Open Source)
- Single CTA button

**Maturity: 3/10**

## Elite Website Patterns

### Vercel

- **Hero:** "Agentic Infrastructure" — bold, declarative title
- **Subhead:** "The autonomous stack for every app and agent" — one sentence, clear value
- **CTA:** "Start Deploying" — action-oriented
- **Social proof:** Logo grid of customers
- **Layout:** Full-width hero, centered content

### Linear

- **Hero:** "The system for product development" — category-defining
- **Subhead:** "Purpose-built for planning and building products with AI agents"
- **CTA:** "Get started" + "See how it works"
- **Visual:** Animated product illustration
- **Social proof:** Customer quotes + logos

### Anthropic

- **Hero:** Clean, minimal — "Building reliable, interpretable, and steerable AI systems"
- **Layout:** Ivory background, centered text
- **Trust:** Research papers, safety commitments

### Stripe

- **Hero:** "Financial infrastructure for the internet"
- **Visual:** Code snippet showing API
- **CTA:** "Start now" + "Contact sales"
- **Social proof:** Logo grid
