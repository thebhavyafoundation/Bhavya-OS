## Rollback Plan

If critical issues are discovered:

1. **Identify issue:** Determine severity and impact
2. **Communicate:** Notify stakeholders
3. **Fix or rollback:** If fixable, fix immediately. If not, rollback to previous version
4. **Test:** Verify fix works
5. **Redeploy:** Deploy fix
6. **Monitor:** Watch for issues
7. **Document:** Record what happened and how it was resolved
