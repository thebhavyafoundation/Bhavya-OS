### Slide 2: The Problem

Most people use AI daily but don't understand how it works.

### Slide 3: Tokenization

LLMs don't read words — they read tokens.
"Hello, world!" → ["Hello", ",", " world", "!"]
This affects how AI understands text.

### Slide 4: Attention Mechanism

When processing text, LLMs use attention to decide which words matter most.
Query → Keys → Values → Scores → Weights
This determines what the AI focuses on.

### Slide 5: Context Window

The context window is how much text an AI can "see" at once.
GPT-3.5: 4K tokens (~3,000 words)
GPT-4: 128K tokens (~96,000 words)
More context = more information.

### Slide 6: Why AI Makes Mistakes

LLMs don't "know" things — they predict tokens.
This leads to hallucinations and reasoning failures.
Always verify AI outputs.

### Slide 7: Better Prompts

Bad: "Tell me about AI."
Better: "Explain how neural networks learn, focusing on training, backpropagation, and gradient descent. Use simple examples."
Specificity matters.

### Slide 8: Key Takeaways

1. Tokenization affects understanding
2. Attention determines relevance
3. Context limits information
4. Hallucinations require verification
5. Specific prompts get better results
