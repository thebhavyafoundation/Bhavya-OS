### Tweet 2

Tokenization: How AI Reads Text

LLMs don't read words — they read tokens.

"Hello, world!" → ["Hello", ",", " world", "!"]
"Unbelievable" → ["Un", "believ", "able"]

This affects how AI understands meaning.

### Tweet 3

The Attention Mechanism: What Matters

When processing text, LLMs use attention to decide which words matter most.

It works like this:

1. Query: What am I looking for?
2. Keys: What's available?
3. Values: What do I return?
4. Scores: How relevant is each key?
5. Weights: Normalized relevance

### Tweet 4

Context Window: How Much AI Remembers

The context window is how much text an AI can "see" at once.

GPT-3.5: 4K tokens (~3,000 words)
GPT-4: 128K tokens (~96,000 words)
Claude 3: 200K tokens (~150,000 words)

More context = more information.

### Tweet 5

Why AI Makes Mistakes

LLMs don't "know" things — they predict tokens.

This leads to:
• Hallucinations (wrong but confident)
• Reasoning failures (can't handle complex logic)

Always verify AI outputs.

### Tweet 6

Writing Better Prompts

Bad: "Tell me about AI."

Better: "Explain how neural networks learn, focusing on:

1. The training process
2. Backpropagation
3. Gradient descent
   Use simple examples."

Specificity matters.
