# Media Generation

## Overview

Every lesson automatically produces media assets. All media references the same Knowledge Package.

## Media Types

### Short-Form Video Scripts

**Length:** 30-60 seconds
**Platform:** TikTok, Instagram Reels, YouTube Shorts
**Structure:**

- Hook (3 seconds)
- Problem (5 seconds)
- Solution (15 seconds)
- Demonstration (15 seconds)
- Call to action (5 seconds)

### Long-Form Lesson Scripts

**Length:** 10-20 minutes
**Platform:** YouTube, Course platform
**Structure:**

- Introduction (1 minute)
- Concept explanation (5 minutes)
- Demonstration (5 minutes)
- Practice (5 minutes)
- Summary (1 minute)

### LinkedIn Carousels

**Length:** 10-15 slides
**Platform:** LinkedIn
**Structure:**

- Title slide
- Problem slide
- Solution slides (3-5)
- Implementation slides (3-5)
- Results slide
- Call to action slide

### Twitter Threads

**Length:** 10-15 tweets
**Platform:** Twitter/X
**Structure:**

- Hook tweet
- Problem tweets (2-3)
- Solution tweets (3-5)
- Implementation tweets (3-5)
- Results tweets (2-3)
- Call to action tweet

### Blog Articles

**Length:** 1000-2000 words
**Platform:** Blog, Medium, Dev.to
**Structure:**

- Engaging title
- Introduction
- Problem explanation
- Solution description
- Implementation guide
- Results and insights
- Conclusion and next steps

### Newsletters

**Length:** 500-1000 words
**Platform:** Email
**Structure:**

- Subject line
- Preview text
- Introduction
- Key insights
- Practical tips
- Resources
- Call to action

### Documentation

**Length:** Varies
**Platform:** Documentation site
**Structure:**

- Overview
- Quick start
- Detailed guide
- Examples
- API reference
- Troubleshooting

## Generation Process

### Input

- Knowledge Package
- Target platform
- Audience profile
- Brand guidelines
- Distribution channels

### Process

1. **Parse Knowledge Package** — Extract key content
2. **Select Format** — Choose appropriate media type
3. **Generate Script** — Create content
4. **Add Visual Cues** — Design visual elements
5. **Include CTAs** — Add calls to action
6. **Review** — Verify quality and accuracy

### Output

- Complete media script
- Visual cues
- Distribution plan
- Performance metrics

## Media Quality

### Standards

- **Engaging** — Captures attention immediately
- **Clear** — Message is understood quickly
- **Actionable** — Viewers know what to do next
- **Consistent** — Matches brand voice
- **Platform-Optimized** — Fits platform requirements

### Metrics

- View count
- Engagement rate
- Click-through rate
- Conversion rate
- Audience growth

## Example Media

### Short-Form Video Script: What is an LLM?

**Hook (3s):**
"AI is changing everything. But what is an LLM really?"

**Problem (5s):**
"You've heard the hype. You know AI is important. But you're not sure what an LLM actually is or how it works."

**Solution (15s):**
"An LLM is a Large Language Model. It's trained on billions of words to predict what comes next. When you type a prompt, it generates a response based on patterns it learned."

**Demonstration (15s):**
[Screen recording of LLM interaction]
"Watch this. I type a question, and the LLM generates a response. It's not understanding like a human — it's predicting the next word based on patterns."

**Call to action (5s):**
"Want to learn more? Link in bio for our free AI Foundations course."

## Media Generation Rules

### From Knowledge Package → Media

- Extract key concepts
- Identify audience needs
- Select appropriate format
- Generate content
- Add visual cues
- Include CTAs

### Platform Optimization

- **TikTok/Reels:** Fast-paced, visual, hook-first
- **LinkedIn:** Professional, insightful, actionable
- **Twitter:** Concise, thread-based, engaging
- **Blog:** Detailed, informative, SEO-optimized
- **Newsletter:** Personal, valuable, exclusive
- **Documentation:** Clear, comprehensive, searchable

### Brand Consistency

- Consistent voice
- Consistent visual style
- Consistent messaging
- Consistent CTAs
- Consistent quality
