# Brand Constitution of Bhavya Foundation

**Document Number:** 01  
**Title:** Brand Constitution  
**Status:** CONSTITUTIONAL  
**Effective Date:** 2026-01-01  
**Authority:** Derived from Document 00 (Vision), Article 2 and Article 5  
**Supersedes:** All conflicting brand guidelines, style guides, and visual identity documents

---

## Preamble

The brand of Bhavya Foundation is not a marketing asset. It is a constitutional commitment. Every color, every word, every visual element communicates the institution's values. This document establishes brand identity as law — not suggestion, not guideline, not best practice. Law.

---

## Article 1 — Brand Identity

### 1.1 Brand Name

**Bhavya Foundation**

Use the full name in all formal communications. Abbreviate to "Bhavya" only in internal contexts where the full name has been established in the same document or conversation.

### 1.2 Tagline

**NATURE. KNOWLEDGE. HERITAGE.**

This tagline is constitutional. It appears on all official materials. It is never modified, shortened, or reinterpreted.

### 1.3 Mission Statement

Bhavya Foundation is an institution committed to building a better tomorrow. We restore nature, advance knowledge, preserve heritage, and empower communities through ethical leadership, innovation, and public service.

### 1.4 Vision Statement

To build one of the world's most trusted public institutions advancing environmental stewardship, education, cultural preservation, and responsible innovation for generations to come.

### 1.5 Brand Promise

Integrity. Excellence. Innovation. Trust.  
Long-term thinking. For generations to come.

### 1.6 Brand Approach

Evidence. Impact. Sustainability.

## Article 2 — Color Palette

### 2.1 Primary Colors

These colors are the constitutional palette. No other primary colors may be introduced without amendment.

| Color        | Hex       | Usage                                         |
| ------------ | --------- | --------------------------------------------- |
| Forest Green | `#1a3a2a` | Primary brand color, headers, logo background |
| Gold/Amber   | `#c9a227` | Accents, highlights, CTAs, sun motif          |
| Sage Green   | `#4a7c59` | Secondary brand color, mid-tone applications  |
| Light Sage   | `#8fbc8f` | Highlights, badges, subtle accents            |

### 2.2 Secondary Colors

| Color           | Hex       | Usage                                          |
| --------------- | --------- | ---------------------------------------------- |
| Cream/Off-white | `#f5f1e6` | Backgrounds, cards, content areas              |
| Warm Gray       | `#6b6b6b` | Body text, secondary information               |
| Deep Brown      | `#3d2b1f` | Accents, heritage elements, typography accents |

### 2.3 Background Colors

| Mode       | Hex       | Usage                              |
| ---------- | --------- | ---------------------------------- |
| Light Mode | `#faf8f5` | Default background, warm off-white |
| Dark Mode  | `#0d1f12` | Deep forest green, dark theme base |

### 2.4 Color Rules

1. **Never** use pure black (`#000000`) for text. Use Warm Gray (`#6b6b6b`) or Deep Brown (`#3d2b1f`).
2. **Never** use pure white (`#ffffff`) for backgrounds. Use Cream (`#f5f1e6`) or Light Mode (`#faf8f5`).
3. **Never** introduce colors outside this palette for core UI elements.
4. Gold/Amber (`#c9a227`) is reserved for emphasis. It must not exceed 15% of any visual composition.
5. Forest Green (`#1a3a2a`) is the dominant color. It must appear in every official material.

## Article 3 — Typography

### 3.1 Headlines

- **Font:** Playfair Display (or equivalent elegant serif)
- **Weight:** 700 (Bold)
- **Style:** Uppercase for labels, Title Case for headlines
- **Usage:** Section headers, hero text, page titles

### 3.2 Body Text

- **Font:** Inter (or equivalent clean sans-serif)
- **Weight:** 400–500
- **Line Height:** 1.6
- **Usage:** Paragraphs, descriptions, UI text, navigation

### 3.3 Accent Text

- **Font:** Playfair Display (or equivalent serif)
- **Weight:** 400–500
- **Style:** Italic for quotes and emphasis
- **Usage:** Blockquotes, pull quotes, inspirational text

### 3.4 Typography Rules

1. **Never** use more than two font families in any composition.
2. **Never** use decorative, script, or display fonts for body text.
3. **Never** set body text below 14px (web) or 10pt (print).
4. **Never** set headlines in sans-serif. Headlines use Playfair Display.
5. Line height for body text is always 1.6. No exceptions.

## Article 4 — Logo Usage

### 4.1 Primary Logo

- Full wordmark with B-tree icon
- Tagline: "NATURE. KNOWLEDGE. HERITAGE."
- Use on light backgrounds (Cream or Light Mode)

### 4.2 Logo Variations

| Variation                | Context                                         | Background        |
| ------------------------ | ----------------------------------------------- | ----------------- |
| Full Wordmark            | Formal documents, website header, presentations | Light backgrounds |
| Icon Only (B-tree)       | Social profiles, favicons, app icons            | Any               |
| Dark Background Version  | Dark mode, video overlays, dark presentations   | Dark backgrounds  |
| Light Background Version | Standard use, documents, web                    | Light backgrounds |

### 4.3 Clear Space

Minimum clear space around the logo: the height of the "B" icon. No text, graphics, or other elements may intrude into this space.

### 4.4 Logo Rules

1. **Never** stretch, rotate, or distort the logo.
2. **Never** apply drop shadows, gradients, or effects to the logo.
3. **Never** place the logo on busy photographic backgrounds without sufficient contrast.
4. **Never** recreate the logo. Always use the canonical asset files.
5. **Never** modify the logo colors outside the approved palette.

## Article 5 — Voice and Tone

### 5.1 Brand Voice

The voice of Bhavya Foundation is:

- **Authoritative but approachable** — We speak with confidence, not arrogance.
- **Evidence-based, not hype-driven** — We cite data, not superlatives.
- **Rooted in tradition, focused on future** — We honor the past while building for tomorrow.
- **Service-oriented, not self-promotional** — We highlight impact, not ourselves.

### 5.2 Tone Variations

| Context                 | Tone                                   |
| ----------------------- | -------------------------------------- |
| Technical documentation | Precise, factual, minimal              |
| Social media            | Warm, engaging, evidence-backed        |
| Governance documents    | Formal, constitutional, authoritative  |
| Student communications  | Encouraging, clear, actionable         |
| Community outreach      | Respectful, empathetic, practical      |
| Press and media         | Professional, measured, impact-focused |

### 5.3 Language Rules

1. **Never** use marketing superlatives ("best," "leading," "revolutionary," "game-changing").
2. **Never** use jargon without explanation.
3. **Never** use passive voice when active voice is available.
4. **Never** claim impact without evidence. If we say "10K+ students empowered," we can prove it.
5. **Never** use hype words ("disrupt," "transform," "next-generation," "cutting-edge").

### 5.4 Key Messages

These messages are constitutional. They appear across all platforms:

1. "Building for Generations"
2. "Nature. Knowledge. Heritage."
3. "Evidence. Impact. Sustainability."
4. "Integrity. Excellence. Innovation. Trust."

## Article 6 — Visual Language

### 6.1 Photography Style

- **Real imagery over AI-generated templates.** Every photograph depicts real people, real places, real work.
- **Natural lighting preferred.** Avoid studio-lit, over-processed photography.
- **Document real impact.** Show forests being restored, students building, communities gathering.
- **No stock photography.** If we cannot photograph it, we do not show it.

### 6.2 Illustration Style

- **Minimal illustration.** When illustration is necessary, use clean line art or simple geometric shapes.
- **No gradient overload.** Maximum two gradients per composition.
- **No glassmorphism.** Translucent, frosted-glass effects are prohibited.
- **No 3D renders** for core brand materials. 3D is permitted only for technical diagrams.

### 6.3 Iconography

- Use simple, consistent icon sets (Lucide, Heroicons, or custom SVGs)
- Icons inherit brand colors. No rainbow icons, no gradient icons.
- Icon stroke width: 1.5px–2px for consistency.

### 6.4 Data Visualization

- Use brand palette for all charts and graphs.
- Gold/Amber for highlights and key data points.
- Forest Green for primary data series.
- Sage Green for secondary data series.
- Never use red/green color coding without additional indicators (accessibility).

## Article 7 — What We Never Do

These are constitutional prohibitions. Violating them is a brand violation.

### 7.1 Visual Prohibitions

1. **No gradient overload** — Maximum two gradients per composition.
2. **No glassmorphism** — Translucent, frosted-glass effects are prohibited.
3. **No stock illustrations** — Every image is real or purposefully designed.
4. **No AI-generated templates** for public-facing materials. AI assists creation; humans verify quality.
5. **No neon colors** — The palette is nature-inspired. Neon is excluded.
6. **No comic sans, papyrus, or decorative fonts** — Typography is elegant and readable.
7. **No auto-playing video** — Users control playback.
8. **No pop-ups or interstitial modals** — Content is accessible without obstruction.

### 7.2 Communication Prohibitions

1. **No marketing superlatives** — No "best," "leading," "revolutionary."
2. **No vague impact claims** — Every claim has evidence.
3. **No guilt-based messaging** — We inspire, not manipulate.
4. **No urgency tactics** — "Limited time," "act now," "last chance" are excluded.
5. **No competitor naming** — We do not mention competitors by name.

### 7.3 Technical Prohibitions

1. **No inline design tokens** — All tokens come from the design system.
2. **No hardcoded colors** — Every color references the brand palette.
3. **No custom foundational components** — All UI components come from @bhavya/platform-ui.
4. **No animation without purpose** — Animation serves function, not decoration.

## Article 9 — Design System Integration

### 9.1 Canonical UI Layer

The brand is implemented through `@bhavya/platform-ui`. No application creates custom foundational components. The design system is the single source of truth for visual implementation.

### 9.2 Design Tokens

All spacing, colors, typography, and animations come from the design system. No inline tokens. No hardcoded values.

### 9.3 Component Evolution

Components evolve only after research and approval through the Bhavya Evolution Engine (BEE 2.0). No component is added, modified, or removed without following the evolution protocol.

### 9.4 Versioning

Every component is versioned with documentation. Brand changes are tracked through constitutional amendment, not through code commits alone.

## Article 11 — Amendment Process

This Brand Constitution may only be amended through:

1. A written proposal with rationale and evidence
2. Review by the governance board
3. A 30-day comment period
4. Approval by the institution builder designated for brand governance
5. Publication with version bump and changelog entry

Color palette changes require additional review by the design system maintainer. Typography changes require accessibility audit.

---

## Article 12 — Enforcement

Brand compliance is enforced through:

1. **Pre-merge review** — All public-facing materials reviewed against this Constitution
2. **Design system validation** — Automated checks for color, typography, and component usage
3. **Quarterly brand audit** — Review of all active materials for compliance
4. **Constitutional citation** — Brand violations are cited with document number and article
