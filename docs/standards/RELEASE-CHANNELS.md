# Release Channels

**Version:** 1.0
**Status:** Active
**Last Updated:** 2026-07-28

## Channels

### LTS (Long-Term Support)

- **Version:** v3.x
- **Support:** Security patches, critical bug fixes
- **Duration:** 2 years from initial release
- **Use case:** Production systems that need stability

### Stable

- **Version:** v3.x.y
- **Support:** Bug fixes, security patches, new features
- **Duration:** Until next minor version
- **Use case:** Recommended for most users

### Preview

- **Version:** v4.0-beta
- **Support:** Bug fixes only
- **Duration:** Until v4.0 stable
- **Use case:** Early adopters, testing next major

### Experimental

- **Version:** feature/*
- **Support:** None
- **Duration:** Indefinite
- **Use case:** Exploration, prototyping

## Promotion Path

```
Experimental -> Preview -> Stable -> LTS
```
