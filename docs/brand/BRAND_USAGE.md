# Bhavya Foundation — Brand Usage Guidelines

**Last updated:** 2026-08-10

## Logo Usage

### Primary Logo

- **File:** `apps/ai-institute/public/brand/logo.svg`
- **Use on:** Light backgrounds (Warm Ivory #F7F4EC)
- **Minimum size:** 120px width
- **Clear space:** Minimum height of the "B" icon on all sides

### Icon Only

- **File:** `apps/ai-institute/public/brand/icon.svg`
- **Use for:** Social profiles, favicons, app icons
- **Minimum size:** 32px

### Dark Background Variant

- Use white/light version of logo on dark forest backgrounds
- Ensure sufficient contrast ratio (minimum 4.5:1)

## Color Usage

### Primary Application

| Context | Color | Hex |
|---------|-------|-----|
| Primary buttons | Forest Green | #0e382e |
| Backgrounds | Warm Ivory | #f7f4ec |
| Accents, highlights | Heritage Gold | #d4af37 |
| Secondary elements | Sage | #8a9a8b |
| Nature elements | Earth | #6a7c52 |

### Anti-Patterns

**NEVER use:**
- Gray placeholder mountains
- Generic black/white cards
- Random gradients/blobs/particles
- Purple/blue AI colors
- Neon cyberpunk aesthetics
- Generic dashboard layouts

**ALWAYS use:**
- Bhavya brand colors from token system
- Editorial typography (Playfair Display + Inter)
- Purposeful motion with meaning
- SVG illustrations from brand assets

## Typography Usage

### Headlines

- **Font:** Playfair Display
- **Weight:** 700 (Bold)
- **Style:** Title Case for headlines, UPPERCASE for labels
- **Usage:** Hero sections, section titles, card headers

### Body Text

- **Font:** Inter
- **Weight:** 400-500
- **Line height:** 1.6
- **Usage:** Paragraphs, descriptions, UI text

### Accent Text

- **Font:** Playfair Display
- **Weight:** 400-500
- **Style:** Italic for quotes and emphasis
- **Usage:** Testimonials, pull quotes, decorative text

## Voice and Tone

### Brand Voice

- **Authoritative but approachable**
- **Evidence-based, not hype-driven**
- **Rooted in tradition, focused on future**
- **Service-oriented, not self-promotional**

### Key Messages

1. "Building for Generations"
2. "Nature. Knowledge. Heritage."
3. "Evidence. Impact. Sustainability."
4. "Integrity. Excellence. Innovation. Trust."
