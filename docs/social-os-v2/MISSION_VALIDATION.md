# Social OS v2 — Mission Validation

## Mission Alignment Check

Every publication is validated against Bhavya Foundation's mission:

> "Nature. Knowledge. Heritage."

### Validation Criteria

1. **Mission Terms** — Content must include at least one mission-related term: education, learning, knowledge, community, nature, heritage
2. **Brand Presence** — Content must reference "Bhavya" or "Bhavya Foundation"
3. **Ethical Compliance** — Content must not contain sensitive topics (political, religious, controversial, discrimination, hate)
4. **Source Traceability** — Content must trace back to a Knowledge Package or Constitutional citation
5. **Child Protection** — Content must comply with child safeguarding policies
6. **Environmental Awareness** — Content should demonstrate environmental awareness (advisory)

### Scoring

- **Passed** — All error-level checks pass
- **Score** — Percentage of checks passed (0-100)
- **Citation** — Required constitutional reference

### Enforcement

- Publications with errors are blocked from publishing
- Publications with warnings require human review
- Publications with only info checks pass automatically
