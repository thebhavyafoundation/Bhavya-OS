## Key Transitions

| From             | To               | Trigger               | Animation            |
| ---------------- | ---------------- | --------------------- | -------------------- |
| Landing          | Path Explorer    | "Explore Paths" click | Slide right          |
| Path Explorer    | Skill Assessment | "Take Assessment"     | Fade in              |
| Skill Assessment | Roadmap          | Assessment complete   | Reveal (graph build) |
| Roadmap          | Dashboard        | "Start Learning"      | Fade + scale         |
| Dashboard        | Course           | "Continue" click      | Slide up             |
| Course           | Lesson           | Module click          | Slide right          |
| Lesson           | Lab              | "Start Lab"           | Fade + expand        |
| Lab              | Quiz             | Lab submitted         | Slide up             |
| Quiz             | Next Lesson      | Quiz passed           | Confetti + slide     |
| Lesson           | Project          | Course complete       | Fade + celebration   |
| Project          | Review           | "Submit"              | Slide up             |
| Review           | Capstone         | Project approved      | Fade + badge         |
| Capstone         | Portfolio        | Capstone complete     | Auto-generate        |
| Portfolio        | Certification    | Requirements met      | Badge animation      |

## Accessibility Requirements

| Requirement         | Implementation              |
| ------------------- | --------------------------- |
| Screen reader       | Semantic HTML, ARIA labels  |
| Keyboard navigation | Tab order, focus management |
| Color contrast      | WCAG 2.1 AA (4.5:1 minimum) |
| Reduced motion      | prefers-reduced-motion      |
| Text scaling        | 200% without breaking       |
| Captions            | All videos captioned        |
| Alt text            | All images described        |
| Focus indicators    | Visible focus rings         |
