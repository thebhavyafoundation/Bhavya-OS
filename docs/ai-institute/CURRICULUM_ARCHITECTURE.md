# Curriculum Architecture

Eight levels from foundation to entrepreneurship.

---

## Level Structure

```
1. Foundation
   ↓
2. Core AI
   ↓
3. Agent Engineering
   ↓
4. Automation
   ↓
5. AI Product Development
   ↓
6. Open Source Contribution
   ↓
7. Research
   ↓
8. Entrepreneurship
```

Each level builds on the previous. Students can specialize after Foundation.

---

## Level 1: Foundation

**Duration:** 4-6 weeks
**Difficulty:** Beginner
**Prerequisites:** None

### Objectives

- Understand what AI is and isn't
- Know how LLMs work at a conceptual level
- Write effective prompts
- Build simple AI-powered applications
- Use AI tools responsibly

### Skills

- AI literacy
- Prompt engineering basics
- API integration basics
- Problem decomposition
- Debugging with AI

### Projects

- Personal AI assistant
- Domain-specific chatbot
- Simple automation script

### Prerequisites

- Basic computer literacy
- Willingness to learn

### Expected Outcomes

- Can explain AI to a non-technical person
- Can build a simple AI application
- Can use AI tools for productivity
- Understands AI limitations and ethics

---

## Level 2: Core AI

**Duration:** 6-8 weeks
**Difficulty:** Intermediate
**Prerequisites:** Foundation

### Objectives

- Master prompt engineering
- Understand agent architectures
- Build multi-turn AI systems
- Integrate AI with external tools
- Design AI workflows

### Skills

- Advanced prompt engineering
- Chain-of-thought reasoning
- Tool use and function calling
- Memory and context management
- Evaluation and testing

### Projects

- Multi-tool agent
- Knowledge base question-answering system
- Code review assistant

### Prerequisites

- Foundation certificate
- Programming proficiency (any language)
- Basic API knowledge

### Expected Outcomes

- Can design complex AI systems
- Can evaluate AI output quality
- Can debug AI behavior
- Can architect agent workflows

---

## Level 3: Agent Engineering

**Difficulty:** Intermediate-Advanced
**Prerequisites:** Core AI

- Design agent communication

- Optimize agent performance

- Agent framework mastery (LangGraph, CrewAI)
- MCP server development
- Tool orchestration
- State management
- Error recovery

### Projects

- Personal AI operating system
- Multi-agent collaboration system
- Custom MCP server

### Prerequisites

- Core AI certificate
- Programming proficiency (TypeScript/Python)
- Git workflow knowledge

### Expected Outcomes

- Can build production agents
- Can design tool ecosystems
- Can architect multi-agent systems
- Can optimize for cost and performance

---

## Specialization Tracks

After Foundation, students can specialize:

### Track A: AI Engineering

Levels: Core AI → Agent Engineering → Research
Focus: Building AI systems

### Track B: AI Product

Levels: Core AI → Automation → AI Product Development
Focus: Building AI products

### Track C: AI Operations

Levels: Core AI → Automation → Open Source Contribution
Focus: Running AI systems

### Track D: AI Research

Levels: Core AI → Agent Engineering → Research → Entrepreneurship
Focus: Advancing AI knowledge

### Track E: AI Education

Levels: Core AI → Agent Engineering → Open Source Contribution → Research
Focus: Teaching AI
