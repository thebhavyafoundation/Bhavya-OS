# Learning Journey

Complete student journey from visitor to mentor.

---

## Journey Stages

### 1. Visitor

**State:** Curious but uncertain.

**Experience:**

- Lands on AI Institute website
- Reads about the program
- Sees student testimonials
- Explores curriculum overview

**Outcome:** Decides to assess readiness.

**Touchpoints:**

- Website (Website OS)
- Social media
- Referrals
- Open source contributions

---

### 2. AI Readiness Assessment

**State:** Evaluating starting point.

**Experience:**

- Takes a 15-minute assessment
- Questions cover: programming basics, math concepts, problem-solving, AI awareness
- Not pass/fail — determines placement
- Receives personalized report

**Outcome:** Knows where to start.

**Assessment dimensions:**

- Programming proficiency (0-10)
- Mathematical foundation (0-10)
- Problem-solving approach (0-10)
- AI familiarity (0-10)
- Learning style (visual, reading, hands-on)

---

### 3. Personalized Roadmap

**State:** Has a plan.

**Experience:**

- Sees customized learning path
- Understands time commitment
- Knows what they'll achieve
- Can adjust based on goals

**Outcome:** Enrolls in Foundation Course.

**Roadmap elements:**

- Recommended courses
- Estimated timeline
- Skill milestones
- Project previews
- Career paths

---

### 4. Foundation Course

**State:** Building fundamentals.

**Experience:**

- 4-6 weeks of structured learning
- Lessons with hands-on labs
- AI mentor for questions
- Community discussion access
- Weekly knowledge checks

**Outcome:** Solid foundation in AI concepts.

**Modules:**

1. What is AI? (History, types, applications)
2. How LLMs Work (Tokens, context, limitations)
3. Prompt Engineering Fundamentals
4. Building with AI APIs
5. Introduction to Agents
6. Your First AI Project

**Assessments:**

- Knowledge quiz (end of each module)
- Prompt challenge (Module 3)
- Mini project (Module 6)

---

### 5. Labs

**State:** Getting hands-on.

**Experience:**

- Guided practical exercises
- Real tools and environments
- Immediate feedback
- Progressive difficulty
- AI hints when stuck

**Outcome:** Practical skills in specific tools.

**Lab tracks:**

1. Prompt Engineering Lab
2. API Integration Lab
3. Agent Building Lab
4. MCP Server Lab
5. Browser Automation Lab
6. Knowledge Studio Lab
7. GitHub OS Lab

---

### 6. Mini Projects

**State:** Building real things.

**Experience:**

- Apply skills to real problems
- Choose from project menu or propose own
- Get mentor feedback
- Present to peers
- Add to portfolio

**Outcome:** Portfolio pieces demonstrating skills.

**Project examples:**

- Build a chatbot for a specific domain
- Automate a workflow using AI
- Create a knowledge base from documents
- Build a code review assistant
- Design an AI-powered tool

---

### 7. Knowledge Checks

**State:** Verifying understanding.

**Experience:**

- Spaced repetition quizzes
- Prompt challenges
- Code reviews
- Architecture discussions
- Not just right/wrong — explanations

**Outcome:** Confident in knowledge.

**Check types:**

- Quick checks (5 min) — after each lesson
- Module reviews (30 min) — after each module
- Track assessments (2 hours) — after each track
- Course comprehensive (half day) — after each course

---

### 8. Capstone

**State:** Proving mastery.

**Experience:**

- Multi-week project
- Real-world complexity
- Mentor guidance
- Peer collaboration
- Public presentation
- Portfolio integration

**Outcome:** Comprehensive proof of competency.

**Capstone requirements:**

- Solves a real problem
- Uses multiple skills
- Has working code
- Includes documentation
- Passes mentor review
- Presented to community

---

### 9. Portfolio

**State:** Showcasing work.

**Experience:**

- Curated collection of best work
- Each item has evidence and reflection
- Shareable URL
- Verified by Bhavya Foundation
- Includes contributions to open source

**Outcome:** Career-ready portfolio.

**Portfolio items:**

- Projects (from labs and capstones)
- Contributions (to open source)
- Reflections (learning journey)
- Certifications (competency proof)
- Skills (demonstrated abilities)

---

### 10. Mentor Review

**State:** Expert validation.

**Experience:**

- One-on-one with industry expert
- Reviews portfolio
- Discusses career goals
- Provides personalized guidance
- Identifies growth areas

**Outcome:** Career direction and validation.

**Review dimensions:**

- Technical competency
- Problem-solving approach
- Communication skills
- Growth potential
- Career readiness

---

### 11. Certification

**State:** Formal recognition.

**Experience:**

- Receives verifiable certificate
- Blockchain-anchored (optional)
- Shareable on LinkedIn
- Includes specific competencies
- Has expiry date for relevance

**Outcome:** Industry-recognized credential.

**Certificate types:**

- Foundation Certificate (completing foundation)
- Specialist Certificate (mastering a domain)
- Professional Certificate (completing full path)
- Mentor Certificate (teaching others)

---

### 12. Contributor Path

**State:** Giving back.

**Experience:**

- Contributes to open source projects
- Improves curriculum content
- Mentors newer students
- Writes articles or creates content
- Builds community tools

**Outcome:** Active member of Bhavya community.

**Contribution types:**

- Code contributions
- Content improvements
- Bug reports
- Documentation
- Community support
- Event organization

---

### 13. Mentor Path

**State:** Teaching others.

**Experience:**

- Applies to become mentor
- Goes through mentor training
- Assigned students
- Conducts office hours
- Reviews projects
- Guides learning

**Outcome:** Qualified AI Institute mentor.

**Mentor requirements:**

- Completed Professional Certificate
- 6 months industry experience
- Mentor training completion
- Peer recommendation
- Ongoing professional development

---
