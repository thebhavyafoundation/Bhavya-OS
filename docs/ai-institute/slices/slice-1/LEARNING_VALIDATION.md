# Learning Validation — Slice 1

## Assessment Design

- **8 questions** covering programming, logic, AI basics, math, experience, time, coding
- **Multiple-choice** with clear correct answers
- **Scoring system** — Beginner (0-40), Intermediate (41-70), Advanced (71-100)
- **Personalized roadmap** based on score

## Lesson Structure

- **5 tabs** — Reading, Examples, Exercises, Reflect, Notes
- **Learning objectives** clearly stated
- **Key concepts** with definitions
- **Knowledge packages** for deeper learning
- **Repository references** for real-world examples

## Lab Design

- **4 progressive tasks** — From simple to complex
- **AI feedback simulation** — Realistic responses
- **Hint system** — Scaffolded support
- **Rubric** — Clear evaluation criteria

## Knowledge Check

- **4 questions** — MCQ and short-answer
- **Immediate feedback** — Learn from mistakes
- **Score tracking** — Progress measurement

## Project

- **Build AI assistant** — Real-world application
- **Code editor** — Write actual code
- **AI review simulation** — Professional feedback
- **Badge award** — Achievement recognition

## Educational Principles Applied

1. **Scaffolded learning** — Build from basics to complex
2. **Active practice** — Do, not just read
3. **Immediate feedback** — Learn from mistakes
4. **Real-world application** — Build real things
5. **Achievement recognition** — Badges for motivation
