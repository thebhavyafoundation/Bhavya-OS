# Known Limitations — Slice 1

## Technical

1. **No backend** — All data is static, feedback is simulated
2. **No authentication** — Progress is local to browser only
3. **No persistence** — Clear browser data = lose progress
4. **No real AI** — Feedback is pre-written, not generated
5. **No real API** — All API calls are simulated

## Educational

1. **Limited content** — Only 3 lessons in foundation
2. **No mentor feedback** — All feedback is automated
3. **No peer interaction** — No collaboration features
4. **No adaptive learning** — Fixed path for all students
5. **No real projects** — Project is simplified version

## Platform

1. **No progress sync** — Can't resume across devices
2. **No admin view** — No instructor dashboard
3. **No analytics** — No learning analytics
4. **No certificates** — Only badges for now
5. **No community** — No discussion forums

## Design

1. **Desktop-first** — Not fully responsive yet
2. **No dark/light toggle** — Dark mode only
3. **Limited animations** — Basic fade-in only
4. **No accessibility audit** — Needs WCAG review
5. **No mobile optimization** — Basic responsive only

- Backend integration
- Real authentication
- Persistent storage
- Real AI feedback
- More content
- Mentor features
- Peer interaction
- Adaptive learning
