# Educational Value — Slice 1

## What Students Learn

### Lesson 1: What is AI?

- Definition of artificial intelligence
- How AI models are trained
- Role of data in AI
- Real-world examples

### Lesson 2: How AI Learns

- Training data and patterns
- Model parameters
- Fine-tuning process
- Practical examples

### Lesson 3: Talking to AI

- API basics
- Prompt engineering
- Communication patterns
- Hands-on practice

### Lab: Prompt Engineering

- Write effective prompts
- Iterate and improve
- Handle edge cases
- Build real prompts

### Knowledge Check

- Test understanding
- Identify gaps
- Reinforce learning

### Mini Project: AI Assistant

- Build real application
- Apply all concepts
- Get professional feedback
- Earn recognition

## Learning Outcomes

By end of Slice 1, students can:

1. Explain what AI is and how it works
2. Describe how AI models learn from data
3. Write effective prompts for AI models
4. Build a simple AI-powered application
5. Understand API communication basics

## Pedagogical Approach

- **Project-based learning** — Build real things
- **Scaffolded complexity** — Start simple, build up
- **Active practice** — Do, not just read
- **Immediate feedback** — Learn from mistakes
- **Achievement recognition** — Badges for motivation
