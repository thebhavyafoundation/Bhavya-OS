# Feedback System

## From Scores to Coaching

### Before (Slice 2.1)

```
"Your prompt scored 20/100"
"Your prompt scored 60/100"
"Your prompt scored 80/100"
```

### After (Slice 2.2)

```
"The AI gave a basic response. What's missing?"
"The AI gave a more detailed response. What changed?"
"The AI gave an excellent response. You nailed it!"
```

## Feedback Levels

### Level 1: Observation

When the student does something, the mentor observes it.

- "You wrote a short message"
- "You added who this is for"
- "You requested examples"

### Level 2: Question

The mentor asks what the student notices.

- "What do you notice about the AI's response?"
- "How did the response change?"
- "What do you think caused that difference?"

### Level 3: Suggestion

When the student is stuck, the mentor suggests.

- "What if you tried adding who this is for?"
- "What if you asked for examples?"
- "What if you were more specific?"

### Level 4: Celebration

When the student improves, the mentor celebrates.

- "That's a great improvement!"
- "You just got a much better response"
- "You're learning to communicate with AI"

## Feedback Rules

### 1. Be Specific

Don't say "Your prompt is bad." Say "Your message is short. What if you added who this is for?"

### 2. Be Positive

Don't say "That's wrong." Say "That's a good start. What would make it even better?"

### 3. Be Helpful

Don't say "Try again." Say "What if you added an example of what you want?"

### 4. Be Encouraging

Don't say "You failed." Say "You're learning. Each attempt teaches you something."

### 5. Be Honest

Don't say "That's perfect" when it's not. Say "That's better! The AI gave you a more detailed response."

## Feedback Examples

### First Attempt

- Observation: "You wrote a message to AI"
- Question: "What did the AI respond with?"
- Suggestion: "What if you told the AI who this is for?"

### After Improvement

- Observation: "You added more detail"
- Question: "How did the AI's response change?"
- Celebration: "The AI gave you a much better response! That's because you were more specific."

### When Stuck

- Observation: "It seems like you're not sure what to try"
- Suggestion: "What if you added 'for a 12-year-old' to your message?"
- Encouragement: "Try that and see what happens"
