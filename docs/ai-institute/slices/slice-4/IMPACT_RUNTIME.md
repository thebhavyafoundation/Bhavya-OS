# Impact Runtime

## Overview

The Impact Runtime manages the lifecycle of real-world problem solving. It ensures every project originates from a real need and creates measurable impact.

## Architecture

```
Impact Runtime
├── ImpactEngine        — Problem tracking, research, canvas, evidence
├── Problem Library     — 8 real-world problems across 8 categories
└── Core Types          — Problem, Research, SolutionCanvas, ImpactEvidence
```

## Core Concepts

### Problem

A real-world problem that needs solving. Contains:

- Statement
- Stakeholders
- Background
- Constraints
- Success criteria
- Knowledge packages
- Related repositories
- Suggested AI techniques
- Open-source opportunity

### Research

Evidence-based investigation before building:

- Articles
- Knowledge packages
- Repositories
- Documentation
- Datasets
- MCP capabilities
- AI tools
- Insights

### Solution Canvas

Definition before implementation:

- Problem
- Users
- Goals
- Non-goals
- Constraints
- Risks
- AI opportunities
- Ethics
- Success metrics
- Design decisions

### Impact Evidence

Proof of impact:

- Who benefits
- What changed
- What remains unsolved
- Open-source potential
- Extensibility
- Deployment readiness

### Open Source Path

How the project contributes to the community:

- Contribution type
- Target repository
- Description
- Skills needed
- Difficulty
- Estimated effort

```
Problem Selection → Research → Solution Canvas → Build → Evidence → Impact → Open Source
```
