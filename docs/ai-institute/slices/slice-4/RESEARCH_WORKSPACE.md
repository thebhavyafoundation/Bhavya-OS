# Research Workspace

## Overview

Before building, students research the problem. Research is evidence-based and linked to the project.

## Research Categories

### Articles

Academic papers, blog posts, news articles about the problem.

### Knowledge Packages

AI Institute learning resources related to the problem.

### Repositories

GitHub repositories that address similar problems.

### Documentation

Official documentation for tools and APIs.

### Datasets

Data sources that could be used in the solution.

### MCP Capabilities

MCP servers that could help solve the problem.

### AI Tools

AI tools and services that could be leveraged.

## Research Process

1. **Gather** — Collect relevant resources
2. **Analyze** — Understand what others have done
3. **Synthesize** — Extract insights
4. **Document** — Record findings linked to the project

## Research Quality

Good research:

- Includes multiple sources
- References existing solutions
- Identifies gaps
- Informs design decisions
- Is documented for others

## Research Output

Research produces:

- List of relevant resources
- Key insights
- Gaps in existing solutions
- Informed design decisions
