# Milestone System

## Overview

Milestones are the phases of a project. Each milestone produces evidence of learning.

## Milestone Flow

```
Locked → Available → In-Progress → Completed
```

### Locked

The milestone is not yet accessible. Previous milestone must be completed first.

### Available

The milestone is ready to be worked on. Tasks are visible.

### In-Progress

At least one task has been started. Milestone is being actively worked on.

### Completed

All tasks are completed. Reflection has been submitted. Next milestone is unlocked.

## First Project Milestones

### Milestone 1: Understand the Problem

- Choose a use case
- Define the user
- Write the problem statement

### Milestone 2: Design the Solution

- Write the system message
- Design conversation flows
- Define capabilities

### Milestone 3: Build

- Set up project structure
- Implement the assistant
- Build the interface
- Test with real conversations

### Milestone 4: Document

- Write the README
- Document the architecture
- Add knowledge package references

### Milestone 5: Reflect

- Write learning journal
- Identify improvements
- Plan next steps

### Milestone 6: Publish

- Create GitHub repository
- Push code
- Generate portfolio entry

## Evidence

Every completed milestone produces evidence:

- Task outputs
- Reflection content
- AI coach interactions
- Knowledge package references

## Progress Tracking

Progress is measured by completed milestones:

- 0/6 = Not started
- 1/6 = 17%
- 3/6 = 50%
- 6/6 = Completed
