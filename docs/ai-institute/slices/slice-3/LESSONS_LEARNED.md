# Lessons Learned

## What We Built

### Project Runtime

A reusable engine for project-based learning. It makes projects first-class citizens.

### First Flagship Project

"Build Your First AI Assistant" with 6 milestones and 18 tasks.

### Project Workspace

A single page with 5 tabs: Overview, Milestones, AI Coach, Learning Journal, Portfolio.

### Portfolio Export

Export as JSON, Markdown, LinkedIn post, or GitHub repository structure.

## What We Learned

### 1. Projects Are the Curriculum

Lessons support projects, not the other way around. The project is where learning happens.

### 2. Milestones Create Momentum

Breaking a project into milestones makes it manageable. Each milestone produces evidence.

### 3. AI Coaching Scales

The AI Project Coach can guide thousands of students simultaneously. It doesn't replace human mentors, but it makes mentorship accessible.

### 4. Reflection Is Evidence

Reflections are not just exercises. They're evidence of learning. They become part of the portfolio.

### 5. Portfolio Is the Output

The portfolio is what the student leaves with. It must be shareable, impressive, and useful.

## What Would We Do Differently

### 1. Start with Projects, Not Lessons

If we started over, we'd build the project first, then create lessons to support it.

### 2. Make the AI Coach More Prominent

The coach is hidden in a tab. It should be more visible, more integrated.

### 3. Add Real AI Earlier

The mock provider works, but real AI would make the experience more compelling.

### 4. Add Community Earlier

Students should see what other students are building. This creates motivation.

## What's Next

### 1. More Projects

- Prompt Engineering Studio
- AI Agent Builder

### 2. Real AI Integration

Replace MockProvider with real AI providers (OpenAI, Anthropic, OpenRouter).

## The Learning Flywheel

```
Lesson → Project → Open Source → Mentorship → Teaching → Learning
```

Every completed lesson leads to a project. Every completed project leads to open-source contribution. Every contribution leads to mentorship. Every mentorship leads to teaching. Teaching is the highest form of learning.

That's the flywheel Bhavya Foundation should optimize for.
