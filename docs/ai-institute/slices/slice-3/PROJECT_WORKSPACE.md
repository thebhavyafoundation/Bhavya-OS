# Project Workspace

## Overview

The project workspace is where students spend most of their time. It's a single page with 5 tabs.

## Tabs

### 1. Overview

Shows:

- Project objectives
- Milestones with status
- Knowledge packages

### 2. Milestones

Shows:

- Current milestone details
- Tasks within the milestone
- Task completion interface
- Evidence capture

### 3. AI Coach

Shows:

- AI coach response
- Context-aware coaching
- "Ask Coach for Advice" button

### 4. Learning Journal

Shows:

- Reflection form for current milestone
- 5 reflection questions
- Save reflection button

### 5. Portfolio

Shows:

- Generate portfolio button
- Export as Markdown
- Copy to clipboard
- Download as Markdown
- GitHub repository generation

## Navigation

- Back to Projects (top left)
- Progress bar (top right)
- Tab navigation (below header)

## Design Rules

1. **One milestone at a time** — Don't overwhelm with all milestones
2. **Task completion is obvious** — Clear button, clear output area
3. **Reflection is mandatory** — Must reflect before completing milestone
4. **AI coach is visible** — Always accessible, never hidden
5. **Portfolio is shareable** — One-click export
