# Experience Flow

## Before → After

### Before (Slice 1)

```
Landing → Assessment → Dashboard → Lesson (5 tabs) → Lab → Check → Project
```

### After (Slice 2.1)

```
Welcome → First Prompt → Experiment → Reflect → Build → Portfolio → Done
```

## Detailed Flow

### Screen 1: Welcome (30 seconds)

- AI mentor introduces itself
- Explains what will happen
- Lists 5 steps
- Shows what will be built
- No reading — just context

### Screen 2: First Prompt (immediate)

- Student writes a prompt
- No prerequisite reading
- No barriers to entry
- AI responds in real-time

### Screen 3: Experiment

- AI output displayed
- Student can see what happened
- Options to retry or continue
- Observations shown

### Screen 4: Reflect (mandatory)

- Must answer before continuing
- Questions: What surprised you? What would you do differently?
- Rate experience (emoji)
- Takes 2-3 minutes

### Screen 5: Build

- Write improved prompt
- Checklist shows progress
- Can go back to experiment
- Creates something tangible

### Screen 6: Portfolio

- Artifact generated automatically
- Title, summary, skills
- Export options (copy, download)
- Evidence of learning

### Screen 7: Done

- Achievement unlocked
- Next lesson available
- Confidence built
