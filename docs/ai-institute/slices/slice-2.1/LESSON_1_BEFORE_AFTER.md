# Lesson 1: Before vs After

## Structure Comparison

### Before (Slice 1)

```
Header
├── Title
├── Description
├── Objectives
├── Prerequisites
Tabs
├── Reading (70% of content)
├── Examples (code samples)
├── Exercises (guided)
├── Reflect (optional)
└── Notes (freeform)
Footer
└── Mark as Complete
```

### After (Slice 2.1)

```
Screen 1: Welcome
├── AI Mentor Introduction
├── What You'll Do (5 steps)
└── What You'll Build

Screen 2: First Prompt
├── AIPlayground Component
├── Live AI Interaction
└── Immediate Feedback

Screen 3: Reflect
├── What surprised you?
├── What would you do differently?
└── Rate experience

Screen 4: Build
├── Write improved prompt
├── Checklist
└── Progress feedback

Screen 5: Portfolio
├── Artifact Summary
├── Skills Demonstrated
└── Export Options

Screen 6: Done
├── Achievement
└── Next Lesson
```

## Content Distribution

### Before

- Reading: 70%
- Examples: 15%
- Exercises: 10%
- Reflect: 5%

### After

- Reading: 10%
- Interaction: 60%
- Reflection: 15%
- Build: 15%

## User Experience

### Before

1. Read about AI
2. Look at examples
3. Complete exercises
4. Maybe reflect
5. Mark complete

### After

1. Meet AI mentor
2. Write prompt
3. See AI respond
4. Reflect on experience
5. Improve prompt
6. Generate artifact
7. Feel accomplished

## Key Differences

| Aspect               | Before      | After        |
| -------------------- | ----------- | ------------ |
| Primary activity     | Reading     | Doing        |
| AI interaction       | None        | Real-time    |
| Reflection           | Optional    | Mandatory    |
| Output               | Completion  | Artifact     |
| Emotion              | Passive     | Active       |
| Time to first action | 10+ minutes | < 60 seconds |
| Confidence building  | Low         | High         |

## Why This Works

1. **Immediate engagement** — Student does something in 60 seconds
2. **Active learning** — Student creates, not consumes
3. **Real feedback** — AI responds to student's actual input
4. **Reflection required** — Student thinks about what happened
5. **Tangible output** — Student has something to show
6. **Confidence built** — Student feels capable
