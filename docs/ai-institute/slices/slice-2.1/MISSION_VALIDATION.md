# Mission Validation

## Core Question

"After 30 minutes, does the student have more confidence in building with AI than when they started?"

## Evidence

### Before (Slice 1)

- Student reads about AI
- Student takes a quiz
- Student completes a lab (guided)
- **Result:** Student knows about AI but hasn't built anything

### After (Slice 2.1)

- Student writes a prompt (within 60 seconds)
- Student sees AI respond
- Student improves the prompt
- Student reflects on what happened
- Student creates a portfolio artifact
- **Result:** Student has built something with AI

## Validation Criteria

| Criterion              | Before      | After        |
| ---------------------- | ----------- | ------------ |
| First interaction      | 10+ minutes | < 60 seconds |
| Reading percentage     | 70%         | 30%          |
| Interaction percentage | 30%         | 70%          |
| Portfolio artifact     | None        | Generated    |
| Confidence             | Low         | High         |
| Agency                 | Passive     | Active       |

## Student Quotes (Expected)

### Before

- "I learned about AI"
- "I finished the lesson"
- "I know what AI is"

### After

- "I built something with AI"
- "I can use AI to explain things"
- "I want to try more"

## Success Metrics

1. First AI interaction within 60 seconds
2. Student writes a prompt before reading anything
3. Reflection is mandatory
4. Portfolio artifact generated
5. Student feels "I did something" not "I read something"
