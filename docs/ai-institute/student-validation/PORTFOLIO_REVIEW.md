# Portfolio Review

## What the Student Gets

### Artifact Content

```
Title: AI Explanation Prompt v1
Summary: A prompt template designed to explain artificial intelligence
         to a 12-year-old, refined through experimentation and reflection.
Skills: Prompt Engineering, Iteration, Reflection
Your Improved Prompt: [student's text]
```

### Export Options

- Copy to Clipboard
- Download as JSON

---

## Evaluation Criteria

### Would the student proudly show this on LinkedIn?

**NO.** A text prompt is not portfolio-worthy. It's a sentence or two that anyone could write.

### Would it impress a recruiter?

**NO.** Recruiters want to see what you BUILT, not what you TYPED. A prompt is input, not output.

### Would it help in a GitHub portfolio?

**NO.** A JSON file with a prompt is not meaningful code or a meaningful project.

### Would it be useful six months later?

**NO.** The student will forget which prompt they wrote and why.

---

## What's Missing

### 1. The AI's Response to the Improved Prompt

The student never sees if their improved prompt actually works better. This is the critical payoff that's missing.

### 2. Before/After Comparison

The student should see:

- First attempt → AI response
- Improved attempt → AI response
- Side-by-side comparison

### 3. Actual Output

The portfolio should include what the AI PRODUCED, not just what the student TYPED.

### 4. Learning Journey

The portfolio should show the student's progression:

- Attempt 1: Score 20/100, AI said "I need more information"
- Attempt 2: Score 60/100, AI gave a better response
- Attempt 3: Score 80/100, AI gave an excellent response

### 5. Reflection Content

The student's reflections should be included in the artifact.

---

## What Would Make This Portfolio-Worthy

### Option A: Show the Full Journey

```
Before: "Explain AI to a 12 year old"
After: "Explain AI to a 12-year-old who loves video games using 3 examples
        from games they play. Keep it under 100 words."

AI Response to Before: [weak response]
AI Response to After: [strong response]

What I Learned: Specificity matters. The more context I give, the better
the response.
```

### Option B: Generate a Shareable Artifact

Instead of just the prompt, generate:

- A blog post explaining what the student learned
- A tweet-length summary
- A GitHub README section

### Option C: Create a Reusable Template

Instead of a one-time prompt, create a template the student can reuse:

```
My Prompt Template for Explaining Complex Topics:
"Explain [TOPIC] to [AUDIENCE] using [FORMAT]. Keep it under [LENGTH].
Include [NUMBER] [EXAMPLES/ANALOGIES/STEPS]."
```

---

## Recommendations

### 1. Show AI Response to Improved Prompt

After the student writes their improved prompt, show them the AI's response to it. This is the critical payoff.

### 2. Include Before/After Comparison

Show the first attempt and the improved attempt side-by-side.

### 3. Include Reflection in Artifact

The student's reflections should be part of the portfolio artifact.

### 4. Make It Shareable

Add a "Share on LinkedIn" button that generates a post like:
"Just completed my first AI experiment at Bhavya AI Institute!
I learned that specificity matters when prompting AI.
Before: [weak prompt]
After: [strong prompt]
The difference is night and day."
#AI #PromptEngineering #BhavyaFoundation

### 5. Generate a Reusable Template

The student should leave with something they can use again, not just a one-time prompt.

---

## Score: 3/10

The portfolio shows what the student typed, not what they achieved. It's not shareable, not impressive, and not useful long-term.
