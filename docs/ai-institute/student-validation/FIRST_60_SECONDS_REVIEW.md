# First 60 Seconds Review

## The Critical Window

### What Happens in the First 60 Seconds

| Time   | Screen       | Action                         | Emotion                         |
| ------ | ------------ | ------------------------------ | ------------------------------- |
| 0-10s  | Welcome      | Read mentor greeting           | Curiosity                       |
| 10-20s | Welcome      | Read 5 steps                   | Mild overload                   |
| 20-30s | Welcome      | Read what I'll build           | Clarity                         |
| 30-40s | Welcome      | Click "Start First Experiment" | Excitement                      |
| 40-50s | First Prompt | Read instructions              | Confusion ("what is a prompt?") |
| 50-60s | First Prompt | Type in text box               | Action                          |

### Verdict: PASS (with reservation)

The student IS doing something within 60 seconds. They click "Start First Experiment" at ~30 seconds and see the playground at ~40 seconds.

## The Problem

The first 60 seconds work, but there's a critical gap:

**At 50 seconds, the student doesn't know what a "prompt" is.**

The instruction says "Write a prompt that asks AI to explain..." but the student has never been told what a prompt is. They type anyway because the text box is there, but they're confused.

## What Would Be Better

### Option A: Teach "prompt" in 5 seconds

"Your prompt is just what you say to AI. Type anything."

### Option B: Remove the word "prompt"

"Type a message asking AI to explain artificial intelligence to a 12-year-old."

### Option C: Show an example first

Before the text box, show: "Try: 'Explain AI to a 12-year-old'"

## Comparison to Alternatives

| Approach                  | Time to First Action | Confusion |
| ------------------------- | -------------------- | --------- |
| Current (no explanation)  | ~40s                 | High      |
| Option A (5s explanation) | ~45s                 | Low       |
| Option B (remove jargon)  | ~35s                 | Low       |
| Option C (show example)   | ~30s                 | Very Low  |

## Recommendation

**Use Option B.** Remove the word "prompt" from the first instruction. The student will learn what a prompt is AFTER they've used one, not before.

The first 60 seconds should feel like:

1. Friendly greeting (done)
2. Clear action (needs improvement)
3. Immediate doing (done)

The word "prompt" is jargon. Remove it from the first interaction. Introduce it AFTER the student has successfully used one.
