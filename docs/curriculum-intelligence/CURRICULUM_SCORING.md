# Curriculum Scoring

## Overview

Every potential topic is scored using a transparent rubric. The scoring system ensures curriculum decisions are evidence-based, not intuition-based.

## Scoring Rubric

### 1. Industry Relevance (20%)

**Definition:** How important is this in industry today?

**Scoring:**

- **9-10:** Critical skill, required for most AI jobs
- **7-8:** Important skill, valued by many employers
- **5-6:** Useful skill, valued by some employers
- **3-4:** Niche skill, valued by specific employers
- **1-2:** Emerging skill, not yet widely valued

**Evidence Sources:**

- Job postings analysis
- Industry surveys
- Employer interviews
- Salary data
- Hiring trends

**Example:**

- Prompt Engineering: 9/10 (Required for most AI roles)
- MCP: 7/10 (Important for advanced AI development)
- Browser Automation: 6/10 (Useful for specific roles)

### 2. Educational Value (15%)

**Definition:** How well can this be taught?

**Scoring:**

- **9-10:** Excellent educational materials exist, clear learning path
- **7-8:** Good educational materials exist, clear learning path
- **5-6:** Some educational materials exist, learning path unclear
- **3-4:** Limited educational materials, learning path difficult
- **1-2:** Poor educational materials, learning path very difficult

**Evidence Sources:**

- Existing courses analysis
- Tutorial quality assessment
- Learning outcome data
- Student feedback
- Teaching experience

**Example:**

- Python Programming: 9/10 (Excellent materials, clear path)
- AI Agents: 7/10 (Good materials emerging, path clarifying)
- MCP: 5/10 (Limited materials, path still forming)

### 3. Long-term Durability (15%)

**Definition:** Will this matter in 5 years?

**Scoring:**

- **9-10:** Fundamental concept, will always be important
- **7-8:** Important concept, likely to remain important
- **5-6:** Useful concept, may evolve significantly
- **3-4:** Specific concept, may become obsolete
- **1-2:** Trending concept, may disappear

**Evidence Sources:**

- Historical trends
- Expert predictions
- Fundamental principles
- Technology evolution
- Industry direction

**Example:**

- Programming Fundamentals: 9/10 (Always important)
- LLMs: 8/10 (Important, will evolve)
- Specific Framework: 4/10 (May become obsolete)

### 4. Open-source Importance (10%)

**Definition:** How important is this to the open-source ecosystem?

**Scoring:**

- **9-10:** Critical to OSS, many projects depend on it
- **7-8:** Important to OSS, many projects use it
- **5-6:** Useful to OSS, some projects use it
- **3-4:** Niche in OSS, few projects use it
- **1-2:** Not relevant to OSS

**Evidence Sources:**

- GitHub trending analysis
- OSS project dependencies
- Community contributions
- Documentation quality
- Adoption rates

**Example:**

- Python: 9/10 (Critical to OSS)
- Hugging Face: 8/10 (Important to OSS)
- Specific Library: 5/10 (Useful to some OSS)

### 5. Hands-on Potential (10%)

**Definition:** Can students learn by doing?

**Scoring:**

- **9-10:** Excellent hands-on opportunities, immediate feedback
- **7-8:** Good hands-on opportunities, clear feedback
- **5-6:** Some hands-on opportunities, feedback limited
- **3-4:** Limited hands-on opportunities, feedback unclear
- **1-2:** Poor hands-on opportunities, no feedback

**Evidence Sources:**

- Lab feasibility
- Project opportunities
- Tool availability
- Feedback mechanisms
- Learning outcomes

**Example:**

- Prompt Engineering: 9/10 (Immediate feedback, many opportunities)
- AI Agents: 8/10 (Good opportunities, clear feedback)
- Theoretical Concepts: 4/10 (Limited hands-on)

### 6. Career Impact (10%)

**Definition:** Does this improve career outcomes?

**Scoring:**

- **9-10:** Significant career advantage, high salary impact
- **7-8:** Good career advantage, moderate salary impact
- **5-6:** Some career advantage, minor salary impact
- **3-4:** Limited career advantage, no salary impact
- **1-2:** No career advantage

**Evidence Sources:**

- Salary data
- Job placement rates
- Career advancement
- Employer feedback
- Industry recognition

**Example:**

- AI Engineering: 9/10 (High demand, high salary)
- Prompt Engineering: 8/10 (Growing demand, good salary)
- Niche Skills: 5/10 (Limited demand)

### 7. AI-native Relevance (5%)

**Definition:** Is this unique to AI engineering?

**Scoring:**

- **9-10:** Unique to AI, not applicable elsewhere
- **7-8:** Primarily AI, some applicability elsewhere
- **5-6:** AI-relevant, applicable elsewhere too
- **3-4:** Somewhat AI-relevant, mostly general
- **1-2:** Not AI-specific

**Evidence Sources:**

- AI-specific applications
- Cross-domain applicability
- Unique AI requirements
- AI-native patterns
- AI-specific tools

**Example:**

- Prompt Engineering: 9/10 (Unique to AI)
- AI Agents: 8/10 (Primarily AI)
- Programming: 3/4 (General skill)

### 8. Mission Alignment (5%)

**Definition:** Does this serve Bhavya's mission?

**Scoring:**

- **9-10:** Directly supports mission, essential for transformation
- **7-8:** Strongly supports mission, important for transformation
- **5-6:** Supports mission, useful for transformation
- **3-4:** Somewhat supports mission, minor role in transformation
- **1-2:** Does not support mission

**Evidence Sources:**

- Mission alignment analysis
- Student transformation impact
- Community contribution potential
- Open source potential
- Teaching potential

**Example:**

- Open Source Contribution: 9/10 (Directly supports mission)
- Real Projects: 8/10 (Strongly supports mission)
- Theoretical Knowledge: 5/6 (Supports mission)

### 9. Prerequisite Complexity (5%)

**Definition:** How complex are the prerequisites?

**Scoring:**

- **9-10:** No prerequisites, anyone can learn
- **7-8:** Minimal prerequisites, most can learn
- **5-6:** Some prerequisites, many can learn
- **3-4:** Significant prerequisites, some can learn
- **1-2:** Extensive prerequisites, few can learn

**Evidence Sources:**

- Prerequisite analysis
- Learning curve assessment
- Student success rates
- Time to competency
- Support requirements

**Example:**

- AI Introduction: 9/10 (No prerequisites)
- Prompt Engineering: 7/8 (Minimal prerequisites)
- Advanced AI: 4/5 (Significant prerequisites)

### 10. Hardware Friendliness (3%)

**Definition:** Can this be taught without special hardware?

**Scoring:**

- **9-10:** Works on any computer, no special hardware
- **7-8:** Works on most computers, minimal hardware
- **5-6:** Requires some hardware, reasonable requirements
- **3-4:** Requires significant hardware, expensive
- **1-2:** Requires specialized hardware, very expensive

**Evidence Sources:**

- Hardware requirements
- Cost analysis
- Accessibility
- Cloud alternatives
- Student access

**Example:**

- Prompt Engineering: 9/10 (Works on any computer)
- LLM API Usage: 8/10 (Works on most computers)
- Model Training: 4/5 (Requires significant hardware)

### 11. Vendor Neutrality (2%)

**Definition:** Is this vendor-independent?

**Scoring:**

- **9-10:** Completely vendor-neutral
- **7-8:** Mostly vendor-neutral
- **5-6:** Some vendor dependency
- **3-4:** Significant vendor dependency
- **1-2:** Completely vendor-dependent

**Evidence Sources:**

- Vendor analysis
- Open standards
- Portability
- Community support
- Alternative options

**Example:**

- Python: 9/10 (Completely vendor-neutral)
- Open Source Tools: 8/10 (Mostly vendor-neutral)
- Specific Cloud Service: 3/4 (Significant vendor dependency)

## Scoring Process

### Step 1: Topic Identification

- Identify potential topic
- Define scope and boundaries
- Gather initial evidence

### Step 2: Evidence Collection

- Gather evidence from all sources
- Document evidence quality
- Identify gaps

### Step 3: Scoring

- Score each criterion (1-10)
- Document scoring rationale
- Calculate weighted score

### Step 4: Review

- Peer review
- Expert review
- Community review
- AI review

### Step 5: Publication

- Publish score
- Publish rationale
- Publish evidence
- Enable feedback

### Step 6: Evolution

- Collect feedback
- Update evidence
- Rescore if needed
- Version control

## Score Calculation

### Weighted Score Formula

```
Final Score = (Industry Relevance × 0.20) +
              (Educational Value × 0.15) +
              (Long-term Durability × 0.15) +
              (Open-source Importance × 0.10) +
              (Hands-on Potential × 0.10) +
              (Career Impact × 0.10) +
              (AI-native Relevance × 0.05) +
              (Mission Alignment × 0.05) +
              (Prerequisite Complexity × 0.05) +
              (Hardware Friendliness × 0.03) +
              (Vendor Neutrality × 0.02)
```

### Score Interpretation

- **9.0-10.0:** Tier 1 — Must Have
- **7.0-8.9:** Tier 2 — Important
- **5.0-6.9:** Tier 3 — Advanced
- **3.0-4.9:** Tier 4 — Research
- **1.0-2.9:** Tier 5 — Future Watch
