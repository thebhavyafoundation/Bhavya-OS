## Mapping Rules

### Knowledge → Skills

Every knowledge concept maps to specific skills:

- **概念理解** → 理解能力
- **技术细节** → 技术能力
- **最佳实践** → 应用能力
- **反模式** → 批判能力

### Skills → Projects

Every skill maps to project opportunities:

- **基础技能** → 基础项目
- **中级技能** → 中级项目
- **高级技能** → 高级项目
- **专家技能** → 专家项目

### Projects → Portfolio Evidence

Every project generates portfolio evidence:

- **代码** → GitHub仓库
- **文档** → 项目文档
- **演示** → 视频/截图
- **反思** → 博客文章

### Portfolio Evidence → Industry Capability

Every portfolio evidence maps to industry capabilities:

- **项目数量** → 经验水平
- **项目质量** → 技能水平
- **社区影响** → 领导能力
- **行业认可** → 专业地位

## Competency Levels

### Level 1: 初学者

**Knowledge:** 基础概念
**Skills:** 基础技能
**Projects:** 简单项目
**Portfolio:** 基本文档
**Industry:** 实习生/初级职位

### Level 2: 中级

**Knowledge:** 中级概念
**Skills:** 中级技能
**Projects:** 中等复杂度项目
**Portfolio:** 完整项目文档
**Industry:** 初级职位

### Level 3: 高级

**Knowledge:** 高级概念
**Skills:** 高级技能
**Projects:** 复杂项目
**Portfolio:** 专业级文档
**Industry:** 中级职位

### Level 4: 专家

**Knowledge:** 专家概念
**Skills:** 专家技能
**Projects:** 创新项目
**Portfolio:** 行业影响力
**Industry:** 高级职位

### Level 5: 行业专家

**Knowledge:** 前沿概念
**Skills:** 领导技能
**Projects:** 行业变革项目
**Portfolio:** 行业声誉
**Industry:** 领导职位
