# Teaching Opportunity Model

## Overview

For every technology or engineering pattern, identify teaching opportunities across all modalities.

## Opportunity Types

### Lesson Opportunity

**When:** Concept can be taught in a structured lesson
**Characteristics:**

- Clear learning objectives
- Defined scope
- Measurable outcomes
- Scalable delivery

**Examples:**

- What is an LLM?
- Prompt Engineering Fundamentals
- AI Agent Architecture

### Lab Opportunity

**When:** Concept can be practiced hands-on
**Characteristics:**

- Immediate feedback
- Safe environment
- Guided exploration
- Skill building

**Examples:**

- LLM API Interaction
- Prompt Engineering Playground
- Agent Development Environment

### Project Opportunity

**When:** Concept can be applied to real problems
**Characteristics:**

- Real-world application
- Portfolio value
- Extended engagement
- Meaningful impact

**Examples:**

- AI-Powered Study Assistant
- Browser Automation Tool
- Knowledge Management System

### Assessment Opportunity

**When:** Concept can be verified
**Characteristics:**

- Clear criteria
- Objective measurement
- Constructive feedback
- Learning verification

**Examples:**

- Prompt Engineering Quiz
- Code Review Challenge
- Architecture Review

### Portfolio Opportunity

**When:** Concept creates portfolio value
**Characteristics:**

- Demonstrates skills
- Creates impact
- Builds reputation
- Enables career advancement

**Examples:**

- Open Source Contribution
- Technical Blog Post
- Conference Talk

### Open-source Contribution Opportunity

**When:** Concept can benefit the community
**Characteristics:**

- Community value
- Learning reinforcement
- Reputation building
- Network expansion

**Examples:**

- Library Contribution
- Documentation Improvement
- Bug Fix

## Opportunity Scoring

### Scoring Criteria

| Criterion        | Weight | Description                                 |
| ---------------- | ------ | ------------------------------------------- |
| Learning Impact  | 30%    | How much does this enhance learning?        |
| Career Impact    | 25%    | How much does this improve career outcomes? |
| Community Impact | 20%    | How much does this benefit the community?   |
| Feasibility      | 15%    | How easy is this to implement?              |
| Scalability      | 10%    | How well does this scale?                   |

### Score Interpretation

- **9-10:** High priority, implement immediately
- **7-8:** Medium priority, plan for implementation
- **5-6:** Low priority, consider if resources allow
- **3-4:** Very low priority, monitor only
- **1-2:** Not a priority, ignore

- **Opportunity Scout** — Identifies opportunities

- **Opportunity Planner** — Plans implementation
- **Opportunity Implementer** — Implements opportunities
- **Opportunity Reviewer** — Reviews outcomes

### Process

- Regular scouting
- Systematic scoring
- Strategic planning
- Effective implementation
- Continuous review

### Standards

- Evidence-based
- Transparent
- Impactful
- Feasible
- Scalable
