# Knowledge Package Priority

## Overview

Do not create all Knowledge Packages. Instead classify them into tiers and create them in priority order.

## Tier System

### Tier 1 — Must Have

Core concepts every AI engineer must know. Without these, you cannot be an AI engineer.

**Criteria:**

- Industry relevance >8/10
- Educational value >7/10
- Long-term durability >8/10
- Career impact >8/10

**Examples:**

1. 什么是AI? — Foundation
2. Python编程基础 — Tool
3. 大型语言模型 (LLMs) — Core Concept
4. 提示工程 — Core Skill
5. AI代理 — Core Pattern
6. 模型上下文协议 (MCP) — Core Protocol
7. 浏览器自动化 — Core Application
8. 知识系统 — Core Pattern
9. 开源贡献 — Core Practice
10. 生产部署 — Core Skill

## Priority Order

### Phase 1: Tier 1 (Months 1-3)

Create all Tier 1 Knowledge Packages first.

### Phase 2: Tier 2 (Months 4-6)

Create Tier 2 Knowledge Packages.

### Phase 3: Tier 3 (Months 7-9)

Create Tier 3 Knowledge Packages for specialized roles.

### Phase 4: Tier 4 (Months 10-12)

Create Tier 4 Knowledge Packages for research-oriented students.

### Phase 5: Tier 5 (Ongoing)

Monitor Tier 5 concepts and create Knowledge Packages when they mature.

## Justification System

### Every Tier Assignment Includes

- Score for each criterion
- Evidence sources
- Scoring rationale
- Peer review
- Community feedback
- Version history

### Example Justification

**Topic: 提示工程**
**Tier: 1 — Must Have**

**Scores:**

- Industry Relevance: 9/10 (Required for most AI roles)
- Educational Value: 9/10 (Excellent materials, clear path)
- Long-term Durability: 8/10 (Important, will evolve)
- Career Impact: 9/10 (High demand, good salary)

**Evidence:**

- Job postings: 70% require prompt engineering
- Courses: 50+ available
- Salary premium: 15-20%
- Student outcomes: High satisfaction

**Rationale:**
Prompt engineering is a fundamental skill for AI engineers. It's required for most roles, has excellent educational materials, and will remain important as LLMs evolve.

### Annual Review
