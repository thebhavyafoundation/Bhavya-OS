# Learning Sequence

## Overview

For every topic, determine the best learning modality. Prioritize experiential learning.

## Learning Modalities

### Read

**When:** Conceptual understanding, reference material
**Examples:**

- Documentation
- Articles
- Blog posts
- Research papers
- Books

**Best For:**

- Background knowledge
- Reference material
- Deep dives
- Multiple perspectives

### Watch

**When:** Visual demonstration, step-by-step guidance
**Examples:**

- Video tutorials
- Live coding sessions
- Webinars
- Conference talks
- Course lectures

**Best For:**

- Visual learners
- Step-by-step guidance
- Complex demonstrations
- Real-time explanations

### Experiment

**When:** Hands-on exploration, trial and error
**Examples:**

- Labs
- Playgrounds
- Sandboxes
- Tinkering
- Exploration

**Best For:**

- Active learners
- Immediate feedback
- Discovery-based learning
- Building intuition

### Build

**When:** Applied learning, real-world application
**Examples:**

- Projects
- Products
- Tools
- Applications
- Contributions

**Best For:**

- Applied learning
- Portfolio building
- Real-world skills
- Long-term retention

### Research

**When:** Deep understanding, innovation
**Examples:**

- Paper implementation
- Experiment design
- Data analysis
- Hypothesis testing
- Discovery

**Best For:**

- Deep understanding
- Innovation
- Critical thinking
- Advanced learners

### Reflect

**When:** Metacognition, learning consolidation
**Examples:**

- Journaling
- Discussion
- Peer feedback
- Self-assessment
- Portfolio review

**Best For:**

- Learning consolidation
- Self-awareness
- Growth mindset
- Community building

### Mentor

**When:** Teaching others, leadership development
**Examples:**

- Tutoring
- Code review
- Project guidance
- Career advice
- Community building

**Best For:**

- Deep understanding
- Leadership skills
- Community building
- Career development

## Sequence Design Principles

### 1. Progressive Complexity

Start simple, increase complexity gradually.

### 2. Immediate Application

Apply knowledge as soon as possible.

### 3. Spaced Repetition

Revisit concepts over time.

### 4. Varied Practice

Use different modalities for the same concept.

### 5. Meaningful Context

Connect learning to real-world applications.

### 6. Social Learning

Learn with and from others.

### 7. Reflective Practice

Regularly reflect on learning.

## Topic Sequences

### Topic: 大型语言模型 (LLMs)

**Sequence:**

1. **Read:** LLM documentation and articles (30 minutes)
2. **Watch:** LLM explainer video (10 minutes)
3. **Experiment:** LLM playground (30 minutes)
4. **Build:** Simple LLM application (2 hours)
5. **Research:** LLM architecture deep dive (1 hour)
6. **Reflect:** Learning journal (30 minutes)
7. **Mentor:** Explain LLMs to someone (30 minutes)

## Sequence Optimization

### Parallel Learning

Some topics can be learned in parallel:

- Python + 基础编程
- LLMs + 提示工程
- AI代理 + MCP

### Prerequisite Chains

Some topics require sequential learning:

- 机器学习基础 → 深度学习基础 → 自然语言处理基础
- LLMs → 提示工程 → AI代理

### Optional Paths

Some topics have multiple paths:

- 浏览器自动化 can be learned via:
  - AI代理 path (agent-centric)
  - MCP path (protocol-centric)
  - 传统自动化 path (tool-centric)

## Personalization

### Student Preferences

- Visual learners: More watch content
- Active learners: More experiment/build content
- Reading learners: More read content
- Social learners: More mentor/collaborate content

### Pace Adjustment

- Fast learners: Compressed sequences
- Normal learners: Standard sequences
- Slow learners: Expanded sequences with more support

### Interest Alignment

- Research-focused: More research content
- Build-focused: More project content
- Teach-focused: More mentor content
- Career-focused: More portfolio content
