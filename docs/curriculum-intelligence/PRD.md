# Curriculum Intelligence Engine — PRD

## Status: Discovery Phase

## Date: 2026-08-04

## Overview

The Curriculum Intelligence Engine (CIE) continuously discovers, evaluates, prioritizes, and evolves the curriculum using evidence rather than intuition.

## Problem Statement

Bhavya Foundation doesn't yet know what the world's best AI engineer should know in 2026. Generating Knowledge Packages now would encode assumptions instead of the best available knowledge.

## Primary Objective

Create the intelligence system that answers: "If Bhavya Foundation were founded today, what should an AI engineer learn first?"

## Curriculum Intelligence Model

### Scoring Rubric

Every potential topic is scored using:

| Criterion               | Weight | Description                                  |
| ----------------------- | ------ | -------------------------------------------- |
| Industry Relevance      | 20%    | How important is this in industry today?     |
| Educational Value       | 15%    | How well can this be taught?                 |
| Long-term Durability    | 15%    | Will this matter in 5 years?                 |
| Open-source Importance  | 10%    | How important is this to OSS?                |
| Hands-on Potential      | 10%    | Can students learn by doing?                 |
| Career Impact           | 10%    | Does this improve career outcomes?           |
| AI-native Relevance     | 5%     | Is this unique to AI engineering?            |
| Mission Alignment       | 5%     | Does this serve Bhavya's mission?            |
| Prerequisite Complexity | 5%     | How complex are the prerequisites?           |
| Hardware Friendliness   | 3%     | Can this be taught without special hardware? |
| Vendor Neutrality       | 2%     | Is this vendor-independent?                  |

### Scoring Process

For each topic:

1. Gather evidence from all sources
2. Score each criterion (1-10)
3. Calculate weighted score
4. Document scoring rationale
5. Review with community
6. Publish score and rationale

## Learning Sequence

### For Every Topic

Determine the best learning modality:

- **Read** — Documentation, articles
- **Watch** — Videos, tutorials
- **Experiment** — Labs, playgrounds
- **Build** — Projects, products
- **Research** — Papers, exploration
- **Reflect** — Journaling, discussion
- **Mentor** — Teaching others

**Prioritize experiential learning.**

## Knowledge Package Prioritization

### Tier 1 — Must Have

Core concepts every AI engineer must know. Without these, you cannot be an AI engineer.

### Tier 2 — Important

Concepts that significantly improve capabilities. Not strictly required, but highly valuable.

### Tier 3 — Advanced

Concepts for specialized roles. Important for certain career paths.

### Tier 4 — Research

Concepts that are emerging. Important to understand, but not yet mainstream.

### Tier 5 — Future Watch

Concepts that may become important. Monitor but don't teach yet.
