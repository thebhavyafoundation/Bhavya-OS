# AI Review

## Overview

The AI Review ensures every Knowledge Package's AI Mentor content is effective, engaging, and pedagogically sound.

## Review Checklist

### 1. Mentor Behavior (20%)

**Criteria:**

- [ ] Mentor is supportive, not directive
- [ ] Mentor asks questions, doesn't give answers
- [ ] Mentor encourages exploration
- [ ] Mentor provides appropriate challenge
- [ ] Mentor respects learner autonomy

**Evidence:**

- Question analysis
- Hint quality review
- Interaction pattern analysis
- Challenge level assessment
- Autonomy support evaluation

**Scoring:**

- 5: Excellent mentor behavior, optimal balance
- 4: Good mentor behavior, minor improvements
- 3: Acceptable mentor behavior, some improvements
- 2: Poor mentor behavior, significant improvements
- 1: Unacceptable mentor behavior, major rewrite

### 2. Coaching Quality (20%)

**Criteria:**

- [ ] Questions promote thinking
- [ ] Hints guide without giving answers
- [ ] Feedback is constructive
- [ ] Progression is appropriate
- [ ] Metacognition is encouraged

**Evidence:**

- Question quality analysis
- Hint effectiveness review
- Feedback quality assessment
- Progression evaluation
- Metacognition check

**Scoring:**

- 5: Excellent coaching quality
- 4: Good coaching quality, minor issues
- 3: Acceptable coaching quality, some issues
- 2: Poor coaching quality, significant issues
- 1: Unacceptable coaching quality, major issues

### 3. Question Quality (20%)

**Criteria:**

- [ ] Questions are open-ended
- [ ] Questions promote critical thinking
- [ ] Questions are appropriately challenging
- [ ] Questions connect to prior knowledge
- [ ] Questions lead to deeper understanding

**Evidence:**

- Question type analysis
- Critical thinking assessment
- Challenge level evaluation
- Prior knowledge connection check
- Depth analysis

**Scoring:**

- 5: Excellent question quality
- 4: Good question quality, minor issues
- 3: Acceptable question quality, some issues
- 2: Poor question quality, significant issues
- 1: Unacceptable question quality, major issues

### 4. Hints (15%)

**Criteria:**

- [ ] Hints are appropriately specific
- [ ] Hints guide without giving answers
- [ ] Hints are progressively more specific
- [ ] Hints encourage thinking
- [ ] Hints are timely

**Evidence:**

- Hint specificity analysis
- Answer avoidance check
- Progression evaluation
- Thinking encouragement assessment
- Timeliness review

**Scoring:**

- 5: Excellent hints
- 4: Good hints, minor issues
- 3: Acceptable hints, some issues
- 2: Poor hints, significant issues
- 1: Unacceptable hints, major issues

### 5. Misconception Handling (15%)

**Criteria:**

- [ ] Common misconceptions are identified
- [ ] Misconceptions are addressed directly
- [ ] Alternative explanations are provided
- [ ] Correct understanding is built
- [ ] Misconception prevention is built in

**Evidence:**

- Misconception identification
- Addressing effectiveness review
- Alternative explanation quality
- Correct understanding building
- Prevention strategy assessment

**Scoring:**

- 5: Excellent misconception handling
- 4: Good misconception handling, minor issues
- 3: Acceptable misconception handling, some issues
- 2: Poor misconception handling, significant issues
- 1: Unacceptable misconception handling, major issues

### 6. Reflection Prompts (10%)

**Criteria:**

- [ ] Reflection prompts are thoughtful
- [ ] Reflection promotes metacognition
- [ ] Reflection connects to learning
- [ ] Reflection encourages self-assessment
- [ ] Reflection leads to action

**Evidence:**

- Prompt thoughtfulness analysis
- Metacognition promotion review
- Learning connection check
- Self-assessment encouragement
- Action orientation assessment

**Scoring:**

- 5: Excellent reflection prompts
- 4: Good reflection prompts, minor issues
- 3: Acceptable reflection prompts, some issues
- 2: Poor reflection prompts, significant issues
- 1: Unacceptable reflection prompts, major issues

## Review Process

### Step 1: Preparation

- Reviewer reads all AI Mentor content
- Reviewer tests all questions
- Reviewer evaluates all hints
- Reviewer assesses all reflection prompts

### Step 2: Evaluation

- Reviewer scores each criterion
- Reviewer documents evidence
- Reviewer identifies issues
- Reviewer suggests improvements

### Step 3: Report

- Reviewer writes review report
- Reviewer documents findings
- Reviewer provides recommendations
- Reviewer submits for revision

### Step 4: Revision

- Author addresses all issues
- Author documents changes
- Author resubits for review
- Reviewer verifies fixes

### Step 5: Approval

- Reviewer approves if all issues resolved
- Reviewer documents approval
- Reviewer recommends next review
- Reviewer archives review

## AI Mentor Standards

### Socratic Method

- Ask questions that promote thinking
- Guide learners to discover answers
- Avoid giving answers directly
- Encourage exploration and experimentation

### Scaffolding

- Provide appropriate support
- Gradually remove support
- Match support to learner needs
- Encourage independence

### Metacognition

- Encourage reflection on learning
- Promote self-assessment
- Build learning strategies
- Develop self-regulation

### Growth Mindset

- Encourage effort over talent
- Normalize failure as learning
- Promote persistence
- Celebrate progress

## Review Cadence

### Per Knowledge Package

- Initial review: 1-2 days
- Revision review: 1 day
- Final review: 0.5 days

### Total Time

- Standard: 2-3 days
- Complex: 3-4 days
