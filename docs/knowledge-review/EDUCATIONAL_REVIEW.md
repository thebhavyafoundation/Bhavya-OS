# Educational Review

## Overview

The Educational Review ensures every Knowledge Package is pedagogically sound, accessible, and creates effective learning experiences.

## Review Checklist

### 1. Learning Objectives (20%)

**Criteria:**

- [ ] Objectives are clear and specific
- [ ] Objectives are measurable
- [ ] Objectives are achievable
- [ ] Objectives are relevant
- [ ] Objectives are aligned with assessment

**Evidence:**

- Objective clarity analysis
- Measurability verification
- Achievability assessment
- Relevance evaluation
- Alignment check

**Scoring:**

- 5: Excellent objectives, clear, measurable, achievable
- 4: Good objectives, minor improvements needed
- 3: Acceptable objectives, improvements needed
- 2: Poor objectives, significant improvements needed
- 1: Unacceptable objectives, major rewrite needed

### 2. Progression (20%)

**Criteria:**

- [ ] Concepts build on each other
- [ ] Difficulty increases gradually
- [ ] Prerequisites are clear
- [ ] Dependencies are logical
- [ ] Flow is natural

**Evidence:**

- Concept mapping
- Difficulty analysis
- Prerequisite verification
- Dependency check
- Flow review

**Scoring:**

- 5: Excellent progression, natural flow
- 4: Good progression, minor issues
- 3: Acceptable progression, some issues
- 2: Poor progression, significant issues
- 1: Unacceptable progression, major issues

### 3. Cognitive Load (15%)

**Criteria:**

- [ ] Information is chunked appropriately
- [ ] Complexity is managed
- [ ] Working memory is respected
- [ ] Prior knowledge is leveraged
- [ ] Mental models are built

**Evidence:**

- Chunk size analysis
- Complexity assessment
- Working memory evaluation
- Prior knowledge check
- Mental model review

**Scoring:**

- 5: Excellent cognitive load management
- 4: Good cognitive load management, minor issues
- 3: Acceptable cognitive load management, some issues
- 2: Poor cognitive load management, significant issues
- 1: Unacceptable cognitive load management, major issues

### 4. Hands-on Balance (15%)

**Criteria:**

- [ ] Explanation to practice ratio is appropriate
- [ ] Practice is immediately applicable
- [ ] Feedback is provided
- [ ] Iteration is encouraged
- [ ] Reflection is included

**Evidence:**

- Ratio analysis
- Applicability check
- Feedback review
- Iteration assessment
- Reflection evaluation

**Scoring:**

- 5: Excellent hands-on balance
- 4: Good hands-on balance, minor issues
- 3: Acceptable hands-on balance, some issues
- 2: Poor hands-on balance, significant issues
- 1: Unacceptable hands-on balance, major issues

### 5. Assessment Quality (15%)

**Criteria:**

- [ ] Assessment aligns with objectives
- [ ] Assessment is valid
- [ ] Assessment is reliable
- [ ] Assessment is fair
- [ ] Feedback is constructive

**Evidence:**

- Alignment verification
- Validity check
- Reliability assessment
- Fairness evaluation
- Feedback review

**Scoring:**

- 5: Excellent assessment quality
- 4: Good assessment quality, minor issues
- 3: Acceptable assessment quality, some issues
- 2: Poor assessment quality, significant issues
- 1: Unacceptable assessment quality, major issues

### 6. Accessibility (15%)

**Criteria:**

- [ ] Content is accessible to all learners
- [ ] Multiple learning styles are supported
- [ ] Prerequisites are clear
- [ ] Help is available
- [ ] Inclusive language is used

**Evidence:**

- Accessibility audit
- Learning style analysis
- Prerequisite check
- Help availability review
- Language review

**Scoring:**

- 5: Excellent accessibility
- 4: Good accessibility, minor issues
- 3: Acceptable accessibility, some issues
- 2: Poor accessibility, significant issues
- 1: Unacceptable accessibility, major issues

## Review Process

### Step 1: Preparation

- Reviewer reads entire Knowledge Package
- Reviewer tests all exercises
- Reviewer completes all assessments
- Reviewer evaluates all projects

### Step 2: Evaluation

- Reviewer scores each criterion
- Reviewer documents evidence
- Reviewer identifies issues
- Reviewer suggests improvements

### Step 3: Report

- Reviewer writes review report
- Reviewer documents findings
- Reviewer provides recommendations
- Reviewer submits for revision

### Step 4: Revision

- Author addresses all issues
- Author documents changes
- Author resubmits for review
- Reviewer verifies fixes

### Step 5: Approval

- Reviewer approves if all issues resolved
- Reviewer documents approval
- Reviewer recommends next review
- Reviewer archives review

## Pedagogical Standards

### Bloom's Taxonomy Alignment

- **Remember:** Students can recall facts and concepts
- **Understand:** Students can explain ideas and concepts
- **Apply:** Students can use information in new situations
- **Analyze:** Students can draw connections among ideas
- **Evaluate:** Students can justify a stand or decision
- **Create:** Students can produce new or original work

### Constructivism Principles

- Learning is active, not passive
- Knowledge is constructed, not transmitted
- Prior knowledge is the foundation
- Social interaction enhances learning
- Authentic tasks promote understanding

### Cognitive Load Theory

- Intrinsic load: inherent difficulty of material
- Extraneous load: how material is presented
- Germane load: effort devoted to learning
- Goal: minimize extraneous, manage intrinsic, maximize germane

## Review Cadence

- Initial review: 2-3 days

- Final review: 1 day

### Total Time

- Standard: 4-6 days
