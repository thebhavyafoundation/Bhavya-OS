## KP-002: Operating System Navigation

### Beginner Experience

| Metric | Value |
|--------|-------|
| Time to Complete | ~5 hours + 1 week project |
| Confidence Before | 3/10 |
| Confidence After | 6/10 |
| Skills Gained | Desktop navigation, window management, settings, Task Manager, shortcuts |
| Portfolio Value | 8/10 |

### What Worked
1. Silent Discovery opening — students enjoy exploring without instructions
2. Alt+Tab revelation — genuine "aha" moment
3. CPU watching — seeing numbers change in real-time is engaging
4. Snap/Split-screen — visual satisfaction
5. Speed run — creates excitement and competition

### What Didn't Work
1. Desktop vs. Desktop Environment distinction is too abstract
2. CPU vs. Memory explanation may still confuse beginners
3. Alt+Tab cycling is mechanically confusing
4. OS-specific instructions favor Windows
5. Settings Scavenger Hunt may frustrate students who can't find things
6. Task Manager section is intimidating for non-technical students

### Confusing Concepts
- Desktop environment (too abstract)
- CPU vs. Memory (hard to internalize without experience)
- Alt+Tab modifier key mechanics
- System processes vs. user processes

### Drop-off Points
1. Section 3 (Settings) — Scavenger Hunt is long
2. Section 4 (Task Manager) — technical nature intimidates
3. Section 5 (Keyboard Shortcuts) — too many shortcuts at once

### Questions Students Ask
1. "What is the taskbar?"
2. "What's the difference between minimize and close?"
3. "Why does my computer have so many processes I don't recognize?"
4. "What happens if I close everything in Task Manager?"
5. "Why should I use keyboard shortcuts?"

## KP-003: File Management

### Beginner Experience

| Metric | Value |
|--------|-------|
| Time to Complete | ~3.25 hours |
| Confidence Before | 2/10 |
| Confidence After | 6/10 |
| Skills Gained | File systems, naming, folders, operations, backups |
| Portfolio Value | 8/10 |

### What Worked
1. "30 seconds to find a file" hook — immediately relevant
2. "Name Game" — engaging and practical
3. "Design Before You Build" — satisfying design exercise
4. Copy vs. Move analogy (photocopy/tear) — makes distinction click
5. 3-2-1 Backup Rule — memorable and empowering
6. "Teach Someone" — reinforces learning

### What Didn't Work
1. Opening challenge may frustrate students with no prior organization
2. "Map Your Computer's Brain" assumes navigation skills
3. File naming experiment with special characters may not produce consistent results
4. Storage Audit assumes cloud access
5. Full Challenge10-minute time limit is too tight

### Confusing Concepts
- Root and path (abstract for beginners)
- Copy vs. Move (confused in practice)
- 3-2-1 Backup Rule (types of storage unclear)
- File extensions (case sensitivity on different systems)

### Drop-off Points
1. Section 5 (Storage Management) — assumes cloud access
2. Section 6 (Full Challenge) — time pressure causes rushing
3. Lab Exercise 4 — requires internet and account creation

### Questions Students Ask
1. "How do I find a file I saved?"
2. "Why does file naming matter?"
3. "When should I use Copy vs. Move?"
4. "How do I organize my photos?"
5. "What happens if my computer breaks?"

## KP-004: Software Installation

### Beginner Experience

| Metric | Value |
|--------|-------|
| Time to Complete | ~4 hours |
| Confidence Before | 2/10 |
| Confidence After | 5/10 |
| Skills Gained | Source verification, installation process, permissions, updates, uninstallation |
| Portfolio Value | 8/10 |

### What Worked
1. "Paperweight Experiment" — powerful opening
2. "Sort the Software" — engaging categorization exercise
3. "Source Investigation" — immediately relevant
4. "Fake Site Challenge" — eye-opening
5. "Red Flag Test" — powerful illustration of least privilege
6. WannaCry story — compelling real-world consequence

### What Didn't Work
1. Source Verification Checklist (5 steps) is too many to remember
2. Installation Process (6 steps) is too technical for beginners
3. Permissions Audit requires understanding of what each permission means
4. WannaCry story is a tangent from installation process
5. Lab 3 (Install Software) may not be possible on restricted school computers

### Confusing Concepts
- System vs. Application Software (boundary is blurry)
- Installation process (6 steps too detailed)
- Dependencies (program needs other programs)
- DLL errors (too advanced for Grade 9)
- Least privilege (abstract concept)

### Drop-off Points
1. Section 3 (Installation Process) — technical breakdown loses students
2. Section 4 (Permissions Audit) — requires prior knowledge
3. Lab 3 — may not be possible on school computers

### Questions Students Ask
1. "How do I know if a download is safe?"
2. "Why can't I download from any website?"
3. "What is bundled software?"
4. "Why are updates so important?"
5. "Why does this app want my camera?"

## Cross-KP Patterns

### Common Strengths
1. Opening hooks are consistently strong (silent discovery, 30-second challenge, paperweight experiment)
2. DO exercises are the most engaging element in every KP
3. Real-world scenarios make content relevant
4. "Teach Someone" sections reinforce learning
5. AI Mentor guides are consistently strong with Socratic approach

### Common Weaknesses
1. Reading load is too high across all KPs (55-65% vs target 30%)
2. Interaction ratio is too low (35-45% vs target 70%)
3. OS-specific instructions favor Windows
4. No mention of AI-assisted tools in any KP
5. Portfolio pieces don't differentiate learners
6. Some exercises assume infrastructure (cloud storage, unrestricted computers)

### Common Drop-off Points
1. Middle sections (Settings, Storage, Installation Process) — where novelty wears off
2. Technical sections (Task Manager, Permissions) — where intimidation begins
3. Time-pressured exercises — where frustration peaks

### Common Confusing Concepts
1. Abstract terminology (desktop environment, root, path, dependencies)
2. Mechanical operations (Alt+Tab cycling, Copy vs. Move)
3. Technical concepts (CPU vs. Memory, DLL errors, least privilege)
4. Cross-system differences (file extensions, installation methods)

### Common Questions
1. "How do I find...?" (files, settings, downloads)
2. "Why does... matter?" (naming, organization, updates)
3. "What happens if...?" (close everything, delete, don't update)
4. "When should I use...?" (Copy vs. Move, minimize vs. close)
5. "How do I know if...?" (download is safe, permission is needed)
