## Analysis by KP

### KP-002: Operating System Navigation

**Reading Load: 65%** — HIGHEST across all KPs

Dense sections:
- Section 3 (Settings): 15 minutes of instruction + Scavenger Hunt
- Section 4 (Task Manager): 15 minutes of technical explanation
- Section 5 (Keyboard Shortcuts): Reference table with 15+ shortcuts

**Interaction Ratio: 35%** — LOWEST across all KPs

The DO exercises are strong but sections are long. Students read for 5-8 minutes before doing anything.

**Recommendation:** Break Sections 3-4 into shorter chunks with more frequent DO exercises.

---

### KP-003: File Management

**Reading Load: 55%** — MODERATE

Dense sections:
- Section 5 (Storage Management): Storage comparison table + 3-2-1 rule
- Section 6 (Full Challenge): 10-minute time limit causes rushing

**Interaction Ratio: 45%** — BEST across all KPs

Every section has DO exercises. The "Design Before You Build" approach is particularly effective.

**Recommendation:** Reduce Full Challenge time pressure; add more DO exercises to Section 5.

---

### KP-004: Software Installation

**Reading Load: 60%** — HIGH

Dense sections:
- Section 3 (Installation Process): 6-step technical breakdown
- Section 4 (Permissions Audit): Requires understanding of each permission
- Section 5 (Updates): WannaCry story is a tangent

**Interaction Ratio: 40%** — MODERATE

DO exercises are practical but Section 3 is too technical for hands-on engagement.

**Recommendation:** Simplify installation process (6 steps → 3 core steps); make WannaCry optional reading.

## Recommendations

### Critical (Must Fix)
1. **Reduce reading load from 60% to 30%** — Break dense sections into shorter chunks
2. **Increase interaction ratio from 40% to 70%** — Add more DO exercises per section
3. **Remove time pressure** — KP-003 Full Challenge10-minute limit causes rushing

### High Priority
4. **Add prerequisite checks** — KP-004 assumes file management knowledge
5. **Simplify technical sections** — KP-004 Installation Process (6 → 3 steps)
6. **Reduce shortcut overload** — KP-002 reference table has 15+ shortcuts

### Medium Priority
7. **Add more reflection opportunities** — Current reflection is end-of-section only
8. **Break long sections** — Sections longer than 10 minutes need internal breaks
9. **Add progress indicators** — Students don't know how much is left

### Low Priority
10. **Add visual diagrams** — Concept maps for technical sections
11. **Add audio alternatives** — For reading-heavy sections
12. **Add video walkthroughs** — For complex procedures
