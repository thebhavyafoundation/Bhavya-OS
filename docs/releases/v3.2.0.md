## What's New

### Declarative Page System
Every page is defined by a schema. The renderer reads the schema and comsembles the page. Adding or updating data inside Bhavya OS automatically changes what visitors see.

```
page:
  title: "Forest Restoration"
  sections:
    - hero
    - impact_metrics
    - projects
    - reports
    - gallery
```

### Content Publishing Workflow

No manual website editing required:

1. Upload Report -> Finance Service
2. Approval Workflow -> Governance Service
3. Audit Snapshot -> Audit Service
4. Public API -> Exposes data
5. Cache Refresh -> Invalidates stale data
6. Live Website -> Reflects latest state

### Unified Search

One search across all content:
- Projects
- Reports
- Policies
- Research
- News
- Annual reports
- Governance documents

## Acceptance Criteria (MET)

- Creating a new project automatically adds it to the Projects page
- Approving a policy automatically publishes it to the Policies page
- Publishing an annual report automatically makes it available for download
- Updating trustee information automatically refreshes the About page
- New research becomes searchable and appears in the Research section
- Website navigation reflects newly published public content

## What This Means

The website contains almost no business logic. It simply renders institutional data provided by Bhavya OS. Every page is a thin presentation layer over the source of truth.
