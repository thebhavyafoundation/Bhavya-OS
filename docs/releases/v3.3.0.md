## What's New

### Mission Service
The operational command center for every initiative.

```
Mission
  -> Objectives
  -> Projects
  -> Milestones
  -> Tasks
  -> Resources
  -> Evidence
  -> Impact
  -> Archive
```

- Create, approve, start, pause, complete, archive missions
- Define objectives with measurable outcomes
- Track timeline events
- Query by domain

### Resource Registry
Track all resources belonging to missions.

- Volunteers, staff, equipment, vehicles, grants, documents, assets
- Assign and release resources
- Query by mission or type

### Impact Registry
Measurable outcomes, metrics, reporting.

- Record metrics over time
- Generate impact reports
- Compare across missions
- Track trends

## Mission Model

Every mission shares a common lifecycle:

```
Mission
  |
  +-- Objectives (measurable outcomes)
  +-- Projects (belong to exactly one mission)
  +-- Resources (volunteers, equipment, grants)
  +-- Impact (metrics, reports)
  +-- Timeline (milestones, reviews)
  +-- Audit (every change recorded)
```

## Example: Forest Restoration

```
Mission: Forest Restoration
  |
  +-- Objective: Plant 50,000 trees
  +-- Objective: Restore 100 hectares
  |
  +-- Project: Village A
  |     +-- Milestone: Site Assessment
  |     +-- Milestone: Planting Phase 1
  |     +-- Tasks: GPS Survey, Procurement, Plantation
  |
  +-- Resource: 10 volunteers
  +-- Resource: Planting tools
  +-- Resource: UNESCO Grant
  |
  +-- Impact: 5,000 trees planted
  +-- Impact: 15 hectares restored
  |
  +-- Timeline: Phase 1 Complete (Sep 2026)
  +-- Timeline: Mid-term Review (Dec 2026)
```

## Example: Heritage Preservation

```
Mission: Heritage Preservation

  |
  +-- Project: Temple A
  |     +-- Survey

```

## Why This Comes Before Volunteer

Volunteers don't exist in isolation -- they join missions.

```
Mission
  |
  +-- Roles
  +-- Tasks
  +-- Volunteers
  +-- Execution
  +-- Impact
```

Now every volunteer has meaningful work immediately upon onboarding.

## What This Means

Every future mission -- environmental conservation, education, healthcare, cultural preservation -- can plug into the same execution framework instead of requiring a brand-new application.

Forest, Heritage, Library, and Research become **modules** powered by the same operational framework rather than isolated applications.
