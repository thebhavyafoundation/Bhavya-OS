## What's New

### Production Configuration Engine
Environment-aware configuration with validation. Supports development, staging, production.

```typescript
const config = new ProductionConfiguration();
await config.initialize();
// Loads from env vars, validates, masks sensitive values in logs
config.get('database'); // { host, port, name, ssl }
config.get('auth');     // { secret: '***', tokenExpiry, refreshExpiry }
```

### Auth & Authorization
Token-based authentication with role-based access control.

```typescript
const token = await auth.issueToken('agent:developer', ['agent']);
const { valid } = await auth.validateToken(token.id);
const allowed = await auth.checkPermission(token.id, 'write');
```

### Rate Limiting & Throttling
Protects the system from overload.

```typescript
const { allowed, remaining } = await rateLimiter.check({ agentId: 'agent:1' });
// allowed: false → request rejected
```

### Monitoring & Alerting
Production observability with alerting.

```typescript
monitoring.record('api.latency', 245, { endpoint: '/api/goals' });
monitoring.onAlert((alert) => console.log(alert.severity, alert.title));
monitoring.raiseAlert('critical', 'Database down', 'Connection refused', 'database');
```

### Backup & Recovery
Automated data protection.

```typescript
const backup = await backupRecovery.createBackup();
const recovery = await backupRecovery.restore(backup.id);
// recovery.restored: true, recovery.filesRestored: 42
```
