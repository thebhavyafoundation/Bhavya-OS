## What's New

### Self-Organizing Engine
Discovers work, assigns agents, coordinates autonomously. No human tells it what to do — it figures it out.

```typescript
const work = await selfOrganizing.discoverWork({
  type: 'task',
  title: 'Update homepage',
  description: '...',
  requiredCapabilities: ['design', 'react'],
  priority: 'high'
});
// Agent assigned automatically
```

### Event-Driven Orchestrator
Reacts to events, triggers workflows automatically. No polling — pure event-driven.

```typescript
orchestrator.registerTrigger({
  eventType: 'page.created',
  condition: (payload) => payload.type === 'mission',
  workflowId: 'update-navigation',
  workflowInput: (payload) => ({ page: payload.page }),
  enabled: true,
  cooldownMs: 60000
});
```

### Consensus Engine
Multi-agent decision making. Agents propose, vote, and reach consensus.

```typescript
const proposal = await consensus.createProposal({
  title: 'Use Tailwind CSS',
  description: '...',
  proposedBy: 'agent:designer',
  type: 'decision',
  quorum: 5,
  threshold: 0.6
});

await consensus.castVote(proposal.id, {
  agentId: 'agent:developer',
  decision: 'approve',
  reasoning: 'Industry standard'
});
```

### Capability Matcher
Pairs agents to tasks based on skills, availability, and performance.

```typescript
const match = await matcher.match({
  id: 'req-1',
  requiredCapabilities: ['react', 'typescript'],
  priority: 'high'
});
// match.bestMatch → { agentId, name, overallScore: 0.92 }
```

## What This Means

The system can now:
- Self-organize when given goals
- Discover work from events, memory, or external signals
- Assign agents based on capabilities, availability, and performance
- Trigger workflows automatically on events
- Reach consensus through multi-agent voting
- Recover from failures via replay
