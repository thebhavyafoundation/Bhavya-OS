# Bhavya OS v4.0 — Worker Governance

**Date:** 2026-08-05
**Status:** ACTIVE

---

## Overview

Every worker has:

- Specialization
- Allowed directories
- Resource limits
- Quality targets
- Review requirements

Workers cannot edit outside their ownership.

---

## Workers

### frontend-engineer

- **Specialization:** UI components, CSS, React, Next.js
- **Allowed:** `apps/*/src/components`, `apps/*/src/app`, `apps/*/src/styles`, `packages/platform-ui/src`
- **Blocked:** `platform/ai-runtime`, `packages/runtime/src/engines`
- **Limits:** 2 concurrent tasks, 512MB memory, 5min timeout
- **Quality:** Lint ≥90, TypeCheck ✓, Accessibility ✓
- **Review:** Required (qa-engineer)

### backend-engineer

- **Specialization:** API routes, database, server logic
- **Allowed:** `apps/*/src/app/api`, `packages/runtime/src`, `packages/api/src`, `packages/database/src`
- **Blocked:** `apps/*/src/components`, `packages/platform-ui/src`
- **Limits:** 2 concurrent tasks, 512MB memory, 5min timeout
- **Quality:** Lint ≥90, TypeCheck ✓, Test Coverage ≥80%, Security Audit ✓
- **Review:** Required (qa-engineer)

### qa-engineer

- **Specialization:** Unit tests, integration tests, E2E tests
- **Allowed:** `**/*.test.*`, `**/*.spec.*`
- **Blocked:** None
- **Limits:** 3 concurrent tasks, 1GB memory, 10min timeout
- **Quality:** Test Coverage ≥80%, All Tests Pass ✓, No Flaky Tests ✓
- **Review:** Not required

### devops-engineer

- **Specialization:** Deployment, CI/CD, infrastructure
- **Allowed:** `platform/ai-runtime/deployment-pipeline.mjs`, `.github/workflows`, `vercel.json`
- **Blocked:** `apps/*/src/components`, `packages/platform-ui/src`
- **Limits:** 1 concurrent task, 256MB memory, 10min timeout
- **Quality:** Deployment Success ✓, Rollback Available ✓, Monitoring Active ✓
- **Review:** Required (chief-architect)

## Enforcement

```javascript
// Worker governance is enforced by the runtime
const worker = workerPool.getIdleWorkers()[0];

// Check if worker can edit the target directory
if (!canWorkerEditDirectory(worker, targetDir)) {
  throw new Error(`Worker ${worker.name} cannot edit ${targetDir}`);
}
```
