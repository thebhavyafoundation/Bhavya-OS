## What's New

### ExecutionContext
Every event, task, workflow, and memory update now has a shared context:

```typescript
interface ExecutionContext {
  executionId: string;       // Unique execution identifier
  parentExecutionId?: string; // Parent execution (for sub-tasks)
  triggeringEvent?: string;  // What triggered this execution
  initiatingAgent?: string;  // Who started this
  correlationId: string;     // Links related executions
  timestamps: {
    started: Date;
    lastUpdated: Date;
    completed?: Date;
    deadline?: Date;
  };
  retryCount: number;
  maxRetries: number;
  state: ExecutionState;
  metadata: Record<string, unknown>;
}
```

### Idempotency Layer
Prevents duplicate execution:

```typescript
const { proceed, reason } = await kernel.idempotency.shouldExecute('page:create-home');
// { proceed: true, reason: 'key_not_found' }
// OR
// { proceed: false, reason: 'already_completed' }
```

If an event is replayed or a workflow restarted, the runtime knows:
- Whether the task has already completed
- Whether it should resume
- Or whether it should execute again
