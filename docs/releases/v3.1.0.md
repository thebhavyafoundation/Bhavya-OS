## What's New

### Governance Service
Institutional source of truth for decisions, approvals, and official documents.

- Create governance documents (policies, resolutions, minutes, charters)
- Route through approval chains
- Record approvals and rejections
- Create and vote on resolutions
- Record meeting minutes
- Complete audit trail

### Finance Service
Budgets, grants, donations, financial reports.

- Create and approve budgets
- Record grants and utilization
- Record donations
- Generate financial reports
- Track income and expenses by category

### Projects Service
Project lifecycle, milestones, impact metrics.

- Create, approve, start, pause, complete projects
- Add and track milestones
- Update impact metrics (beneficiaries, hectares, trees, volunteers)
- Track budget utilization

### Audit Service
Audit trail, compliance, versioning, snapshots.

- Record audit entries
- Query audit trail by entity, time, agent
- Create snapshots for versioning
- Restore from snapshots
- Compliance rules and validation

### Public API
Exposes the source of truth to other applications.

- REST endpoints for governance, finance, projects, audit
- CORS support
- Rate limiting
- Health checks

## Architecture

```
Transparency Platform
  |
  +-- Governance Service (decisions, approvals)
  +-- Finance Service (budgets, grants, donations)
  +-- Projects Service (lifecycle, impact)
  +-- Audit Service (trail, compliance, snapshots)
  +-- Public API (REST endpoints)
  |
Kernel (@bhavya/kernel)
  |
Engines (@bhavya/*-engine)
  |
Memory (.memory/)
```

## Example Workflow

Trustee approves environmental project:

1. Resolution Approved
2. Create Project
3. Assign Budget
4. Publish Resolution
5. Update Registry
6. Generate Public Page
7. Notify Website
8. Update Search Index
9. Record Audit Event
10. Archive Snapshot

## Acceptance Criteria (MET)

- Create a governance document
- Route it through approvals
- Record the approval chain
- Publish a public version
- Update the search index
- Emit audit events
- Archive a versioned snapshot
- Make it searchable through the Knowledge Platform
- Surface it automatically on the Website

## What This Means

Bhavya OS can now manage an institution's core governance lifecycle. The Transparency Platform becomes the authoritative data source that the Website and other applications consume.
