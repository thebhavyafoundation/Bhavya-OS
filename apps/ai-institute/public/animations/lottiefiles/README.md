# Lottie Animations - Free License

## Download Instructions

1. Go to: https://lottiefiles.com
2. Search for free animations (loading, success, education, checkmarks, confetti)
2. Filter by "Free" license
3. Download JSON files
3. Copy to this folder

## License

**Free** - Free for commercial and personal use. Check individual animation licenses.

## Recommended Animations

### Loading Animations
- `loading-spinner.json` - Basic spinner
- `loading-dots.json` - Dot animation
- `loading-pulse.json` - Pulse animation

### Success/Feedback
- `success-checkmark.json` - Checkmark animation
- `success-confetti.json` - Confetti celebration
- `success-celebration.json` - Full celebration

### Education
- `education-book.json` - Book opening
- `education-lightbulb.json` - Idea/lightbulb
- `education-graduation.json` - Graduation cap

### UI Elements
- `ui-button-press.json` - Button press
- `ui-toggle.json` - Toggle switch
- `ui-loading-bar.json` - Progress bar

### Nature/Science
- `nature-plant-growth.json` - Plant growing
- `science-atom.json` - Atom spinning
- `science-dna.json` - DNA helix

## Usage

```tsx
import Lottie from 'lottie-react'
import successAnimation from '/animations/lottiefiles/success-checkmark.json'

<Lottie animationData={successAnimation} loop={false} />
```
