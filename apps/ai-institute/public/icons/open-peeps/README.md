# Open Peeps - CC0 Hand-Drawn Illustrations

## Download Instructions

1. Go to: https://openpeeps.com
2. Click "Download Library" 
3. Download the ZIP file
4. Extract and copy SVG files to this folder

## License

**CC0 (Public Domain)** - Free for commercial and personal use without attribution.

## Usage

```tsx
// Direct SVG import
import PersonIcon from '/icons/open-peeps/peep-1.svg'

// Or as image
<img src="/icons/open-peeps/peep-1.svg" alt="Student" />
```
