# Reshot Icons - Free License

## Download Instructions

1. Go to: https://www.reshot.com
2. Search for education/science/school icons
3. Download SVG files
4. Copy to this folder

## License

**Free** - Free for commercial and personal use. No attribution required but appreciated.

## Recommended Categories

- Education icons (books, pencils, graduation caps)
- Science icons (atoms, beakers, microscopes)
- Technology icons (laptops, code brackets, robots)
- School icons (schools, buses, lockers)
- People icons (students, teachers, diverse characters)

## Usage

```tsx
// Direct SVG import
import BookIcon from '/icons/reshot/book.svg'
import AtomIcon from '/icons/reshot/atom.svg'

// Or as image
<img src="/icons/reshot/science-beaker.svg" alt="Science" />
```
