# Kenney 3D Models - CC0

## Download Instructions

1. Go to: https://kenney.nl/assets
2. Filter by "3D" category
3. Download these recommended packs:
   - **Nature Kit** - Trees, plants, rocks
   - **Robot Pack** - Robots, mechanical parts
   - **Space Kit** - Spaceships, planets, asteroids
   - **City Kit** - Buildings, streets, props
   - **Fantasy Kit** - Fantasy buildings, props
   - **Mini Dungeon** - Dungeon tiles, props
   - **Tiny Factory** - Industrial props
4. Extract GLB files to this folder

## File Formats

- **GLB** - Binary GLTF (recommended, single file)
- **GLTF** - JSON + separate resources
- **OBJ** - Wavefront OBJ (with MTL)

## Naming Convention

```
{category}-{name}-{variant}.glb
Examples:
- nature-tree-oak-01.glb
- character-robot-basic.glb
- prop-crate-wood-01.glb
- space-ship-fighter.glb
```
