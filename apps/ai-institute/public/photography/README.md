# Bhavya Foundation — Real Photography Archive

## Overview

This directory contains real documentary photographs from Himachal Pradesh, India.
All images are contextual photographs — they do not imply Bhavya Foundation activities
unless verified by repository evidence.

## Directory Structure

```
photography/
├── hero/           # Hero background photographs
│   └── hero-himalayan-sunset.jpg
├── forest/         # Forest mission photographs
│   └── forest-cedar-sunlight.jpg
├── knowledge/      # Knowledge mission photographs
│   └── knowledge-school-children.jpg
├── heritage/       # Heritage mission photographs
│   ├── heritage-stone-temple.jpg
│   └── heritage-wooden-temple.jpg
├── community/      # Community mission photographs
│   └── community-village-gathering.jpg
├── village/        # Supporting village photographs
└── metadata/
    └── photo_manifest.json
```

## Photo Placement Instructions

Place each photograph in its corresponding directory with the exact filename:

| Photo                       | Destination                                 | Description               |
| --------------------------- | ------------------------------------------- | ------------------------- |
| Himalayan sunset mountains  | `hero/hero-himalayan-sunset.jpg`            | Primary hero background   |
| Sunlit cedar forest         | `forest/forest-cedar-sunlight.jpg`          | Forest page hero          |
| School children +雪山       | `knowledge/knowledge-school-children.jpg`   | Knowledge page hero       |
| Stone temple architecture   | `heritage/heritage-stone-temple.jpg`        | Heritage page hero        |
| Wooden temple + mountains   | `heritage/heritage-wooden-temple.jpg`       | Heritage page alternative |
| Village community gathering | `community/community-village-gathering.jpg` | Community page hero       |

## Legal Notice

These are CONTEXTUAL REAL PHOTOGRAPHS. Never write copy such as:

- "Bhavya restored this forest"
- "Bhavya's school"
- "Bhavya's volunteers"
- "Bhavya's community project"

unless the repository contains verified evidence that the activity actually
belongs to Bhavya Foundation.

Use language such as:

- "Across the Himalayan communities we seek to serve."
- "Representative photograph — Himachal Pradesh."

## Provenance

Every image must be traceable to its original source. See `metadata/photo_manifest.json`
for photographer, source, location, license, and original source URL.
