# Bhavya Design Language

This document defines the design language and visual identity standards for the Bhavya Foundation platform.

## Brand Colors

- **Deep Forest Green**: #0D503C (Primary)
- **Earth Stone**: #8B7355 (Secondary)
- **Warm Gold**: #C9A84C (Accent)

## Typography

- **Primary Font**: Inter (Google Fonts)
- **Heading Weight**: 600-700
- **Body Weight**: 400

## Components

All UI components must follow the design system established in the design-system package.

## Accessibility

WCAG 2.1 AA compliance is required for all user interfaces.
