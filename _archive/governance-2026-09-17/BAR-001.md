# Bhavya Architecture Rules

This document defines the architectural rules and patterns that govern the Bhavya Foundation platform.

## Core Principles

1. **Domain Isolation**: Each mission domain (Forest, Heritage, Research, Volunteer) operates independently with no cross-domain dependencies.
2. **Shared Platform**: All mission apps consume content-core as the single source of truth.
3. **Single Publishing Pipeline**: All data flows through publish.ts to the Knowledge graph.
4. **Filesystem as Source of Truth**: JSON/Markdown files in the data directory are the canonical store.

## Technical Standards

- TypeScript strict mode for all packages
- Vitest for unit testing
- ESLint + Prettier for code quality
- pnpm workspaces for package management

## Architecture Decision Records

All significant architectural decisions must be documented as ADRs in the governance/adr directory.
