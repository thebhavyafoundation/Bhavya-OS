# Skill: Research

**Purpose:** Patterns and best practices for educational research
**Last Updated:** 2026-07-30

## README.md
This skill covers research methodologies for educational content creation.

## CONTEXT.md
When to use this skill: Any time you need to research a topic for curriculum development.

## patterns.md
- Source triangulation (3+ sources per claim)
- Local relevance mapping
- Misconception identification
- Prerequisite chain analysis

## examples.md
- How to research "What is AI?" for rural students
- How to find local examples in Himachal Pradesh
- How to document sources properly

## anti_patterns.md
- Using single source without verification
- Ignoring local context
- Creating circular definitions
- Skipping prerequisite analysis

## best_practices.md
- Always cite sources
- Include local examples
- Document misconceptions
- Map prerequisite chains
- Version all outputs
