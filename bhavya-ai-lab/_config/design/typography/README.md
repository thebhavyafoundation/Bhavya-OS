# Typography System

## Type Scale

| Token | Size | Line Height | Use Case |
|-------|------|-------------|----------|
| `text-xs` | 12px | 16px | Captions, labels |
| `text-sm` | 14px | 20px | Small text, descriptions |
| `text-base` | 16px | 24px | Body text |
| `text-lg` | 18px | 28px | Lead paragraphs |
| `text-xl` | 20px | 28px | Subheadings |
| `text-2xl` | 24px | 32px | Section headings |
| `text-3xl` | 30px | 36px | Page headings |
| `text-4xl` | 36px | 40px | Hero headings |
| `text-5xl` | 48px | 48px | Display headings |

## Font Families

| Token | Font | Use Case |
|-------|------|----------|
| `font-heading` | Poppins | Headings, titles |
| `font-body` | Inter | Body text, UI |
| `font-mono` | JetBrains Mono | Code, technical |

## Font Weights

| Token | Weight | Use Case |
|-------|--------|----------|
| `font-light` | 300 | Decorative |
| `font-regular` | 400 | Body text |
| `font-medium` | 500 | Emphasis |
| `font-semibold` | 600 | Strong emphasis |
| `font-bold` | 700 | Headings |

## Line Heights

| Token | Value | Use Case |
|-------|-------|----------|
| `leading-none` | 1 | Headings |
| `leading-tight` | 1.25 | Subheadings |
| `leading-normal` | 1.5 | Body text |
| `leading-relaxed` | 1.625 | Long-form reading |

## Letter Spacing

| Token | Value | Use Case |
|-------|-------|----------|
| `tracking-tight` | -0.025em | Headings |
| `tracking-normal` | 0 | Body text |
| `tracking-wide` | 0.025em | Labels, buttons |
