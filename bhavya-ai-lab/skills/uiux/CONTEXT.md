# CONTEXT — UI/UX Skill

## Purpose

Provide design intelligence for building professional UI/UX across Bhavya AI Lab outputs.

## When to Use

- Building websites or dashboards
- Creating educational interfaces
- Designing video layouts
- Ensuring accessibility compliance
- Generating design systems

## Inputs

- Project type (education, dashboard, landing page)
- Target audience
- Brand requirements
- Platform (web, mobile, desktop)

## Outputs

- Design system (colors, typography, spacing)
- Component specifications
- Accessibility checklist
- Layout patterns

## Dependencies

- Tailwind CSS (for utility classes)
- shadcn/ui (for component patterns)
- Google Fonts (for typography)

## Constraints

- Must be WCAG AA compliant
- Must support dark mode
- Must be responsive (375px - 1440px)
- Must support `prefers-reduced-motion`

## Quality Standards

- Color contrast ≥ 4.5:1
- Keyboard navigable
- Screen reader compatible
- Consistent spacing
- Clear visual hierarchy
