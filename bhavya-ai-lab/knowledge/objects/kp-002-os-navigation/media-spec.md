- What is Task Manager?

- When and how to close processes
- Safety rules

**Section 5: Keyboard Shortcuts That Save Time (300 words)**
- Essential shortcuts table
- Windows vs. Mac equivalents
- Practice exercises
- Tips for memorizing shortcuts

**Conclusion (100 words)**
- Summary of key points
- Call to action: practice daily
- Link to additional resources
