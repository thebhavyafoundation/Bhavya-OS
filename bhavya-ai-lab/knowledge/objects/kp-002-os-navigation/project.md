# Project: Personal Computer Navigation Guide

**Knowledge Package:** KP-002  
**Duration:** 1 week (in-class + homework)  
**Grade Level:** 9  
**Subject:** Digital Literacy  

---

## Project Overview

Create a comprehensive Personal Computer Navigation Guide that helps a new computer user feel confident navigating their operating system. Your guide will be a practical reference document that demonstrates your mastery of desktop navigation, window management, system settings, and keyboard shortcuts.

---

## Learning Objectives

By completing this project, you will:

1. Synthesize knowledge from all KP-002 concepts into a cohesive guide
2. Practice technical writing and instructional design
3. Demonstrate understanding through real-world examples
4. Create a useful resource that can help others learn

---

## Project Requirements

### Part 1: Desktop Interface Guide (20 points)

Create a section explaining the desktop interface for your chosen operating system.

**Must include:**
- Labeled diagram or annotated screenshot of the desktop
- Description of each component (taskbar, Start menu, icons, system tray)
- Step-by-step instructions for basic navigation
- Tips for organizing your desktop efficiently

**Format requirements:**
- Minimum 300 words
- At least 2 labeled screenshots
- Clear, step-by-step instructions

### Part 2: Window Management Guide (20 points)

Create a section on managing application windows.

**Must include:**
- Explanation of minimize, maximize, close, and restore
- How to resize and move windows
- How to arrange windows side by side
- How to switch between open applications
- Common window management problems and solutions

**Format requirements:**
- Minimum 300 words
- At least 1 screenshot showing window arrangement
- Troubleshooting section with 3 common problems

### Part 3: System Settings Guide (20 points)

Create a section on configuring system settings.

**Must include:**
- How to access settings on your OS
- Instructions for changing display settings
- Instructions for adjusting sound settings
- Instructions for connecting to Wi-Fi
- Privacy settings overview

**Format requirements:**
- Minimum 300 words
- At least 2 screenshots of settings screens
- Security/privacy recommendations

### Part 4: Keyboard Shortcuts Reference (20 points)

Create a keyboard shortcuts cheat sheet.

**Must include:**
- Table of at least 15 essential shortcuts
- Organized by category (navigation, editing, system)
- Windows and Mac equivalents (if applicable)
- Practice exercises for memorizing shortcuts

**Format requirements:**
- Well-organized table format
- Color coding or visual hierarchy
- Practice exercises section

### Part 5: Personal Reflection (20 points)

Write a reflection on your learning journey.

**Must include:**
- What you learned that surprised you
- Which skills you found most challenging
- How you plan to use these skills in other subjects
- Advice for a new computer user

**Format requirements:**
- Minimum 200 words
- Honest, personal voice
- Specific examples from your experience

---

## Deliverables

1. **Main Guide Document** (Word, PDF, or Google Doc)
   - All 5 sections combined
   - Professional formatting with headings and subheadings
   - Minimum 1,500 words total

2. **Screenshots Folder**
   - All referenced screenshots with descriptive filenames
   - Minimum 5 screenshots total

3. **Presentation** (Optional bonus: +10 points)
   - 5-slide presentation summarizing your guide
   - Include visuals from your guide

## Sample Topics and Approaches

### For Windows Users:
- Focus on Windows 11 snap layouts and virtual desktops
- Include Windows-specific shortcuts (Win key combinations)
- Cover Windows Security and Update settings

### For macOS Users:
- Focus on Stage Manager and Mission Control
- Include macOS-specific shortcuts (Cmd key combinations)
- Cover System Preferences and Privacy settings

### For Linux Users:
- Focus on GNOME desktop customization
- Include terminal shortcuts as a bonus
- Cover Ubuntu-specific settings and tools

---

## Tips for Success

1. **Start with screenshots** — Take all your screenshots first, then write around them
2. **Use your own words** — Don't copy from online sources; explain things as you understand them
3. **Test everything** — Make sure your instructions actually work before writing them down
4. **Ask for help** — If you're stuck, ask a classmate or teacher
5. **Proofread** — Check spelling and grammar before submitting
