## Section A: Scenario-Based Multiple Choice (5 questions)

**Instructions:** Read each scenario carefully. Select the best answer.

### Question 1

Your friend opens Task Manager and sees that their CPU usage is at 95%. One process called "Windows Audio Device Graph Isolation" is using 60% of the CPU. They ask you: "Should I close this process?"

What is the BEST advice?

A) Yes — any process using that much CPU should be closed immediately
B) No — this is a system process that your computer needs to run audio; closing it will break sound
C) Yes — but only after saving all open files
D) No — you should restart the computer instead of closing any process

**Answer:** B
**Explanation:** System processes with names like "Windows Audio Device Graph Isolation" are essential OS components. Closing them breaks functionality. The correct approach is to identify whether a process is one YOU opened (safe to close) or a system process (never close). Audio issues from closing this process would require a restart to fix.

### Question 2

You are writing an essay with research material open in a browser window. You need to copy a quote from the browser and paste it into your document. Which arrangement is MOST efficient?

A) Keep switching between the two windows using the taskbar
B) Arrange the browser and document side by side using Snap, then use Ctrl+C and Ctrl+V
C) Maximize the browser, copy the quote, minimize it, then maximize the document and paste
D) Write the quote down on paper, then type it into the document

**Answer:** B
**Explanation:** Side-by-side arrangement eliminates the need to switch between windows, and keyboard shortcuts (Ctrl+C, Ctrl+V) are faster than any other method. This combines two efficient techniques for maximum productivity.

### Question 3

A student says: "I minimized my web browser, but I can still hear a video playing from it. How is that possible if I minimized it?"

What is the BEST explanation?

A) Minimizing a window closes the program
B) Minimizing a window only hides it from view — the program keeps running in the background, including audio
C) The video is actually playing from a different application
D) The computer is broken and needs to be restarted

**Answer:** B
**Explanation:** Minimizing hides the window but does not stop the program. The browser continues to run, process data, and play audio. To stop the video, you would need to pause it, close the tab, or close the browser entirely.

### Question 4

Your classmate discovers that 12 apps currently have access to their microphone. Three of those apps are ones they've never used. What should they do FIRST?

A) Delete all the apps immediately
B) Turn off the microphone entirely in privacy settings
C) Review each app's microphone permission and disable it for apps they don't use or trust
D) Ignore it — microphone access doesn't matter

**Answer:** C
**Explanation:** Privacy settings require selective management. Disabling ALL microphone access breaks apps you need (like video calling). Deleting apps is extreme. The correct approach is to review each permission individually and disable access for untrusted or unused apps.

### Question 5

You notice your computer has been running slowly for the past hour. You open Task Manager and see that memory usage is at 92%. Which combination of actions is MOST likely to help?

A) Close unused browser tabs and applications you're not actively using
B) Restart the computer immediately
C) Download more RAM from the internet
D) Change the wallpaper to a simpler image

**Answer:** A
**Explanation:** High memory usage means too many programs are running simultaneously. Closing unused applications frees memory immediately. Restarting is a secondary option if closing programs doesn't help. You cannot download RAM (it's physical hardware), and wallpaper has no effect on performance.

## Section B: Scenario-Based Short Answer (5 questions)

**Instructions:** Answer each scenario in 3-5 complete sentences.

### Question 6

**Scenario:** Your friend just got their first laptop. They call you and say: "I opened five browser tabs and now my computer is making the fan spin really loud. Is it broken?"

Write what you would tell them, including:
- What the loud fan probably means
- How to check what's happening
- What they can do about it

**Sample Answer:**
The loud fan means your computer is working hard to cool itself — it's not broken. When you open many tabs, each one uses memory and processing power, which generates heat. Your fan spins faster to cool the system. To check, press Ctrl+Shift+Esc to open Task Manager and look at CPU and memory usage. If they're high, close tabs you're not using. The fan will quiet down as the workload decreases. This is normal behavior, not a sign of damage.

**Evaluation Criteria:**
- Correctly identifies high resource usage as the cause
- Knows how to open Task Manager
- Provides actionable solution (close tabs)
- Reassures without alarming

### Question 7

**Scenario:** A student says: "I pressed Alt+Tab and a bunch of windows appeared, but when I let go, the wrong one came to the front. How do I fix this?"

Explain what happened and how to use Alt+Tab correctly.

**Sample Answer:**
Alt+Tab shows a preview of all open windows. While holding Alt, you press Tab to move through the windows — each press highlights the next one. The window that's highlighted when you release Alt is the one that opens. If the wrong one appeared, they probably released Alt too early or pressed Tab one too many times. To fix it: hold Alt, press Tab repeatedly until the correct window is highlighted, then release Alt. If you overshoot, keep pressing Tab — it cycles back to the beginning.

**Evaluation Criteria:**
- Correctly explains how Alt+Tab cycling works
- Identifies the likely user error (releasing too early)
- Provides clear corrective steps
- Mentions the cycling behavior

### Question 8

**Scenario:** You're helping a teacher set up their classroom computer. They ask: "Why should I care about privacy settings on a computer that only I use?"

Write a response explaining why privacy settings matter even on a personal computer.

**Sample Answer:**
Privacy settings matter even on a personal computer for several reasons. First, many applications request access to your camera, microphone, and location by default — some you may not even be aware of. Second, if your computer is ever compromised by malware, strong privacy settings limit what an attacker can access. Third, some apps collect and share your data for advertising purposes, which you can control through privacy settings. Finally, if you ever sell or give away the computer, past data could be recovered if permissions were too open. Checking privacy settings is quick and protects you from risks you might not anticipate.

**Evaluation Criteria:**
- Provides multiple valid reasons
- Addresses the specific concern (personal use)
- Includes concrete examples
- Shows understanding of digital citizenship

### Question 9

**Scenario:** Your friend shows you their desktop — it has 47 icons scattered everywhere, files mixed with application shortcuts, and no visible organization. They say: "I can find everything I need, so why does it matter?"

Write a response explaining why desktop organization matters, even if they think they can find things.

**Sample Answer:**
While you might find things now, a cluttered desktop causes real problems. First, every icon uses a small amount of memory — 47 icons slow down your computer, especially at startup when Windows has to load all of them. Second, as you add more files, finding things gets progressively harder. What works for 47 icons won't work for 100. Third, a clean desktop with organized folders helps you work faster because your brain doesn't have to process visual clutter. Try this: create folders for different categories (School, Personal, Projects) and move your files into them. You'll find things faster and your computer will start up quicker.

**Evaluation Criteria:**
- Acknowledges the student's perspective
- Provides concrete reasons (memory, speed, scalability)
- Offers a practical solution
- Uses evidence-based reasoning

### Question 10

**Scenario:** You're taking a test on a school computer. You accidentally close the document you were working on without saving. You need to recover it.

What steps would you try, in order, to recover your work?

**Sample Answer:**
First, I'd check if the application has an auto-recovery feature — many text editors and word processors save temporary copies. I'd reopen the application and look for "Recover unsaved documents" or a similar option. Second, I'd check the Recycle Bin or Trash to see if the file was accidentally deleted. Third, I'd look in the application's temporary files folder — some programs save to a temp directory. Fourth, if the application supports version history (like Google Docs), I'd check for previous versions. Finally, if nothing works, I'd accept the loss and retype what I remember, using Ctrl+S frequently this time to prevent future loss.

**Evaluation Criteria:**
- Provides ordered, logical steps
- Knows about auto-recovery features
- Checks Recycle Bin/Trash
- Mentions prevention (Ctrl+S habit)
- Realistic about recovery limitations

## Section C: Debugging Questions (3 questions)

**Instructions:** Analyze each situation. Explain what went wrong and how to fix it.

### Question 11

**Screenshot scenario:** A student shows you their Task Manager. It shows:
- CPU: 12%
- Memory: 45%
- Disk: 98%

They say: "My computer is slow, but CPU and memory look fine. What's wrong?"

**What is the problem and what should they do?**

**Sample Answer:**
The problem is disk usage at 98%, not CPU or memory. When disk usage is that high, the hard drive is overwhelmed — it can't read or write data fast enough, which makes everything feel slow. This often happens when Windows is updating, when many programs are saving files simultaneously, or when the hard drive is failing. To fix it: close any unnecessary programs to reduce disk activity. If the problem persists, check if Windows Update is running. If disk usage stays at 98% for hours, the hard drive may need to be replaced with an SSD (solid-state drive), which is much faster.

**Evaluation Criteria:**
- Correctly identifies disk usage as the bottleneck
- Understands the relationship between disk speed and system performance
- Provides immediate and long-term solutions
- Shows awareness of hardware implications

### Question 12

**Screenshot scenario:** A student tries to paste text using Ctrl+V but nothing happens. The text was already copied (they confirmed with Ctrl+C). The cursor is blinking in a text field.

What are THREE possible reasons the paste isn't working, and how would you troubleshoot each?

**Sample Answer:**
1. **The text field doesn't accept pasted content.** Some secure fields (like password inputs) block pasting. Try right-clicking and selecting "Paste" from the context menu. If that doesn't work, the field may not support paste at all.
2. **The clipboard was overwritten.** If the student copied something else after copying the text, the original text is gone. Re-copy the text with Ctrl+C and try pasting again immediately.
3. **The application has a different paste shortcut.** Some applications use Ctrl+Shift+V for plain text paste, or Ctrl+Insert for paste. Try these alternatives. Also check if the application has a "Paste" option in the Edit menu.

**Evaluation Criteria:**
- Identifies three distinct, plausible causes
- Provides troubleshooting steps for each
- Shows understanding of clipboard mechanics
- Knows about application-specific variations

### Question 13

**Screenshot scenario:** A student arranges two windows side by side. The left window looks normal, but the right window is compressed and text wraps awkwardly. They say: "I snapped both windows to the edges, but the right one looks weird."

What is probably happening and how would you fix it?

**Sample Answer:**
The right window is probably being compressed because Snap is trying to fill available space, but the window's minimum size is larger than the half-screen width. This can happen if the display resolution is low, if the window has a minimum size requirement, or if another window or toolbar is taking up space. To fix it: try dragging the Snap divider between the two windows to give the right window more space. Alternatively, maximize the right window and manually resize it to your preferred width. You can also try changing the display resolution to give more screen real estate. Another option: use Windows 11's Snap Layouts (Win+Z) to choose a layout that better fits your needs.

**Evaluation Criteria:**
- Understands Snap behavior and constraints
- Identifies multiple potential causes
- Provides practical solutions
- Knows about Snap Layouts as an alternative

## Section D: Architecture Decision Questions (2 questions)

**Instructions:** Analyze each situation. Explain your reasoning.

### Question 14

A school IT administrator needs to configure 30 student computers. They must balance student freedom with school safety. For EACH setting below, recommend a configuration and explain your reasoning:

1. **Camera access:** Allow or restrict?
2. **Wallpaper changes:** Allow or restrict?
3. **Software installation:** Allow or restrict?
4. **Night light/blue light filter:** Enable by default or not?

**Sample Answer:**
1. **Camera access: Restrict.** Students don't need camera access for most schoolwork, and unrestricted access creates privacy risks. Enable only for specific apps like video conferencing when needed.
2. **Wallpaper changes: Allow.** This is a low-risk customization that makes students feel ownership of their workspace. It doesn't affect security or performance.
3. **Software installation: Restrict.** Students could install malware, inappropriate content, or resource-heavy programs that slow shared computers. Installation should require admin approval.
4. **Night light: Enable by default.** Students often use computers for extended periods. Blue light filtering reduces eye strain and improves sleep quality. Students can disable it if they prefer.

**Evaluation Criteria:**
- Provides clear recommendation for each setting
- Explains reasoning with practical considerations
- Balances freedom and safety appropriately
- Shows awareness of school-specific concerns

### Question 15

You're designing a "Quick Start Guide" for new students who have never used a computer. You can only include FIVE skills, in order of priority.

List your five skills and explain why each one is more important than the one that follows it.

**Sample Answer:**
1. **Turning on and off the computer safely** — This is the most fundamental skill. Without it, nothing else matters. Students must know the proper shutdown procedure to avoid data loss or corruption.
2. **Using the mouse/trackpad to click, drag, and right-click** — Pointing and clicking is how you interact with everything on screen. Before learning any keyboard shortcuts, students need to be comfortable with basic pointing.
3. **Opening and closing applications** — Students need to access tools (browser, text editor) before they can do anything productive. This teaches the Start menu/App launcher concept.
4. **Switching between windows (Alt+Tab)** — Multitasking is essential for schoolwork. This single shortcut transforms how students work and is faster than any mouse-based method.
5. **Copying and pasting (Ctrl+C, Ctrl+V)** — The most universally useful shortcut. Students copy information constantly for assignments, and this saves significant time.

**Evaluation Criteria:**
- Logical priority ordering
- Justification for each ranking
- Practical reasoning tied to student needs
- Understanding of dependency (skill 1 enables skill 2, etc.)
