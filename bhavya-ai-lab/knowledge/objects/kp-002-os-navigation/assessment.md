## Section A: Multiple Choice Questions (5 questions)

**Instructions:** Select the best answer for each question.

### Question 1
What does the taskbar show?

A) Only open applications  
B) Open applications and system icons  
C) Only the Start button  
D) Only the clock  

**Answer:** B  
**Explanation:** The taskbar displays open applications, system icons (network, volume, clock), and the Start button. It provides quick access to running programs and system information.

### Question 2
Which keyboard shortcut copies selected text?

A) Ctrl + V  
B) Ctrl + X  
C) Ctrl + C  
D) Ctrl + Z  

**Answer:** C  
**Explanation:** Ctrl + C (or Cmd + C on Mac) copies the selected text to the clipboard. Ctrl + V pastes, Ctrl + X cuts, and Ctrl + Z undoes.

### Question 3
What happens when you minimize a window?

A) The program closes completely  
B) The window hides but the program keeps running  
C) The program stops running  
D) The window moves to the desktop  

**Answer:** B  
**Explanation:** Minimizing a window hides it from view but the program continues running in the background. You can restore it by clicking its icon on the taskbar.

### Question 4
Which utility shows running processes and system resource usage?

A) Control Panel  
B) File Explorer  
C) Task Manager  
D) Start Menu  

**Answer:** C  
**Explanation:** Task Manager displays running processes, CPU usage, memory consumption, and other system information. It helps monitor and manage system performance.

### Question 5
What does restarting your computer do?

A) Damages the hardware  
B) Deletes all your files  
C) Clears memory and closes stuck processes  
D) Makes the computer slower  

**Answer:** C  
**Explanation:** Restarting clears temporary memory (RAM), closes stuck processes, installs updates, and improves overall performance. It is good maintenance practice.

## Section B: Short-Answer Questions (5 questions)

**Instructions:** Answer each question in 2-3 complete sentences.

### Question 6
Explain the difference between minimizing and closing a window. When would you use each action?

**Sample Answer:**  
Minimizing a window hides it from view but keeps the program running in the background. You can restore it by clicking its taskbar icon. Closing a window removes it from the screen and may end the program entirely. I minimize when I want to quickly switch between applications, and close when I'm finished with a program.

### Question 7
Describe three keyboard shortcuts you can use while working on a computer. Include what each shortcut does.

**Sample Answer:**  
1. Ctrl + C copies selected text to the clipboard for pasting elsewhere.  
2. Alt + Tab switches between open windows, allowing quick navigation between applications.  
3. Ctrl + Z undoes the last action, which is useful when making mistakes in documents.

### Question 8
What information does Task Manager display about your computer?

**Sample Answer:**  
Task Manager shows the list of running processes, CPU usage percentage, memory (RAM) usage, disk activity, and network usage. It also shows how much total memory is available and which programs are using the most resources. This helps identify slow programs or processes that need to be closed.

### Question 9
Why is it important to configure privacy settings on your computer?

**Sample Answer:**  
Privacy settings control which apps can access your camera, microphone, location, and personal data. Configuring them protects your privacy and prevents unauthorized access to sensitive information. For example, disabling location tracking for unnecessary apps prevents them from monitoring your movements.

### Question 10
What are the benefits of using keyboard shortcuts instead of the mouse?

**Sample Answer:**  
Keyboard shortcuts are faster than navigating menus with a mouse, increasing productivity. They allow you to keep your hands on the keyboard while working, reducing interruptions. They also enable performing complex actions with simple key combinations, making tasks like copying, pasting, and switching windows more efficient.
