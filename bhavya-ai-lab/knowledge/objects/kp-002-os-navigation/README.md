# KP-002: Operating System Navigation

## Project Overview

**Knowledge Package ID:** kp-002-os-navigation  
**Domain:** Digital Foundations  
**Grade:** 9  
**Subject:** Digital Literacy  
**Duration:** 2 hours  
**Difficulty:** Beginner  

## Learning Objective

Navigate a desktop operating system to manage windows, settings, and system resources.

## Learning Outcomes

Upon completing this knowledge package, students will be able to:

1. **Identify** the components of a desktop interface including taskbar, Start menu, icons, and windows
2. **Manage** application windows by opening, closing, minimizing, maximizing, resizing, and arranging them
3. **Configure** basic system settings for display, sound, network, and privacy
4. **Monitor** system performance using Task Manager to view running processes, CPU usage, and memory
5. **Apply** keyboard shortcuts to perform common navigation and editing tasks efficiently
6. **Evaluate** system resources and identify when a computer needs maintenance or restart
7. **Create** a personal computer navigation guide demonstrating understanding of OS concepts

## Prerequisites

- **kp-001-computer-basics**: Understanding of basic computer components and terminology

| Concept | Difficulty | Description |
|---------|------------|-------------|

| Window Management | Beginner | Arranging, resizing, minimizing, maximizing, and switching between application windows |
| System Settings | Intermediate | Configuring display, sound, network, and privacy settings |
| Task Manager | Intermediate | Monitoring and managing running processes, CPU usage, and memory |
| Keyboard Shortcuts | Beginner | Common shortcuts for navigation, copy/paste, and system functions |

## Key Definitions

- **Operating System**: The main software that manages computer hardware and provides a user interface
- **Taskbar**: The horizontal bar at the bottom of the screen showing open applications and system icons
- **Start Menu**: The menu providing access to applications and settings
- **Window**: A rectangular area on screen displaying an application or document
- **Process**: A running program that the operating system manages
