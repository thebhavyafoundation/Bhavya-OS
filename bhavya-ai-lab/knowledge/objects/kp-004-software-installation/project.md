# Project: Software Installation Guide

**Duration:** 45 minutes
**Grade:** 9 | **Subject:** Digital Literacy
**Type:** Individual Project

---

## Project Overview

Create a comprehensive software installation guide for an application of your choice. Your guide will serve as a reference document that someone with no technical experience could follow to install, configure, and maintain the software safely.

## Learning Objectives

- Apply knowledge of safe download sources and installation procedures
- Practice clear technical writing with step-by-step instructions
- Develop the ability to anticipate common problems and provide solutions

## Requirements

### Application Selection

Choose ONE application from the following list or propose your own (must be approved by teacher):

## Guide Structure

Your project must include the following sections:

### Section 1: Application Overview (10 points)

- Name and version of the software
- What the software does (2-3 sentences)
- System requirements (minimum and recommended)
- License type (free, open-source, paid, subscription)
- Estimated installation time

### Section 2: Download Instructions (15 points)

- Exact URL for the official download page
- How to verify you are on the official site (at least 3 verification steps)
- Which version to download for your operating system
- File size and download time estimate
- What to do if the download is slow or fails

### Section 3: Installation Steps (20 points)

- Numbered step-by-step instructions
- Screenshots or diagrams for each major step
- What to click at each dialog box
- Which options to select or deselect (explain why)
- How to handle common installation prompts:
  - License agreement acceptance
  - Installation directory choice
  - Bundled software offers
  - Permission requests

### Section 4: First-Time Configuration (15 points)

- Essential settings to change immediately
- Account creation steps (if required)
- Privacy settings to review
- Default file format and save location
- Recommended preferences for beginners

### Section 5: Keeping It Updated (10 points)

- How to check for updates
- How to enable automatic updates
- What updates typically include
- What to do if an update fails

### Section 6: Troubleshooting (15 points)

Common problems and solutions:

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| Installer won't open | Insufficient permissions | Right-click > Run as administrator |
| Installation freezes | Insufficient disk space | Free space and try again |
| Program crashes on launch | Corrupted installation | Uninstall and reinstall |
| Missing features | Wrong version downloaded | Verify system requirements |
| Slow performance | Too many background programs | Close other applications |

Include at least 5 common problems specific to your chosen application.

### Section 7: Uninstallation (10 points)

- How to properly uninstall the software
- How to verify complete removal
- How to clean up residual files
- What data you might lose during uninstallation

### Section 8: Safety Tips (5 points)

- At least 3 safety tips for software installation
- How to verify a download is not malware
- What to do if you accidentally install unwanted software

## Evaluation Rubric

| Criterion | Excellent (A) | Good (B) | Satisfactory (C) | Needs Work (D) |
|-----------|--------------|----------|-------------------|----------------|
| **Accuracy** | All steps are correct and verifiable | Most steps correct, minor errors | Some errors that could cause confusion | Major errors or unsafe advice |
| **Clarity** | A beginner could follow without help | Mostly clear with minor ambiguity | Requires some technical knowledge | Confusing or incomplete |
| **Completeness** | All 8 sections thorough and detailed | Most sections complete | Missing 1-2 sections | Missing 3+ sections |
| **Safety Focus** | Security emphasized throughout | Security mentioned in key places | Minimal safety content | No safety guidance |
| **Visuals** | Clear screenshots/diagrams for every step | Most steps illustrated | Some visuals | No visuals |

## Submission Format

Submit your guide as a **Markdown file** (`.md`) with the following naming convention:

```
software-guide-[your-name]-[application-name].md
```

Example: `software-guide-priya-sharma-vlc.md`

## Extension Activities

For students who finish early:

1. **Video Tutorial:** Record a screen-capture video walking through the installation process
2. **Multilingual Guide:** Translate your guide into Hindi
3. **Comparison Guide:** Install the same type of software from two different sources and compare the experience
4. **Security Audit:** Research the software's security history using CVE databases

---

## Presentation

Each student will present their guide to the class in a 3-minute presentation covering:
- Which application they chose and why
- The most important safety tip they discovered
- One unexpected problem they encountered and how they solved it
