# Project: Software Installation Guide

**Duration:** 45 minutes
**Grade:** 9 | **Subject:** Digital Literacy
**Type:** Individual Project

---

## Project Overview

Create a professional-grade Software Installation Guide that could live on GitHub as a portfolio piece. This is not a classroom exercise — it is a reference document that a real person with no technical experience could follow. Write it as if you are publishing it for the world.

## Learning Objectives

- Apply knowledge of safe download sources and installation procedures
- Practice clear technical writing with step-by-step instructions
- Develop the ability to anticipate common problems and provide solutions
- Build a portfolio-quality document with proper structure and presentation

---

## Section Breakdown

### Section 1: Application Overview (15 points)

- Name and current version of the software
- What the software does (2-3 sentences, written for a beginner)
- System requirements (minimum and recommended)
- License type (free, open-source, paid, subscription) with a brief explanation of what the license means
- Estimated installation time
- **Software comparison table** comparing your chosen software with two alternatives

### Section 2: Download Instructions (20 points)

- Exact URL for the official download page
- **Five-step verification process** proving this is the official source:
  1. Domain name check
  2. HTTPS verification
  3. Copyright/corporate identity check
  4. Cross-reference with app store
  5. Community reputation check (search for reviews)
- Which version to download for your operating system and why
- File size and download time estimate
- What to do if the download is slow or fails
- **Screenshot or diagram** showing the official download page with key elements highlighted

### Section 3: Installation Steps (25 points)

- Numbered step-by-step instructions
- Screenshots or diagrams for each major step
- What to click at each dialog box
- Which options to select or deselect with explanations for each choice
- How to handle common installation prompts:
  - License agreement acceptance (what you are agreeing to)
  - Installation directory choice (why default is usually fine)
  - Bundled software offers (always uncheck unless you want it)
  - Permission requests (evaluate each one)
- **Decision annotations** at each step explaining your choice

### Section 4: First-Time Configuration (15 points)

- Essential settings to change immediately (with screenshots)
- Account creation steps if required
- Privacy settings to review (list specific settings)
- Default file format and save location
- Recommended preferences for beginners
- **Configuration rationale** explaining why each setting matters

### Section 5: Keeping It Updated (10 points)

- How to check for updates
- How to enable automatic updates
- What updates typically include
- What to do if an update fails
- **Update schedule recommendation** for the user

### Section 6: Troubleshooting (15 points)

Create a troubleshooting table with at least 5 problems specific to your chosen application:

| Problem | Likely Cause | Solution | Prevention |
|---------|-------------|----------|------------|
| [Specific error] | [Cause] | [Step-by-step fix] | [How to avoid it] |

Include: error messages users might see, compatibility issues, performance problems, and configuration conflicts.

### Section 7: Uninstallation (10 points)

- How to properly uninstall the software
- How to verify complete removal
- How to clean up residual files
- What data you might lose during uninstallation
- **Pre-uninstallation checklist** (backup data, export settings)

### Section 8: Security Checklist (10 points)

Create a security checklist for your software:

- [ ] Downloaded from official source only
- [ ] Verified digital signature
- [ ] No bundled software installed
- [ ] Automatic updates enabled
- [ ] Permissions reviewed and restricted
- [ ] Privacy settings configured
- [ ] Backup of default settings created

Explain each item: why it matters and how to verify it.

### Section 9: Reflection (15 points)

Write a 200-300 word reflection covering:
- Why you chose this software
- What you learned during the installation process
- One unexpected thing you discovered
- How your understanding of software safety has changed
- What advice you would give to someone installing this software for the first time

## Evaluation Rubric

| Criterion | Excellent (A) | Good (B) | Satisfactory (C) | Needs Work (D) |
|-----------|--------------|----------|-------------------|----------------|
| **Accuracy** | All steps correct, verified, tested | Most steps correct, minor errors | Some errors that could cause confusion | Major errors or unsafe advice |
| **Clarity** | A complete beginner could follow without help | Mostly clear with minor ambiguity | Requires some technical knowledge | Confusing or incomplete |
| **Completeness** | All 9 sections thorough and detailed | Most sections complete | Missing 1-2 sections | Missing 3+ sections |
| **Safety Focus** | Security woven throughout every section | Security mentioned in key places | Minimal safety content | No safety guidance |
| **Visuals** | Screenshots/diagrams for every major step | Most steps illustrated | Some visuals | No visuals |
| **Portfolio Quality** | Could publish on GitHub as-is | Minor polish needed | Classroom quality only | Not publication ready |
| **Reflection** | Deep insight, specific examples, genuine voice | Good reflection with some depth | Surface-level reflection | Missing or generic |
