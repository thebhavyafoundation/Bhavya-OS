# Assessment: Software Installation

**Total Questions:** 15
**Duration:** 45 minutes
**Grade:** 9 | **Subject:** Digital Literacy

---

## Section A: Multiple Choice Questions (5 questions, 2 points each)

### Question 1
What is the primary purpose of a software installer?

- A) To delete files from your computer
- B) To copy program files, configure settings, and register the application with the operating system
- C) To connect your computer to the internet
- D) To scan your computer for viruses

**Correct Answer:** B
**Concept:** Installation Methods

---

### Question 2
Which of the following is the safest source for downloading software?

- A) A torrent website offering free versions of paid software
- B) An advertisement pop-up promising a free download
- C) The official website of the software developer
- D) A random blog post with a download link

**Correct Answer:** C
**Concept:** Installation Methods

---

### Question 3
What is a software patch?

- A) A physical component added to a computer
- B) An update that fixes bugs, closes security holes, or adds features
- C) A type of software license
- D) A tool for uninstalling software

**Correct Answer:** B
**Concept:** Updates and Patches

---

### Question 4
What is the correct term for the legal agreement that governs how you can use software?

- A) Installer
- B) License
- C) Patch
- D) Configuration

**Correct Answer:** B
**Concept:** Software Types

---

### Question 5
Why should you uncheck pre-selected options during software installation?

- A) They slow down your internet connection
- B) They may install unwanted additional software or change your browser settings
- C) They are always viruses
- D) They make the installation take longer

**Correct Answer:** B
**Concept:** Installation Methods

## Section B: Short Answer Questions (5 questions, 4 points each)

### Question 6
Explain the difference between system software and application software. Give two examples of each.

**Marking Guide:**
- System software definition (1 mark)
- Two system software examples (1 mark)
- Application software definition (1 mark)
- Two application software examples (1 mark)

### Question 7
Describe three steps you should take to verify that a software download is safe before running the installer.

**Marking Guide:**
- Verify the URL is the official domain (1 mark)
- Check for HTTPS/secure connection (1 mark)
- Verify digital signatures or publisher information (1 mark)
- Clear, logical explanation (1 mark)

- Logical reasoning (1 mark)

### Question 10
You just installed a new application, but it is asking for permission to access your camera and microphone. The application is a note-taking tool. Should you grant these permissions? Explain your reasoning.

**Marking Guide:**
- Correct answer: No (1 mark)
- Explanation that note-taking apps do not need camera/microphone (1 mark)

## Section C: Reflection Questions (3 questions, 5 points each)

### Question 11
Describe a time when you or someone you know experienced a problem caused by software — a crash, a virus, or an unwanted program. What happened, how was it discovered, and what was done to fix it? What could have been done to prevent it?

**Marking Guide:**
- Clear description of the problem (2 marks)
- Explanation of how it was discovered (1 mark)
- Description of the solution (1 mark)
- Prevention strategy that demonstrates learning (1 mark)

### Question 12

**Marking Guide:**

- Describes realistic consequences (2 marks)
- Shows understanding of software dependency (1 mark)
- Thoughtful adaptation plan (1 mark)

### Question 13

## Section D: Practical Questions (2 questions, 7.5 points each)

### Question 14
You are helping a family member install a web browser on their new computer. They have never installed software before. Write a step-by-step guide (minimum 8 steps) that covers:
- Finding the official website
- Downloading the correct version
- Running the installer
- Configuring basic settings after installation

**Marking Guide:**
- Clear, numbered steps (2 marks)
- Safety verification included (2 marks)
- Configuration steps included (2 marks)
- Written for a non-technical audience (1.5 marks)

---

### Question 15
A classmate tells you they found a website offering Microsoft Office for free. They want to download it. Write a message to your classmate explaining:
1. Why this download might be dangerous
2. What they should look for to verify the source
3. Two legitimate alternatives for getting productivity software

**Marking Guide:**
- Explanation of malware risks (2 marks)
- Verification steps provided (2 marks)
- At least two legitimate alternatives (2 marks)
- Clear, persuasive communication (1.5 marks)
