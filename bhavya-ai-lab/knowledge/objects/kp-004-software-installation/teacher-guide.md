# Teacher Guide: Software Installation

**Duration:** 2 hours (2 × 45-minute sessions + 30-minute lab)
**Grade:** 9 | **Subject:** Digital Literacy

---

## Session Overview

| Session | Time | Focus | Format |
|---------|------|-------|--------|
| Session 1 | 45 min | Software types, safe sources, installation process | Lecture + Discussion |
| Lab | 30 min | Hands-on installation exercises | Individual Lab Work |
| Session 2 | 45 min | Configuration, updates, uninstallation | Lecture + Activity + Assessment |

---

## Materials and Preparation

### Required Materials

- Computer with internet access (teacher's machine for demonstration)
- Projector or shared screen
- Student computers with administrative access
- Internet connection for student machines
- Text editor or notebook for each student

### Pre-Class Preparation

1. **Test the network:** Ensure internet access works on all student machines
2. **Pre-download installers:** Download VLC Media Player, GIMP, and Notepad++ installers to a shared folder in case internet is slow
3. **Prepare a sample application:** Have a simple application ready for live demonstration
4. **Set up a shared drive:** Create a folder where students can save their work

### Recommended Software for Lab

| Application | Size | Purpose |
|-------------|------|---------|
| VLC Media Player | ~40 MB | Media player installation |
| GIMP | ~300 MB | Image editor (demonstrates larger installs) |
| Notepad++ | ~5 MB | Text editor (quick install for demonstrations) |

## Session 1: What Software Is and Where It Comes From (45 minutes)

### Timeline

| Time | Activity | Method |
|------|----------|--------|
| 0:00 - 0:05 | Warm-up: Ask students what software they used today | Class discussion |
| 0:05 - 0:20 | Section 1: Software Types | Lecture with visuals |
| 0:20 - 0:25 | Activity: Classify programs on the class computer | Live demo |
| 0:25 - 0:40 | Section 2: Safe Sources and Installation | Lecture with demonstration |
| 0:40 - 0:45 | Q&A and preview of lab | Discussion |

### Discussion Prompts

**Opening Prompt (5 minutes):**
"Think about everything you did on a computer or phone today. List every application you used. Which ones came pre-installed? Which ones did you or someone else install?"

**After Section 1:**
"Why do you think operating systems come pre-installed on computers but other software does not?"

**After Section 2:**
"Have you ever downloaded something that turned out to be not what you expected? What happened? What did you learn?"

**Common Misconception to Address:**
Students often believe free software is less safe than paid software. Use examples like VLC, Firefox, and LibreOffice to show that many free tools are industry-standard and more secure than some paid alternatives.

### Teaching Tips

- **Use real examples:** Open the class computer's program list and classify items live
- **Show the fake vs. real:** Search for "download VLC" and show students how to distinguish the official site from ad-supported download portals
- **Emphasize habit formation:** The goal is to build the habit of verifying sources, not just memorizing steps

## Lab Session: Hands-On Installation (30 minutes)

### Setup

- Students work individually or in pairs
- Each student needs admin access to install software
- Teacher circulates to assist and verify progress

### Expected Challenges

| Challenge | Solution |
|-----------|----------|
| Slow internet | Use pre-downloaded installers from shared drive |
| Insufficient permissions | Use teacher's admin account to unlock |
| Installer fails to open | Check file extensions, run as administrator |
| Students distracted by browsing | Monitor screens, redirect to task |

### Monitoring Checkpoints

| Minute | Check |
|--------|-------|
| 5 min | All students have identified their OS and disk space |
| 10 min | All students have found an official download source |
| 15 min | All students have downloaded the installer |
| 20 min | Most students have completed installation |
| 25 min | All students have configured the application |
| 30 min | All students have begun uninstallation |

## Session 2: Configuration, Updates, and Cleanup (45 minutes)

### Timeline

| Time | Activity | Method |
|------|----------|--------|
| 0:00 - 0:05 | Warm-up: What did you install in the lab? | Quick share |
| 0:05 - 0:15 | Section 4: Software Configuration | Lecture |
| 0:15 - 0:25 | Section 5: Updates and Patches | Lecture + live demo |
| 0:25 - 0:35 | Section 6: Uninstallation | Lecture + demo |
| 0:35 - 0:40 | Common misconceptions review | Group activity |
| 0:40 - 0:45 | Assessment introduction and expectations | Instructions |

### Live Demonstration: Checking for Updates

Show students on the projector:

**Windows:**
1. Open Settings > Update & Security > Windows Update
2. Click "Check for updates"
3. Show what updates are available and what they fix

**Linux (if applicable):**
1. Open terminal
2. Run `sudo apt update && sudo apt list --upgradable`
3. Show the list of available updates

### Discussion Prompts

**After Configuration:**
"Why do you think applications ask for permissions? Is it always necessary? How do you decide whether to grant a permission?"

**After Updates:**
"Can you think of a famous security breach that happened because people did not update their software? (Examples: WannaCry ransomware, Equifax breach)"

**After Uninstallation:**
"Why is it not enough to just delete a program's shortcut from your desktop?"

### Assessment Administration

- Distribute assessment sheets
- Allow 45 minutes for completion
- Remind students to read each question carefully
- Circulate to answer clarifying questions (not content questions)

## Differentiation Strategies

### For Advanced Students

- Ask them to install software using a package manager (command line)
- Have them research CVE databases for known vulnerabilities in outdated software
- Challenge them to create a comparison guide for two similar applications

### For Struggling Students

- Pair them with a partner during the lab
- Provide a printed checklist of installation steps
- Allow them to complete the assessment with notes
- Focus on the core concepts (safe sources, update importance) rather than all details

### For Students Without Computer Access

- Use the teacher's computer for live demonstration
- Provide printed screenshots of each installation step
- Have them document the process by observing a partner
- Assign the research components (finding official sources) as homework

## Assessment Guidance

### Grading Rubric Summary

| Section | Points | Weight |
|---------|--------|--------|
| MCQ (5) | 10 | 17% |
| Short Answer (5) | 20 | 33% |
| Reflection (3) | 15 | 25% |
| Practical (2) | 15 | 25% |
| **Total** | **60** | **100%** |

### Common Grading Mistakes

- **MCQ:** Accept only the exact correct answer
- **Short Answer:** Look for specific technical terms and logical reasoning, not just length
- **Reflection:** Value personal experience AND learning demonstrated
- **Practical:** Assess clarity for a non-technical audience, not just accuracy

### Feedback Guidelines

- Start with what the student did well
- Point to specific areas for improvement
- Connect feedback to the learning objectives
- Suggest one concrete action for improvement

## Extension Activities

### For Early Finishers

1. Research the history of software installation (from floppy disks to cloud apps)
2. Explore the Ubuntu package repository and count how many packages are available
3. Compare the Microsoft Store, Apple App Store, and Google Play Store policies
4. Write a blog post about software safety tips

### Cross-Curricular Connections

- **Mathematics:** Calculate download times based on file sizes and internet speeds
- **English:** Write persuasive text about why software updates matter
- **Social Studies:** Research the digital divide and software access in rural areas
- **Science:** Explore how software vulnerabilities are discovered through ethical hacking

---

## Homework Assignment

Before the next class:

1. Check for updates on all devices at home (phone, tablet, computer)
2. Identify three applications that need updating
3. Research the official update source for one application you use daily
4. Write a short paragraph about what you found
