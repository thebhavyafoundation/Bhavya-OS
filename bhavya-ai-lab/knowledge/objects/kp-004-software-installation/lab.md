# Lab: Software Installation

**Duration:** 30 minutes
**Grade:** 9 | **Subject:** Digital Literacy
**Prerequisites:** KP-003: File Management

---

## Lab Overview

This hands-on lab gives you practical experience installing, configuring, updating, and uninstalling software on your computer. You will work with real applications and document every step.

## Materials Needed

- A desktop or laptop computer with administrative access
- Internet connection
- A text editor or notebook for documentation

---

## Lab 1: Identify Your System (5 minutes)

Before installing anything, understand your operating system.

### Steps

1. **Find your OS:** Right-click on "This PC" (Windows) or click the Apple menu (macOS) or open Settings > About (Linux). Record your operating system and version number.

2. **Check disk space:** Open File Explorer and click "This PC." Record how much free space you have on your main drive.

3. **Check installed software:** Open the list of all installed programs. On Windows, go to Settings > Apps > Installed apps. Count how many applications are currently installed.

## Lab 2: Safe Download Practice (10 minutes)

Verify that you can identify official software sources.

### Steps

1. **Choose an application:** Pick one of the following to research:
   - VLC Media Player
   - GIMP (image editor)
   - Notepad++ (text editor)
   - Blender (3D modeling)

2. **Find the official website:** Search for the application name. Do NOT click the first ad result. Look for the official domain. Record the URL.

3. **Verify the source:** Answer these questions about the URL you found:
   - Is it the developer's official domain?
   - Does it use HTTPS (secure connection)?
   - Is there a clear copyright notice on the page?

4. **Identify alternatives:** Find the same application on at least one app store or package manager. Record where else it is available.

## Lab 3: Install Software (10 minutes)

Install one application following proper procedure.

### Steps

1. **Download** the installer from the official source you identified in Lab 2.

2. **Verify the download** (Windows only):
   - Right-click the downloaded file and select Properties
   - Check if there is a "Digital Signatures" tab
   - Record the publisher name

3. **Run the installer:**
   - Follow each prompt carefully
   - At each step, record what the installer is asking you
   - Pay attention to any pre-checked options (these are often unwanted bundled software — uncheck them)

4. **Document the installation steps:**

## Lab 5: Uninstall Software (5 minutes)

Remove the application you just installed and clean up.

### Steps

1. **Close the application** completely (make sure it is not running in the background).

2. **Uninstall using the proper method:**
   - **Windows:** Settings > Apps > Installed apps > Find the app > Click Uninstall
   - **Linux:** Open the Software Center or run `sudo apt remove [package-name]`
   - **macOS:** Drag the app from Applications to Trash, or use the app's uninstaller

3. **Restart your computer** to clear any leftover processes.

4. **Verify removal:** Check the installed apps list again. Confirm the application no longer appears.

5. **Check for residual files:**
   - Look in your Documents folder for any files the app created
   - Check if any shortcuts remain on your desktop
   - Record what you found:
