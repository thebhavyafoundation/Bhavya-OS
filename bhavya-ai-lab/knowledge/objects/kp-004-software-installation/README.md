# KP-004: Software Installation

**Domain:** Digital Foundations
**Grade:** 9 | **Subject:** Digital Literacy
**Duration:** 2 hours | **Difficulty:** Beginner
**Priority Score:** 96

## Learning Objective

Install, configure, and update software applications on a desktop operating system.

## Prerequisites

- KP-003: File Management

## Learning Outcomes

Upon completing this knowledge package, students will be able to:

1. **Identify** different types of software (system software, application software) and their categories
2. **Evaluate** safe installation sources and recognize risks of downloading from unofficial websites
3. **Install** software using multiple methods: direct download, app stores, and package managers
4. **Configure** application preferences, user accounts, and permissions after installation
5. **Apply** update and patch management practices to keep software secure
6. **Perform** proper uninstallation procedures and clean up residual files

## Concepts Covered

| Concept | Difficulty | Description |
|---------|------------|-------------|
| Software Types | Beginner | System software vs. application software |
| Installation Methods | Beginner | Downloads, app stores, package managers |
| Software Configuration | Intermediate | Preferences, accounts, permissions |
| Updates and Patches | Beginner | Security patches and feature updates |
| Uninstallation | Beginner | Proper removal and cleanup |

## Key Definitions

| Term | Definition |
|------|------------|
| Software | A set of instructions that tells computer hardware what to do |
| Installer | A program that sets up software on a computer by copying files and configuring settings |
| App Store | A centralized platform for downloading and updating verified software applications |
| License | Legal terms governing how software can be used, copied, and distributed |
| Patch | A software update that fixes bugs, closes security holes, or adds features |

## Real-World Examples

1. **Microsoft Office** — Productivity suite via Microsoft 365
2. **Google Chrome** — Browser from official Google website
3. **Ubuntu Software Center** — Linux app store for open-source apps
4. **Visual Studio Code** — Code editor via download or package manager
5. **WhatsApp Desktop** — Mobile app as desktop installation
