# Media Specification: Software Installation

**Knowledge Package:** KP-004
**Domain:** Digital Foundations

---

## Article Specification

### Title
"Software Installation: A Complete Guide for Beginners"

### Target Audience
Grade 9 students and their families

### Word Count
1,200 - 1,500 words

### Structure

**Introduction (150 words)**
- Hook: Every time you open an app, someone installed it
- Thesis: Understanding software installation keeps your computer safe and running well
- Preview of what the article covers

**Section 1: What Is Software? (200 words)**
- System software vs. application software
- Why the distinction matters for installation and removal
- Visual: Infographic showing software categories

**Section 2: Where to Download Software Safely (250 words)**
- Official websites (with verification steps)
- App stores (Microsoft Store, Ubuntu Software Center)
- Package managers (APT, Chocolatey, Homebrew)
- Red flags: torrent sites, ads, suspicious URLs
- Visual: Comparison chart of safe vs. unsafe sources

**Section 3: What Happens When You Install (250 words)**
- The 6-step installation process explained simply
- What installers do behind the scenes
- Why understanding the process helps with troubleshooting
- Visual: Flowchart of installation steps

**Section 4: Configuration and Permissions (200 words)**
- Why you should not click "Accept All" blindly
- The principle of least privilege
- Common permission requests and how to evaluate them
- Visual: Permission decision tree

**Section 5: Updates Are Not Optional (200 words)**
- Security patches and why they matter
- Real examples of breaches from outdated software
- How to enable automatic updates
- Visual: Before/after comparison of patched vs. unpatched systems

**Conclusion (100 words)**
- Recap of key habits
- Call to action: Check for updates today
- Link to KP-004 lesson materials

### SEO Keywords
software installation, how to install software safely, download software safely, software updates, computer security beginners, digital literacy grade 9

### Visual Requirements
- Hero image: Computer screen with installation dialog
- 4-5 inline infographics or diagrams
- Screenshot examples of safe vs. unsafe download pages
- Color palette: Bhavya Foundation brand colors

- Quick montage of common software installation screens

**0:30 - 1:30 | What Is Software?**
- Animated diagram: hardware vs. software
- Two categories: system software and application software
- Why understanding this matters

**1:30 - 2:30 | Finding Safe Sources**
- Screen recording: Searching for VLC, comparing results
- Highlight the official site vs. ad-supported portals
- Show the verification checklist

**2:30 - 3:30 | The Installation Process**
- Screen recording: Installing VLC step by step

**3:30 - 4:30 | Configuration and Updates**
- Screen recording: First-run setup and settings

**4:30 - 5:00 | Call to Action**

- Challenge: Check for updates on your computer today
