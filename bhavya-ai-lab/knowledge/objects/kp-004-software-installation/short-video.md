# Short Video Script: Software Installation

**Title:** Software Installation in 60 Seconds
**Duration:** 60 seconds
**Format:** Vertical video (9:16) for Instagram Reels, YouTube Shorts, TikTok
**Audience:** Students and young learners

---

## Script

### [0:00 - 0:05] Hook

**Visual:** Phone screen showing a download button. Finger about to tap it. Freeze frame with red warning symbol.

**Voiceover (fast, energetic):**
"STOP. Before you download that app, you need to know this."

**Text Overlay:** "STOP Before You Download ⚠️"

---

### [0:05 - 0:15] The Problem

**Visual:** Fast montage of fake download sites, pop-up ads, suspicious installers.

**Voiceover:**
"There are thousands of fake download sites that look real. They install malware, steal your data, and slow down your computer. One wrong click can cause serious problems."

**Text Overlay:** "Fake sites look real. Check the URL."

---

### [0:15 - 0:30] The Solution — 3 Checks

**Visual:** Checklist appearing one item at a time with checkmarks.

**Voiceover:**
"Before you download ANY software, do these three checks. One: Is this the developer's official website? Type the URL directly. Two: Do you see the HTTPS lock icon? If not, leave. Three: Can you find the same app in an official app store? If yes, you are good."

**Text Overlay:**
```
✓ Official website?
✓ HTTPS lock icon?
✓ Available in app store?
```

---

### [0:30 - 0:40] The Installation Tip

**Visual:** Screen recording of installer with pre-checked options being unchecked.

**Voiceover:**
"When you install, READ every screen. Uncheck anything you did not ask for. Choose Custom over Express. Those pre-checked boxes install junk you do not want."

**Text Overlay: "Uncheck what you did not ask for"

---

### [0:40 - 0:50] The Update Rule

**Visual:** Windows Update screen. Update completing successfully.

**Voiceover:**
"And the golden rule: ALWAYS update. Updates fix security holes that hackers exploit. Turn on automatic updates. Do it right now."

**Text Overlay:** "Always Update. Always."

---

### [0:50 - 1:00] Call to Action

**Visual:** Bhavya Foundation logo. Website URL. Follow button animation.

**Voiceover:**
"Three checks before you download. Read every prompt. Always update. Follow Bhavya Foundation for more tips."

**Text Overlay:**
```
Bhavya Foundation
Digital Literacy Tips
Follow for more ✓
```

---

## Production Notes

- **Pacing:** Fast — every second counts in a 60-second video
- **Energy:** High energy, urgent tone — this is a safety message
- **Visuals:** Quick cuts, bold text overlays, screen recordings with annotations
- **Music:** Upbeat, modern, electronic — matches the energy
- **Text:** Large, readable text on every frame — many viewers watch without sound
- **Branding:** Bhavya Foundation logo on final frame
- **Hashtags:** #DigitalLiteracy #SoftwareSafety #ComputerTips #BhavyaFoundation
