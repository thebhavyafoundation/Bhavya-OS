## Page 3: File Naming Conventions

### The 5 Rules

1. **Be descriptive** — Name describes the content
2. **Date first** — Use YYYY-MM-DD format
3. **No spaces** — Use hyphens or underscores
4. **No special characters** — Avoid / \ : * ? " < > |
5. **Short but clear** — 3-8 words that describe the content

## Page 5: File Operations

### Operations Reference

| Operation | What It Does | Shortcut (Windows) | Shortcut (Mac) |
|-----------|-------------|-------------------|----------------|
| Copy | Creates a duplicate | Ctrl+C | Cmd+C |
| Cut | Prepares to move | Ctrl+X | Cmd+X |
| Paste | Places the copy/move | Ctrl+V | Cmd+V |
| Rename | Changes the name | F2 | Enter |
| Delete | Sends to Recycle Bin | Delete | Cmd+Delete |
| Undo | Reverses last action | Ctrl+Z | Cmd+Z |

## Page 6: Storage Management

### Storage Types

| Type | Speed | Cost | Portability | Good For |
|------|-------|------|-------------|----------|
| HDD | Moderate | Low per GB | No | Desktop computers, large storage |
| SSD | Fast | Higher per GB | No | Laptops, fast access needed |
| USB Drive | Moderate | Moderate | Yes | Transferring files between computers |
| External HDD | Moderate | Low per GB | Yes | Backups, large archives |
| Cloud Storage | Depends on internet | Free tier available | Yes (online) | Access anywhere, sharing |

### The 3-2-1 Backup Rule

- **3** copies of important files
- **2** different types of storage
- **1** copy offsite (cloud or separate location)
