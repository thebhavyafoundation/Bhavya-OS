## What You Will Learn

### The 5 Rules of File Naming
1. **Be descriptive** — Name files so you know what is inside without opening them
2. **Date first** — Use YYYY-MM-DD format so files sort chronologically
3. **No spaces** — Use hyphens or underscores instead
4. **No special characters** — Avoid / \ : * ? " < > |
5. **Short but clear** — Three to eight words that describe the content

### Three Ways to Organize Folders
- **By Subject** — One folder per class (Science, English, Math)
- **By Project** — One folder per assignment or project
- **By Date** — Organized by month or week

### The 3-2-1 Backup Rule
Keep **3** copies of important files, on **2** different types of storage, with **1** copy offsite (such as cloud storage).

## Try This at Home

### Family File Challenge

Spend 20 minutes this weekend organizing your family computer together:

1. **Open the desktop** — How many files are there? Can you name what each one is?
2. **Create folders** — Make a folder for each family member and one for shared documents
3. **Rename files** — Use proper naming conventions (date, descriptive name, no spaces)
4. **Clean up** — Move files to the right folders, delete what you no longer need
5. **Back up** — Upload important family photos and documents to a cloud service

This is a great activity to do together. Parents can learn from students, and students can teach what they know.

## Parent Corner

### Why File Management Matters

File management is not just a school skill — it is a life skill. In the workplace, employees who can organize digital files efficiently are more productive and less stressed. Here is how you can support your child:

**At Home:**
- Ask your child to show you their folder structure
- Help them set up a cloud backup for schoolwork
- Practice good file naming on shared family files

**Conversation Starters:**
- "How do you organize your school files?"
- "Can you show me how to find a specific file on your computer?"
- "What would happen if your computer broke? Do you have backups?"

**Resources:**
- GCFGlobal File Management Tutorial: free online guide
- Microsoft File Explorer Guide: step-by-step instructions
- CISA Backup Best Practices: government cybersecurity recommendations

## Educator Corner

### Teaching File Management

File management is often overlooked in the curriculum, but it underpins every digital task. Here are tips for integrating it into your classroom:

**Quick Activities (5 minutes):**
- Start class with a "rename this file" challenge
- Show a messy desktop and ask students to suggest organization strategies
- Have students explain their folder structure to a partner

**Full Lessons:**
- Use the KP-003 lesson plan for a 60-minute introduction
- Assign the File Organization System project for hands-on assessment
- Have students create a "File Management Tips" poster for younger students

**Assessment Ideas:**
- Give students a folder of badly named files and have them reorganize it
- Ask students to design a folder structure for a hypothetical scenario
- Test keyboard shortcuts with a timed file operations challenge

**Common Student Mistakes to Address:**
- Saving everything to the desktop
- Using vague file names like "doc1" or "notes"
- Not backing up important work
- Confusing Copy and Move operations

## Quick Reference Card

Print this card and keep it near your computer:

```
FILE NAMING CHEAT SHEET

Pattern: YYYY-MM-DD_description.filetype

Examples:
2026-08-05_science-report.pdf
2026-08-05_english-essay-draft.docx
2026-08-05_math-homework-ch3.pdf

NEVER USE:
Spaces → Use hyphens instead
Special characters → / \ : * ? " < > |
Vague names → doc1, notes, untitled

KEYBOARD SHORTCUTS:
Copy: Ctrl+C (Win) / Cmd+C (Mac)
Move: Ctrl+X then Ctrl+V / Cmd+X then Cmd+V
Rename: F2 (Win) / Enter (Mac)
Delete: Delete key / Cmd+Delete
Undo: Ctrl+Z / Cmd+Z

BACKUP RULE: 3-2-1
3 copies
2 storage types
1 offsite
```
