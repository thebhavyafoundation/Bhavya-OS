# KP-003: File Management

**Knowledge Package** | Domain: Digital Foundations | Grade: 9 | Subject: Digital Literacy

## Overview

This knowledge package teaches students how to organize files and folders using a hierarchical file system with proper naming conventions. Students learn to navigate, create, and maintain organized digital workspaces that save time and prevent data loss.

## Learning Outcomes

By the end of this package, students will be able to:

1. Explain the hierarchical structure of file systems and how files and folders relate to each other
2. Apply consistent file naming conventions that improve findability and professionalism
3. Design logical folder structures for school projects, personal files, and shared workspaces
4. Perform file operations—copying, moving, renaming, and deleting—with confidence and care
5. Understand different storage options and implement basic backup strategies to protect their work

## Prerequisites

- **KP-002: OS Navigation** — Students should be comfortable opening applications, using the desktop, and navigating basic operating system interfaces

## Time Estimate

- **Lesson:** 60 minutes (6 sections × 10 minutes)
- **Lab:** 45 minutes (5 hands-on exercises)
- **Project:** 45 minutes (folder structure design and implementation)
- **Assessment:** 30 minutes (15 questions)

**Total: 3 hours** (can be split across two sessions)

## Key Concepts

1. **File System** — The hierarchical tree of folders and files on a computer
2. **File Naming Conventions** — Rules for clear, consistent, and professional file names
3. **Folder Organization** — Designing logical structures that make files easy to find
4. **File Operations** — Copying, moving, renaming, and deleting files safely
5. **Storage Management** — Understanding drives, cloud storage, and backup strategies
