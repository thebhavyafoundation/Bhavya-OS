## Article Structure

### Title
"File Management 101: How to Never Lose a File Again"

### Subtitle
A Grade 9 guide to organizing your digital world with folders, naming conventions, and smart backups

### Target Audience
Students aged 14-15, educators, and parents in Himachal Pradesh

### Sections

**1. The Messy Desktop Problem (200 words)**
- Opening hook: "If your desktop looks like a graveyard of untitled documents, this guide is for you."

- Preview of what the article covers

**2. Understanding File Systems (250 words)**
- The library analogy: buildings, rooms, shelves, books
- Visual diagram of a file tree
- File paths explained with real examples
- Common mistakes (files on desktop, no folders)

**3. The Art of Naming Files (250 words)**
- The 5 rules with good and bad examples
- Date format explained (YYYY-MM-DD)
- Why spaces and special characters cause problems

**4. Folder Organization That Works (250 words)**
- Three methods: by project, subject, and date
- When to use each method
- Real example: organizing a semester of schoolwork
- The golden rule: create folders before you need them

**5. File Operations Made Simple (200 words)**
- Copy vs. Move explained with visual metaphor
- Keyboard shortcuts table

- Undo as your best friend

**6. Storage and Backups (200 words)**
- HDD vs. SSD in plain language
- Cloud storage: convenient but not enough
- The 3-2-1 backup rule
- When to back up

**7. Your Action Plan (150 words)**
- 5 steps to organize your files today
- Checklist for immediate implementation
- Call to action

- Bhavya Foundation branding

**Slide 2: The Problem**
- "The average student wastes 30 minutes per week searching for files"
- "That is 18 hours per school year — lost"
- Visual: Clock icon

**Slide 3: Rule 1 — Be Descriptive**
- Bad: `doc1.txt` → Good: `science-lab-report.pdf`
- "If the name does not describe the content, it is a bad name"
- Visual: Before/after comparison

**Slide 4: Rule 2 — Date First**
- Bad: `report-aug-5.docx` → Good: `2026-08-05_report.docx`
- "YYYY-MM-DD makes files sort chronologically"
- Visual: Calendar icon

**Slide 5: Rule 3 — No Spaces**
- Bad: `my file.docx` → Good: `my-file.docx`
- "Spaces cause errors in some systems — use hyphens"
- Visual: Hyphen icon

**Slide 6: Rule 4 — No Special Characters**
- Bad: `file!.pdf` → Good: `file-v2.pdf`
- "Characters like / \\ : * ? cause problems"
- Visual: Warning icon

**Slide 7: Rule 5 — Short But Clear**
- Bad: `my really long presentation that I worked on for hours.pptx`
- Good: `science-presentation-final.pptx`
- "3-8 words that describe the content"
- Visual: Shorten icon

**Slide 8: Folder Organization**
- Show tree structure: School/Science/Lab-Reports/
- "Organize by project, subject, or date"
- "Create folders before you need them"

**Slide 9: The 3-2-1 Backup Rule**
- 3 copies
- 2 storage types
- 1 offsite
- "Your work is worth protecting"

**Slide 10: Call to Action**
- "Apply these 5 rules today"
- "Tag a friend who needs this"
- Bhavya Foundation logo and website
