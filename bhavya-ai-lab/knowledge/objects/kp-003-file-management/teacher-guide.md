# Teacher Guide: File Management

**Grade:** 9 | **Subject:** Digital Literacy | **Duration:** 2 hours (2 sessions)

---

## Lesson Overview

This guide provides everything needed to teach file management effectively. The lesson is designed for two 60-minute sessions or one 2-hour block. Students learn file systems, naming conventions, folder organization, file operations, and storage management through direct instruction, hands-on practice, and a project.

### Session 1: Concepts and Practice (60 minutes)
Sections 1-3 of the lesson plus Lab Exercises 1-3

### Session 2: Application and Assessment (60 minutes)
Sections 4-6 of the lesson, Lab Exercises 4-5, and the Project

---

## Materials and Preparation

### Required Materials
- Computer with projector and screen
- Student computers (one per student or pair)
- File manager open on the projector (File Explorer or Finder)
- Pre-created test files for demonstrations
- Printed copies of the naming convention reference sheet

### Pre-Lesson Setup (15 minutes before class)
1. Open File Explorer / Finder on the projector
2. Create a demo folder structure for live demonstrations
3. Prepare 10 sample files with intentionally bad names in a flat folder
4. Ensure all student computers have basic access to desktop and Documents
5. Test that students can create folders and files on their machines

### Digital Resources
- Lesson slides (if using presentation software)
- Lab exercise worksheets (printed or digital)
- Project evaluation rubric (printed)

## Session 1: Concepts and Practice

### Opening (5 minutes)

**Hook Question:**
"Raise your hand if you have ever lost a file on your computer and could not find it again."

Wait for hands. Follow up:
"How did that feel? How much time did you waste? Today we learn how to never lose a file again."

**Learning Objectives (write on board):**
1. Understand how files and folders are organized
2. Name files so you can always find them
3. Create folder structures that make sense
4. Copy, move, rename, and delete files safely

---

### Section 1: File Systems (10 minutes)

**Teaching Approach:** Visual demonstration with the projector

1. Open File Explorer / Finder and navigate to the root of the C: drive
2. Show the tree structure by expanding folders one level at a time
3. Use the analogy: "The file system is like a library — drives are buildings, folders are rooms, files are books"

**Key Points to Emphasize:**
- The root is the top of the hierarchy — everything starts here
- Folders can contain files AND other folders
- The file path is like a home address: it tells you exactly where something lives
- Each folder can have many children, but each file has only one parent folder

**Common Misconception to Address:**
Students often think files on the desktop are "not really on the computer." Clarify that the desktop is just a folder — files there are still on the hard drive.

**Activity:** Have students draw their own file tree on paper (3 minutes)

---

### Section 2: File Naming Conventions (10 minutes)

**Teaching Approach:** Compare good and bad examples side by side

**Write on the board:**
| Bad Name | Good Name | Why |
|----------|-----------|-----|
| doc1.txt | 2026-08-05_essay-draft.txt | Descriptive and dated |
| my file.docx | science-report-final.docx | No spaces, clear |
| report!.pdf | report-v2.pdf | No special characters |
| untitled.pptx | presentation-slides.pptx | Descriptive |

**Five Rules (have students repeat them):**
1. Be descriptive
2. Date first in YYYY-MM-DD
3. Hyphens or underscores, not spaces
4. No special characters
5. Short but clear

**Live Demo:** Rename 3 badly named files on the projector using proper conventions. Let students suggest the new names.

**Common Misconception to Address:**
"Saving and exporting are the same." Explain: Saving overwrites the current file. Exporting creates a new file in a different format (like Word to PDF).

---

### Section 3: Folder Organization (10 minutes)

**Teaching Approach:** Present three methods, let students choose

Show the three methods from the lesson (by project, by subject, by date). For each, draw the tree on the board and discuss when it works best.

**Discussion Prompt:**
"If you were organizing files for this entire school year, which method would you choose? Why?"

**Activity (5 minutes):**
Students design their own folder structure on paper. They must include:
- At least 5 folders
- At least 2 levels of hierarchy
- A label for what each folder would contain

**Circulate and Check:** Walk around and look at student designs. Give quick feedback: "This is clear" or "Consider adding a folder for..."

---

### Transition to Lab (5 minutes)

Distribute lab worksheets or direct students to the lab.md file. Explain:
- Exercise 1: Navigate and create folders (8 min)
- Exercise 2: Practice naming (8 min)
- Exercise 3: Practice copy/move/rename/delete (10 min)
- We will continue with Exercises 4-5 in Session 2

Students begin Exercise 1. Circulate to assist.

---

### Lab Practice — Exercises 1-3 (30 minutes)

**Exercise 1 (8 min):** Students create the folder structure and answer questions.
**Exercise 2 (8 min):** Students create and rename files with proper conventions.
**Exercise 3 (10 min):** Students practice file operations with keyboard shortcuts.

**Troubleshooting Tips:**
- If students cannot find the path bar, show them how to enable it in their file manager
- If keyboard shortcuts do not work, have them use right-click menus instead
- If a student accidentally deletes something, show them how to restore from Recycle Bin/Trash

---

### Closing Session 1 (5 minutes)

**Quick Review (call on students):**
1. What is the root of the file system?
2. Name two rules for file naming.
3. What is the difference between Copy and Move?

**Homework Preview:**
"Tomorrow we finish with storage management, complete the organization challenge, and work on a project where you design a file system for a school club."

---

## Session 2: Application and Assessment

### Opening Review (5 minutes)

**Rapid-Fire Quiz (hands up or mini whiteboards):**
1. File path shows ____ (location)
2. File extension shows ____ (file type)
3. YYYY-MM-DD goes at the ____ of the file name (beginning)
4. Copy = ____ (duplicate, original stays)
5. Move = ____ (transfer, original removed)
6. 3-2-1 rule means ____ (3 copies, 2 storage types, 1 offsite)

---

### Section 4: File Operations (10 minutes)

**Teaching Approach:** Live demonstration with student participation

**Demo Sequence:**
1. Create a test file on the projector
2. Copy it — ask "Where did the original go?" (Nowhere — Copy keeps it)
3. Move it — ask "Where is it now?" (At the new location only)
4. Rename it — show keyboard shortcut F2
5. Delete it — show Recycle Bin/Trash and restore

**Student Practice (5 minutes):**
Students perform the same operations on their own computers.

**Key Emphasis:**
"Before you delete anything important, always ask: Do I have a backup? Can I restore this?"

---

### Section 5: Storage Management (10 minutes)

**Teaching Approach:** Show physical examples if available

**Show and Tell:**
- If you have an external hard drive or USB, pass it around
- Show a screenshot of cloud storage (Google Drive, OneDrive)
- Show the storage settings on the projector

**Key Concepts:**
- HDD vs SSD: HDD is like a record player (spinning disk), SSD is like a USB drive (no moving parts)
- Cloud storage: Convenient but needs internet, not a complete backup
- The 3-2-1 rule: 3 copies, 2 media types, 1 offsite

**Discussion:**
"Who has lost data before? A phone breaking, a computer crashing, accidentally deleting something? This is why backups matter."

---

### Lab Practice — Exercises 4-5 (15 minutes)

**Exercise 4 (9 min):** Storage check, find large files, backup simulation.
**Exercise 5 (10 min):** Complete organization challenge with mixed-up files.

**Circulate and Assist:**
- Help students find large files using search
- Guide students through the backup/restore simulation
- For Exercise 5, check that students designed their structure before organizing

---

### Project Introduction (5 minutes)

Explain the File Organization System project:
- Students become the "Digital Organization Lead" for a science club
- They design a folder structure, create naming conventions, organize messy files, and write documentation
- This is their major assessment for the unit

**Due:** Next class or within one week (your choice)

---

### Closing Session 2 (5 minutes)

**Exit Ticket:**
On a sticky note or small paper, students write:
1. One thing I learned today
2. One thing I am still confused about
3. One thing I will do differently with my files

Collect exit tickets. Address common confusions in the next class.

## Differentiation Strategies

### For Struggling Students
- Provide a pre-made folder template they can customize rather than designing from scratch
- Pair them with a partner for lab exercises
- Reduce the number of files to organize in Exercise 5
- Allow them to complete the project with a simpler folder structure

### For Advanced Students
- Challenge them to create a folder structure with 5+ levels
- Ask them to research cloud backup options and present findings
- Have them create a video tutorial teaching file management to younger students
- Introduce them to command-line file operations (terminal/cmd)

### For Students Without Home Computers
- Allow completion of exercises during library or lab time
- Provide a USB drive they can use for the backup exercise
- Partner them with students who have computer access
- Offer alternative assessment through verbal explanation and diagrams

## Assessment Rubric

### Formative Assessment (During Lessons)
- Observation during lab exercises
- Exit ticket responses
- Quick quiz participation

### Summative Assessment (Project)
| Criteria | Excellent (4) | Proficient (3) | Developing (2) | Beginning (1) |
|----------|--------------|----------------|-----------------|----------------|
| Folder Structure | Clear, logical, well-designed | Functional with minor issues | Basic but incomplete | Unclear or missing |
| Naming Conventions | Consistent, follows all rules | Mostly consistent | Some inconsistencies | Does not follow conventions |
| File Organization | All files correctly placed | Most files placed correctly | Some files misplaced | Files not organized |
| Documentation | Clear, complete, professional | Clear and complete | Basic but functional | Incomplete or unclear |

## Common Student Questions

**Q: Can I use spaces in file names?**
A: You can, but it is better practice to use hyphens or underscores. Some systems and programs do not handle spaces well.

**Q: What if I need to undo a file operation?**
A: Press Ctrl+Z (Windows) or Cmd+Z (Mac) immediately. You can also check the Recycle Bin/Trash for deleted files.

**Q: How much storage do I need for backups?**
A: For schoolwork, a USB drive (16-64 GB) is usually enough. For photos and videos, consider an external hard drive (1-2 TB).

**Q: Is cloud storage free?**
A: Most services offer free tiers (Google Drive gives 15 GB, OneDrive gives 5 GB). For large amounts of data, you may need to pay for a subscription.

**Q: What if I cannot find a file even after organizing?**
A: Use the search function with keywords from the file name. If you named it well, the search should find it. This is why naming conventions matter.

## Extension Activities

1. **File Management for Younger Students** — Have advanced students create a simple guide for Grade 5 students learning file management for the first time

2. **Storage Audit** — Students audit their own computers and report on how much space they use, what types of files they have, and what they could clean up

3. **Backup Challenge** — Students implement a real backup strategy (USB drive, cloud, or both) and document the process

4. **Career Connection** — Research how different professions manage files (graphic designers, software engineers, scientists, writers) and present findings
