# Project: File Organization System

**Grade:** 9 | **Duration:** 45 minutes | **Type:** Project-based learning

---

## Project Overview

Design and implement a complete file organization system for a realistic school scenario. You will create folder structures, establish naming conventions, organize existing files, and document your system for others to follow.

### The Scenario

You are the newly appointed "Digital Organization Lead" for your school's science club. The club has been running for three years, but files are scattered across different computers, USB drives, and email attachments. The club advisor has asked you to create a proper file management system that any club member can follow.

### Learning Objectives
- Design a hierarchical folder structure that serves multiple users and purposes
- Apply consistent file naming conventions across different file types
- Organize messy, unstructured files into a clean system
- Document the system so new members can follow it

---

## Deliverables

### 1. Folder Structure Design (10 minutes)

Design a folder structure that accommodates:
- Meeting notes and agendas
- Project files (at least 3 different projects)
- Photos and media from events
- Administrative documents (membership lists, budgets, contacts)
- Resources and reference materials

**Requirements:**
- At least 3 levels of hierarchy in at least one branch
- At least 8 folders total
- Logical grouping that makes sense to someone who did not design it

**Design Template:**
```
Science-Club-Files/
├── [Folder 1]
│   ├── [Subfolder 1A]
│   └── [Subfolder 1B]
├── [Folder 2]
│   └── [Subfolder 2A]
├── [Folder 3]
└── [Add more as needed]
```

**Write your complete design in `project-folder-design.txt`.**

---

### 2. Naming Convention Guide (10 minutes)

Create a naming convention guide that the club will adopt. Your guide must include:

**Required Elements:**
1. Date format (explain your choice)
2. File name structure (show the pattern)
3. At least 3 examples for different file types
4. A list of forbidden characters and why they are forbidden
5. Version naming rules (how to handle drafts and revisions)

**Template:**
```
SCIENCE CLUB FILE NAMING GUIDE

Date Format: [Your format]
File Name Pattern: [Your pattern]

Examples:
- Meeting notes: [example]
- Project files: [example]
- Photos: [example]

Forbidden Characters: [list and reasons]

Version Naming: [your rules]
```

**Write your complete guide in `project-naming-guide.txt`.**

---

### 3. File Organization (15 minutes)

Using your folder design and naming guide, organize these messy files:

**The Mess (files with bad names in a flat folder):**

```
untitled.docx
photo_2024_03_15.png
meeting notes march.txt
budget.xlsx
IMG_4521.jpg
science fair.docx
notes.txt
presentation final FINAL v2.pptx
member list.csv
report draft.docx
screen shot 2026-01-20.png
ideas.txt
```

**Instructions:**
1. Create your folder structure on your computer
2. Rename each file following your naming guide
3. Move each file to its correct folder
4. Delete any files that are truly empty or useless (check each one first)

**Expected Result:**
- All 12 files renamed and placed in correct folders
- No files left in the original flat folder
- File names follow your naming guide exactly

---

### 4. Documentation (10 minutes)

Write a `README.txt` that explains the system to a new club member who has never seen it before. Include:

1. **Overview** — What is this folder structure for?
2. **How to Navigate** — Quick guide to finding things
3. **Naming Rules** — Summary of the naming conventions
4. **Adding New Files** — Step-by-step for adding new work
5. **Rules** — What club members must and must not do

**Write your documentation in `project-readme.txt`.**

## Evaluation Criteria

| Criteria | Points | Description |
|----------|--------|-------------|
| **Folder Structure** | 25 | Logical hierarchy, appropriate depth, covers all needs |
| **Naming Conventions** | 25 | Consistent, clear, follows the guide you created |
| **File Organization** | 25 | All files correctly placed and renamed |
| **Documentation** | 25 | Clear, complete, usable by a new member |

**Total: 100 points**

### Scoring Guide
- **90-100:** Exceptional — System is professional, intuitive, and well-documented
- **75-89:** Proficient — System works well with minor improvements needed
- **60-74:** Developing — System covers basics but has organizational gaps
- **Below 60:** Needs revision — Review naming conventions and folder logic

## Extension Activities

### For Students Who Finish Early

1. **Create a Folder Template** — Package your folder structure as a template that can be duplicated for new projects

2. **Design a Backup Plan** — Write a one-page backup strategy for the club using the 3-2-1 rule

3. **Peer Review** — Swap your system with a classmate and provide feedback on clarity and usability

4. **Digital vs Physical** — Compare your digital file organization to how the club organizes physical materials (binders, posters, equipment). What similarities and differences do you notice?

## Real-World Connections

This project mirrors how professional organizations manage files:
- **Software companies** use folder structures with `src/`, `docs/`, `tests/`, `build/` directories
- **Design agencies** organize by client, then by project, then by asset type
- **Research labs** use date-based and project-based organization
- **Schools and universities** often organize by department, course, then semester

The skills you practice here apply directly to future careers in any field that uses computers.
