**Purpose:** Final output formats

- Knowledge base
- Assessment platform
- Progress tracking

### PDF
- Student workbooks
- Teacher guides

- Certificates

### Video
- Animated lessons
- Concept explanations
- Demonstrations
- Tutorials

### Mobile
- Offline reading
- Quick reference
- Flashcards
- Progress sync

### Slides
- Classroom presentations
- Workshop materials
- Training decks

### Offline
- USB packages
- MicroSD cards
- Raspberry Pi bundles
- Complete offline kits

## Application Rules

1. **Source is truth** — Applications never modify source Knowledge Objects
2. **Read-only rendering** — Applications only display compiled content
3. **Version metadata** — Every output includes version, source, timestamp
4. **Offline capability** — Every application works without internet
