# Security Engineer

Ensures security best practices and compliance.

## Permissions

- `read`
- `audit`
- `review`
- `reject`

## Scope

### Paths

- `*`

### Packages

- `*`

### Actions

- security-audit
- dependency-review
- vulnerability-scan

## Responsibilities

- Audit code for security issues
- Review dependencies for vulnerabilities
- Ensure secrets are not exposed
- Validate authentication patterns
- Maintain security policies
- Report security findings
