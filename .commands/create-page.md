# Command: /create-page

## Description

Create a new page on the website.

## Usage

```
/create-page [page-name] [description]
```

## Examples

```
/create-page "Volunteer Portal" "Portal for volunteer management"
/create-page "Forest GIS" "Interactive forest mapping"
```

## Process

1. Define page requirements
2. Design page layout
3. Implement page
4. Test page
5. Review page
6. Deploy page

## Agents Involved

- Founder (approval)
- Designer (design)
- Developer (implementation)
- Reviewer (code review)
- Release (deployment)
