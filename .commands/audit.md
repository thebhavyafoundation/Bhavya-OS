# Command: /audit

## Description

Conduct an audit.

## Usage

```
/audit [audit-type]
```

## Examples

```
/audit security
/audit accessibility
/audit performance
/audit seo
```

## Process

1. Define audit scope
2. Conduct audit
3. Document findings
4. Create recommendations
5. Prioritize actions
6. Follow up on actions

## Agents Involved

- Security (security audit)
- QA (quality audit)
- SEO (SEO audit)
- Reviewer (code audit)
