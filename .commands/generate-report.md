# Command: /generate-report

## Description

Generate a report.

## Usage

```
/generate-report [report-type] [period]
```

## Examples

```
/generate-report "monthly" "2026-07"
/generate-report "quarterly" "Q2-2026"
/generate-report "annual" "2026"
```

## Process

1. Define report scope
2. Gather data
3. Analyze data
4. Create visualizations
5. Write report
6. Review report
7. Distribute report

## Agents Involved

- Researcher (data gathering)
- Writer (report writing)
- Designer (visualizations)
- Founder (review)
