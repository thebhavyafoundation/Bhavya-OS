# Command: /create-article

## Description

Create a new article.

## Usage

```
/create-article [title] [topic]
```

## Examples

```
/create-article "Forest Update" "Monthly forest restoration progress"
/create-article "Volunteer Story" "Spotlight on volunteer contributions"
```

## Process

1. Research topic
2. Write article
3. Edit and proofread
4. Optimize for SEO
5. Review content
6. Publish article

## Agents Involved

- Researcher (research)
- Writer (writing)
- SEO (optimization)
- Reviewer (review)
