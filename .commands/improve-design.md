# Command: /improve-design

## Description

Improve the design of a page or component.

## Usage

```
/improve-design [page-or-component] [focus-area]
```

## Examples

```
/improve-design "homepage" "accessibility"
/improve-design "volunteer-portal" "mobile-responsive"
/improve-design "footer" "brand-consistency"
```

## Process

1. Audit current design
2. Identify improvements
3. Create design mockup
4. Implement changes
5. Test changes
6. Review changes

## Agents Involved

- Designer (design)
- Developer (implementation)
- QA (testing)
- Reviewer (review)
