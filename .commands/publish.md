# Command: /publish

## Description

Publish content to the website.

## Usage

```
/publish [content-type] [title]
```

## Examples

```
/publish article "Forest Restoration Update"
/publish blog "Volunteer Spotlight"
/publish news "New Partnership Announced"
```

## Process

1. Validate content
2. Review content
3. Optimize for SEO
4. Publish to website
5. Share on social media
6. Notify stakeholders

## Agents Involved

- Writer (content creation)
- SEO (optimization)
- SocialMedia (promotion)
- Reviewer (quality check)
