# Command: /research

## Description

Conduct research on a topic.

## Usage

```
/research [topic]
```

## Examples

```
/research "Himalayan biodiversity"
/research "Digital library best practices"
/research "Volunteer engagement strategies"
```

## Process

1. Define research scope
2. Gather information
3. Analyze findings
4. Create research report
5. Add to knowledge base
6. Notify stakeholders

## Agents Involved

- Researcher (data gathering)
- Writer (report writing)
- Historian (knowledge preservation)
