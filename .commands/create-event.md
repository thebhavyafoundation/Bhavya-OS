# Command: /create-event

## Description

Create a new event.

## Usage

```
/create-event [event-name] [date] [description]
```

## Examples

```
/create-event "Tree Planting Drive" "2026-08-15" "Community tree planting event"
/create-event "Heritage Workshop" "2026-09-01" "Cultural heritage documentation workshop"
```

## Process

1. Define event details
2. Create event page
3. Set up registration
4. Promote event
5. Manage attendance
6. Post-event follow-up

## Agents Involved

- Founder (approval)
- Developer (page creation)
- SocialMedia (promotion)
- Volunteer (management)
