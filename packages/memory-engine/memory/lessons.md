# Memory — Lessons

## Technical Lessons

### 1. Always Read Before Write

- Read existing code before modifying
- Read documentation before implementing
- Read patterns before creating new ones

### 2. Small Changes Are Better

- Atomic commits are easier to review
- Small PRs are easier to merge
- Incremental changes are easier to debug

### 3. Document Everything

- If it's not documented, it doesn't exist
- Document decisions, not just code
- Document why, not just what

### 4. Test Before Deploy

- Tests catch errors early
- Tests provide confidence
- Tests document behavior

### 5. Memory Is Essential for AI

- AI agents need memory to be effective
- Memory prevents repeated mistakes
- Memory enables continuous improvement

## Process Lessons

### 1. Follow Conventions

- Consistent code style is easier to maintain
- Consistent commit messages help history
- Consistent documentation helps onboarding

### 2. Automate Everything

- Manual processes cause errors
- Automation enables speed
- Automation ensures consistency

### 3. Review Everything

- Fresh eyes catch issues
- Code reviews improve quality
- Reviews share knowledge

### 4. Measure Everything

- What gets measured gets improved
- Metrics provide visibility
- Data drives decisions

## Governance Lessons

### 1. Constitution Is Supreme

- All decisions must comply
- No exceptions
- Document violations

### 2. Transparency Builds Trust

- Open decisions build trust
- Open processes build trust
- Open failures build trust

### 3. Accountability Matters

- Own your mistakes
- Learn from failures
- Improve continuously
