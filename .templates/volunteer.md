# Template: Volunteer

## Metadata

```yaml
name: "[Volunteer Name]"
email: "[Volunteer Email]"
skills: "[Skill1, Skill2]"
availability: "[Availability]"
status: "pending"
```

## Structure

### Personal Information

- Name
- Email
- Phone
- Location

### Skills and Interests

- Technical skills
- Non-technical skills
- Areas of interest
- Previous experience

### Availability

- Hours per week
- Preferred schedule
- Start date
- End date (if applicable)

### Onboarding

- Welcome email
- Team assignment
- Resources
- Next steps

## Onboarding Process

1. Review application
2. Approve application
3. Send welcome email
4. Assign to team
5. Schedule orientation
6. Provide resources
