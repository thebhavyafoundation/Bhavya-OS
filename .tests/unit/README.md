# Tests: Unit

## Scope

Individual component and function testing.

## Tools

- Vitest
- React Testing Library

## Test Cases

### Components

- Renders correctly
- Handles props
- Responds to events
- Accessibility

### Functions

- Input validation
- Data transformation
- Error handling
- Edge cases

### Hooks

- State management
- Side effects
- Cleanup

## Run Tests

```bash
pnpm test:unit
```

## Coverage

- Minimum 80% coverage
- Critical paths 100% coverage
- Regular coverage reports
