# Bhavya AI Lab OS — v3.1.0 Release Notes

**Date:** 2026-07-30

## Overview

v3.1.0 is a platform maturity release. It adds three significant capabilities (Provenance, Build Manifests, Animation Studio) and fixes a systemic path-resolution issue where every engine module computed its own root directory independently.

## What's New

### Provenance System

Every artifact generated by the educational compiler now carries a provenance record tracing it back to its source Knowledge Object, builder, runtime version, parent artifacts, and quality gate status. Provenance records are stored at `bhavya-ai-lab/institution/provenance/` and queryable through the runtime API.

```
KO → Lesson → Assessment → TeacherGuide → Workbook → VisualSpec → Video → Website
                                                                    ↓
                                              Each artifact has _provenance:
                                                artifactId, builder, runtimeVersion,
                                                source KO, parentIds, qualityGate
```

### Build Manifests

Every pipeline execution emits a build manifest at `bhavya-ai-lab/institution/manifests/` containing the full artifact list, quality gate summary, and execution duration. This enables downstream tooling (dashboards, CI/CD) to see what was built and whether quality gates passed.

### Animation Studio

A dedicated full-page timeline editor at `/animation/[id]` that visualizes the scene graph from visual specs:

- **Scene timeline**: horizontal bars showing per-element animation timing with color-coded animation types (fade-in, slide-up, scale-in, etc.)
- **Element timeline**: detailed per-element animation chart with start/end times
- **Video spec**: compositions, frame counts, resolution, FPS, formats

### Unified Configuration

All runtime path resolution now flows through a single `packages/runtime/engine/config.mjs` module. Previously, five modules (`capability-engine`, `course-manager`, `lesson-manager`, `knowledge-pipeline`, `api-standalone`) computed `ROOT` and `BHAVYA_LAB` independently using different relative depths. This was the source of the quality-gates path bug and would have caused increasingly subtle issues as more mission applications are built.

## Migration Notes

- `RUNTIME_VERSION` updated from `3.0.0` to `3.1.0` in capability-engine.mjs
- API version banner updated in api-standalone.mjs
- No breaking changes to the capability API or Lesson Studio integration

## Acknowledgements

This release addresses the configuration path debt identified during Sprint 2. The unified config module ensures that as more mission applications (Knowledge Browser, Assessment Studio, Engineering Dashboard) are built, they will resolve paths consistently without silent fallback failures.
