# Bhavya Foundation — Style Guide

**How We Write and Design**

---

## Writing Style

### Voice

- **Professional** — Clear, concise, authoritative
- **Minimal** — Every word earns its place
- **Human** — Not robotic, not overly casual
- **Honest** — No marketing fluff, no exaggeration

### Tone

- Confident but not arrogant
- Passionate but not emotional
- Technical but accessible
- Warm but professional

### Language Rules

1. **Use active voice** — "We restored" not "Land was restored"
2. **Use present tense** — "The system does" not "The system will do"
3. **Use simple words** — "Use" not "utilize"
4. **Use short sentences** — Maximum 25 words
5. **Use specific numbers** — "8 hectares" not "many hectares"

### Typography

| Element  | Font           | Size    | Weight |
| -------- | -------------- | ------- | ------ |
| Headings | Inter          | 24-48px | 700    |
| Body     | Inter          | 16-18px | 400    |
| Code     | JetBrains Mono | 14px    | 400    |
| Captions | Inter          | 12-14px | 400    |

### Spacing

Use 8px grid: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96

### Visual Principles

1. **Minimal** — Remove unnecessary elements
2. **Consistent** — Same patterns everywhere
3. **Accessible** — WCAG 2.1 AA minimum
4. **Premium** — Apple/Tesla-inspired quality
5. **Purposeful** — Every element has a reason

## Code Style

### TypeScript

- Use functional components
- Use hooks over lifecycle methods
- Use named exports
- Use const over let
- Use template literals

### CSS

- Use Tailwind CSS
- Use design tokens
- Avoid inline styles
- Follow spacing scale

### Documentation

- Write in Markdown
- Use clear headings
- Include code examples
- Link to related docs
