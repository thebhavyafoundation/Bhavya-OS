# Design System Summary

## Colors
- bg: #060608, surface: #0e0e11, border: #222228
- text: #f2f2f4, text-2: #9999aa, text-3: #666677
- green: #34d58a, blue: #4c9eff, amber: #ffb340, purple: #b57bff, red: #ff6b6b

## Typography
- Font: Inter (400/500/600/700/800), Mono: JetBrains Mono
- Scale: 11px → 68px

## Spacing
- Radius: 12px (cards), 8px (inputs), 6px (nav)
- Max width: 1200px
- Grid gaps: 16px/20px/24px

## Components
- `@bhavya/bdl` → tokens, primitives, icons, charts, maps, motion
- `@bhavya/ui` → re-exports BDL for apps
- WCAG AA, skip links, focus rings, prefers-reduced-motion
