# Bhavya OS Architecture

## High-Level Architecture

```
Apps (Next.js 15)
  │
  ▼
Mission Runtime (packages/mission-runtime)
  ├── Gateway     — Provider-agnostic AI gateway
  ├── Registry    — Deterministic registry reader
  ├── Memory      — Domain-owned memory system
  ├── Events      — Event bus
  ├── Metadata    — App manifest types
  ├── Accessibility — A11y utilities
  └── Observability  — Logging
  │
  ▼
Shared Packages
  ├── @bhavya/ui     — Component library (re-exports BDL)
  ├── @bhavya/bdl    — Design Language (tokens, primitives, icons, charts, maps, motion)
  ├── @bhavya/bdx    — Developer tools (CLI, generators, validators)
  ├── @bhavya/docs   — MDX content registry
  ├── @bhavya/branding — Brand & navigation
  ├── @bhavya/charts — Chart primitives
  ├── @bhavya/icons  — Icon wrappers (Lucide-based)
  ├── @bhavya/maps   — MapLibre-ready placeholders
  ├── @bhavya/auth   — Auth (shell)
  ├── @bhavya/config — Shared config
  └── @bhavya/database — Database (shell)
  │
  ▼
Infrastructure
  ├── schemas/     — JSON Schema validation
  ├── registry/    — Generated deterministic registries
  ├── standards/   — Engineering & governance standards
  ├── specs/       — Product specifications
  ├── rfcs/        — RFC documents
  ├── config/      — App configuration
  └── memory/      — Domain memory (agents, decisions, knowledge, projects, releases, research, tasks)
```

## Dependency Rules

- Apps may depend on `@bhavya/mission-runtime` and `@bhavya/ui`
- `@bhavya/ui` depends on `@bhavya/bdl`
- Packages may depend on other packages only if no circular dependency
- No apps depend on other apps
- Schema, registry, standards, specs are data, not code imports

## Key Decisions

- **Provider-Agnostic Gateway** (ADR-008): AI gateway abstracts LLM providers behind a unified interface
- **Deterministic Registry** (ADR-012): All registries generated by `scripts/generate-registry.js`, never edited manually
- **Domain-Owned Memory** (ADR-013): Each domain owns its memory subdirectory with `_meta.json` manifests
- **Monorepo with Turborepo**: Shared TypeScript, ESLint, build caching
