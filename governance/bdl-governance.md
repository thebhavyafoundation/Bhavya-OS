# BDL Governance

Treat BDL like a public API.

## Roles & Approvals
- Only the Founder and Chief Architect can approve new primitives.

## Token Evolution
- No direct CSS modifications; tokens must be modified in the JSON source of truth.

## Breaking Changes
- Require an ADR and bump the Major version.

## Deprecation Policy
- Deprecated components must exist for 1 major version cycle before archiving.

## Compatibility Guarantees
- Backward compatibility guaranteed within a major version.
